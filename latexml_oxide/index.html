exit_removing 🔒
process::exit skips destructors, so an archive’s unpacked sources (--whatsin=archive, a TempDir) are removed first: each conversion of an arXiv zip left its whole source tree in the temp directory, which filled a per-user /tmp quota over an A/B run. The exits this function does not see — the watchdog’s timeout and memory ceiling, the allocation-failure hook — remove it through its remove_on_exit registration.
fatal_before_conversion 🔒
End a run whose input could not be opened as a conversion, as a Fatal conversion ends: the Fatal: line, the verdict and Status:conversion:3 (Perl latexmlc’s last lines), the log at log_path (--log, or the default <stem>.latexml.log), and the Fatal exit code. A failed unpack once printed a bare message and exited 1 with no Fatal, no status line and no log (astro-ph9407095, astro-ph9409032, cs9610101: PostScript sources), where cortex_worker and Perl both record a Fatal.
