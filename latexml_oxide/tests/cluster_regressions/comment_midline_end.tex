% aborts: "File ended while scanning use of \next", no PDF (verified
% 2026-09-05). Perl comment.sty.ltxml swallows silently; the earlier Rust
% mid-line detection (OXIDIZED_DESIGN #133, retracted) showed more than
% pdflatex. Now: TeX's error is reported, nothing after the open comment is
% kept. Guard: comment_midline_end_runs_to_eof_like_pdflatex.
\documentclass{article}
\usepackage{comment}
\begin{document}
Body cites \cite{a} and \cite{b}.
\begin{comment}
Some commented reasoning that runs for a while.
The proof concludes here.\end{comment}
After the comment block.
\begin{thebibliography}{9}
\bibitem{a} First entry.
\bibitem{b} Second entry.
\end{thebibliography}
\end{document}
