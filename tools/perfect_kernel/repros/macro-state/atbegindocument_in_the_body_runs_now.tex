%   `\document` (latex_constructs/sect02.rs) fires them with `\hook_use:n`: the hooks are never
%   marked, and the late code is added to a hook nothing runs again. 57r special-cased etoolbox's
%   `\AfterEndPreamble` with a done flag; the general fix is `\hook_use_once:n`, after which the
%   flag goes.
