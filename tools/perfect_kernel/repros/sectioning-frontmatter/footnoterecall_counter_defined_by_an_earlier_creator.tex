% mechanism: an author block's `\footnoterecall{uni}` (`\footnotemark[\value{uni}]`) reads the counter an earlier
%   creator's `\footnoteremember` made (`\newcounter{uni}`, global); pdflatex typesets the block in order, so every
%   recall prints the remembered mark. The remember macro's body holds spaces (` \footnote{#2} \newcounter{#1} …`), so
%   its definitions are in no replayable declaration; FNR1 writes the block as Perl's `\lx@add@authors` splits it, in
%   order (`declaration_reads_past`, emit.rs; the article form footnoterecall_three_authors_spaced_remember is GREEN).
%   Under scrarticle (raw scrarticle.cls, `\LoadClassWithOptions{scrartcl}`) the title block is scrartcl's
%   (`settle_title_block_after_class_load`): its notes step the footnote counter, so the recall reads 1, "∗".
%   Formerly footnoterecall_counter_defined_by_an_earlier_creator_red
% witness: 2407.13730, 2606.19583 (GA1d A/B; `\footnoteremember` in 6 of 35,942 census papers)
% oracle:  pdflatex (TL 2025, -no-shell-escape) 0 `!`: Ann One ∗, Bob Two ∗, Cy Three ∗; footnote ∗ The University
% engines: rust int163a 0 errors, 3 warnings, Bob Two's mark dropped, Cy Three's mark empty; GA1d 1 error
%   (Error:undefined:\c@uni), 2 warnings, Cy Three's mark `<ERROR class="undefined">\c@uni</ERROR>`; GA1e 0 errors,
%   2 warnings, the XML as int163a; GA1f 0 errors, 3 warnings, Cy Three's mark "0" with its "Missing number"; FNR1
%   0 errors, 1 warning (the decline), Bob Two's and Cy Three's marks "0"; INT081EP 0 errors, 3 warnings, Bob Two's
%   and Cy Three's marks dropped; OMNT 0 errors, 1 warning (the decline), each creator the note ∗
% expect:  0 errors, 1 warning (the decline); each creator carries the one note's mark ∗
% status:  GREEN (OMNT)
\documentclass[a4paper]{scrarticle}
\newcommand{\footnoteremember}[2]{
	\footnote{#2}
	\newcounter{#1}
	\setcounter{#1}{\value{footnote}}
}
\newcommand{\footnoterecall}[1]{
	\footnotemark[\value{#1}]
}
\begin{document}
\title{T}
\author{
 Ann One\footnoteremember{uni}{The University}
		\and  Bob Two \footnoterecall{uni}
  \and
	Cy Three\footnoterecall{uni}
}
\maketitle
Text.
\end{document}
