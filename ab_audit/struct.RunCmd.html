Fields§

§bin_a: PathBuf§expect_a: String

The commit binary A must be stamped with (a short or full SHA).

§bin_b: PathBuf§expect_b: String§accept_stamp: Vec<String>

Accept a binary stamped with exactly this revision although it is not the expected one (a historical replay). Printed in the report header. Repeatable.

§papers: PathBuf

One paper per line: an arXiv id (resolved under –corpus) or a .zip path.

§out: PathBuf§jobs: usize§cores: String

The taskset -c core list.

§timeout: u32

The converter’s own --timeout.

§wall: u32

The wall-clock kill (timeout <wall>).

§memory_kb: u64

ulimit -v, in KiB.

§corpus: PathBuf§texlive_bin: PathBuf

Put first on PATH (kpsewhich, pdflatex).

§dump_dir: Option<PathBuf>

LATEXML_DUMP_DIR for both binaries (default: inherited).

§allow_same_binary: bool

Allow A and B to be byte-identical binaries (a noise baseline).

§accept_same_stamp: bool

Allow A and B to carry one revision stamp although their expected commits differ (a replay of binaries built in a target directory whose stamp never moved). Printed in the report header.

§repo: PathBuf

The git checkout that resolves the expected commits (a binary older than its commit is refused).
