Crate ab_audit 

Source
Expand description

P0: one audited A/B comparator, and the per-document audit it is built from.

  • ab_audit run --bin-a A --expect-a SHA --bin-b B --expect-b SHA --papers LIST --out DIR converts every paper with both binaries (refusing a binary whose stamped revision is not the expected commit; --accept-stamp <stamp> replays a historical one, printed in the report) and compares them.
  • ab_audit compare A_ROOT B_ROOT -o PREFIX compares two existing output trees.
  • ab_audit audit ROOT -o PREFIX audits one tree (the seed of the end-of-queue fidelity audit).

Every report is <prefix>.tsv (one row per paper: tier, flags, then the columns), <prefix>.summary.txt (tallies, then the rows ranked regressions first) and <prefix>.details/<key>.txt per flagged paper. It fails toward flagging: a missing or unparsable XML, a log without its status, a timeout is a regression row. Exit code: 0 when every row is a change or the same, 1 when any row is a regression or needs review (a reason), 2 refused or bad usage.
