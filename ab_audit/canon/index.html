Module canon 

Source
Expand description

The canonical XML diff: each document as a line per start tag (attributes sorted), text run, end tag, comment and processing instruction. Ids are MAPPED, not stripped: an xml:id/fragid becomes # and an idref @ in the compared line, the real values ride beside it, A’s ids are paired with B’s along the diff’s equal runs, and every reference in an equal line must still point at the paired target. No wrapper is stripped: a font run added around a contact is a changed line.

Volatile host detail is normalised in values: a /tmp/<dir> path (the graphicspath PI of an archive unpacked to a temporary directory) and a Rust primitive’s heap address in a \meaning.
