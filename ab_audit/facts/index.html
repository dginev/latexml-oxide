ab_audit

Module facts 

Source
Expand description

What one conversion produced, read from its log and its XML: the per-document extractor shared by compare (two trees) and audit (one tree).

The log is read ANSI-stripped, so a coloured \x1b[31mError: line counts (the bug that once hid 2002.05958’s 654 errors as “fixed”, CLAUDE.md). The XML is parsed by roxmltree, a pure-Rust reader, so each worker thread owns its parser (rust-libxml is not shared across threads in this project).
