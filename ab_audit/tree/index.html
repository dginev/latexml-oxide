ab_audit

Source
Expand description

Output trees: finding the document directories under a root, loading one document’s files, and the parallel map the subcommands share.

A document directory holds a conversion’s XML and log under one of the names the harnesses use: out.xml + out.log (ab_audit run, the payload A/B runners), or <name>.xml + <name>.latexml.log (the manual sweeps). meta.tsv (ab_audit run), verdict.tsv (the manual sweeps) or exit.txt (a runner’s exit code) give the exit code, the wall time and the timeout; the key is the directory’s path under the root. A directory holding only a run record or a stderr/stdout capture is a document too.
