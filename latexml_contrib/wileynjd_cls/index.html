Module wileynjd_cls 

Source
Expand description

The Wiley NJD family of classes: WileyNJD-v1, WileyNJD-v2, WileyNJDv5 (and wileyNJDv5), and WileyASNA-v1 (crate::wileyasna_cls), one binding for every version (wiley_njd_family).

These Wiley journal classes share a common set of frontmatter macros (\corres, \authormark, \jnlcitation, \cname, \cyear, \vol, \DOI, \papertype, …). Route to OmniBus and gobble the frontmatter so downstream content renders cleanly.
