dhucs.sty — kotex’s Unicode Hangul support.

The real package is loaded under the pdfTeX byte mouth (KERNEL_CAPABILITIES K10, inputenc_sty::enable_pdftex_byte_mouth). dhucs.sty:44 \ifx 가가\else… \RequirePackage{kotexutf}\expandafter\endinput\fi is a byte-vs-native-Unicode engine probe: pdfTeX sees two different UTF-8 bytes (false → the kotexutf byte path, kotexutf-core.tex:177 \def\dhucs@hu{\z@}) — which the byte mouth reproduces, so kotexutf_sty.rs takes over — while a Unicode-native reader (the LuaTeX persona; Perl alike) sees one character twice (true → the native branch). In that branch \dhucs@hu, \setInterHangulSkip, \jong/ \jung/\rieul and the \disablehangul* switches are defined only under the LuaTeX (dhucs.sty:58-75, \csname directlua\endcsname) or XeTeX (:78-93, \csname XeTeXrevision\endcsname) probes — neither of which may be satisfied here — so memhangul-ucs.sty:90 \memh@hu=\dhucs@hu, oblivoir-utf.cls:271, kosections-utf.sty:53 \hskip\dhucs@hu fail (10 kotex/oblivoir manuals; SHARED with Perl, pdflatex clean). Supply the branch’s engine-neutral subset (dhucs.sty:69-75 minus the luatexko attribute calls) when the raw load left them undefined. Guard: perfect_kernel_batch56::dhucs_native_branch_defines_the_hangul_skip.
