MnSymbol.sty — Achim Blumensath’s symbol fonts (TeX Live tex/latex/mnsymbol/MnSymbol.sty, v1.4 2007/01/21).

No Perl binding exists (Perl reads the package raw, where its seven NFSS symbol fonts give no glyphs). MnSymbol replaces the math symbol fonts and declares every name in them, one font slot after another, with \Decl@Mn@Char/\Decl@Mn@Alias (\DeclareMathSymbol), the big operators with \Decl@Mn@Op/\Decl@Mn@Int, and the delimiters with \Decl@Mn@Open/\Decl@Mn@Close (\DeclareMathDelimiter). The binding gives each declared name a math symbol: the tables below hold all 1,307 \Decl@Mn@Char/\Decl@Mn@Alias names of MnSymbol.sty:250-1584 in declaration order, the 55 \Decl@Mn@Op/\Decl@Mn@Int operators of :1586-1650, and the delimiters, accents and commands of :1651-1853 are bound by hand below.

Glyphs. A name’s code point is unicode-math’s for the same name (unicode-math-table.tex), else the Unicode TeX4ht gives the name’s font slot (tex4ht/ht-fonts/unicode/MnSymbol/MnSymbol{A,B,C,D,F}-Bold10.htf, HTML entities decoded: &gt; is \gtr‘s >; a slot is the running \Set@Mn@Sym count), else the base glyph with U+0338 for a negated \n… name, else a glyph chosen from MnSymbol.pdf’s tables, checked against its drawings (the footlines’ bar on the side the name says, \rightfootline ⟞; \upmodels ⫫, 2604.25507; \ocirc ⊚, where unicode-math’s \ocirc is the ring accent). A glyph Unicode lacks (most of the diagonal arrows, the filled spoons, the smile/frown stacks) takes the code point of its family’s right-pointing member — the XMTok keeps the command’s name. Roles follow the declared class as the sibling symbol bindings do: \mathrel an ARROW for an arrow/harpoon/spoon/mapsto family, else RELOP; \mathbin ADDOP for the plus/minus/cup/cap/vee/wedge/triangle/ diamond families (math_common’s \cup, \vee, \diamond), else MULOP; \mathord none (ID for the dots); \mathop SUMOP or INTOP.

Names already defined keep their definition (OXIDIZED_DESIGN_DIVERGENCES #545). MnSymbol redeclares the whole AMS set (\Decl@Mn@Sym first \lets the name undefined); here a name the kernel, amsmath or amssymb already defines keeps that definition, whose role and meaning are richer than the slot’s class, and a name sharing an already defined name’s slot and class is \let to it (\nin to \notin, \rightvdash to \vdash). So \Mn@Fake@Missing (:29-78) has nothing left to fake, and its undefining of \eth, \mho, \Finv… is not carried out: a document that uses them keeps them. The package’s own declarators stay available to a document under the same rule (2410.20575 \Decl@Mn@Open{\lsem}{MNlargesymbols}{'102} after loading MnSymbol); a new name takes the glyph the tables give its slot (slot_glyph), and a slot they do not map goes to the kernel’s \DeclareMathSymbol with an Info:unmapped.

Witnesses (run 340: 13,470 papers load MnSymbol, 3,724 ended in Error, their first errors \nin 175, \udots 173, \sumint 165, \cupdot 130, \strokedint 113, \lsem 108): 2410.20575, 2210.15345 (\let\vec\undefined before MnSymbol, whose \DeclareMathAccent\vec defines it again), 2508.12496 (\checkmark), 2609.07645 (\llangle), 2604.25507 (\upmodels), atableau (\bigcircle), biblatex-apa6-test (\rcurvearrowse), univie-ling (\blacktriangleright).
