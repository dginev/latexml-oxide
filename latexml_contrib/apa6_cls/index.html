Module apa6_cls

Expand description

apa6.cls (APA 6th edition manuscripts, TeX Live apa6 2023/08/07 v2.35): the class is loaded raw, and its numbered author forms — \twoauthors … \sixauthors, \onetwoauthors/\twooneauthors (apa6.cls:745-759) and \twoaffiliations … \sixaffiliations, \onetwoaffiliations/\twooneaffiliations (:761-777), which store each name in \@authorOne … \@authorSix and each affiliation in \@affilOne … \@affilSix — become the frontmatter as its title page lays them out: every layout (man :1143-1214; jou and doc \put@one@authaffil/\put@two@authaffil :1321-1365 at :1378-1414) sets the n-th name over the n-th affiliation, so each name is a creator carrying the affiliation of its number. Under the raw class (the rawclasses lever) only the class’s refused \maketitle read those stores, so the names and affiliations were lost (2102.04789: “Najko Jahn, Lisa Matthias, Mikael Laakso” and their Göttingen address; 1710.04173 \sixauthors/\sixaffiliations). The one-author \author/\affiliation stay the kernel’s and K11’s.

Functions§

apa_family_class
Interpret the class name raw (as the document asked for it: latexml_package::shipped_class::requested_shipped_class, so a class only named like the family — TeX Live’s apa6e.cls, a paper’s apa6mod.cls, which the prefix fallback answers with this binding — is read as itself), then give its numbered author forms to the frontmatter (define_numbered_author_forms) when it has them. A paper whose source lacks the class falls to OmniBus, with the loader’s missing-file Warning.
define_numbered_author_forms
The numbered author and affiliation forms of apa.cls and apa6.cls (apa.cls:427-459 is apa6.cls:745-777 line for line), handed to the frontmatter at \maketitle, where the class reads them: mask names the class’s author-masking flag (apa6.cls:126 the mask option, read at :1143 and :1378; apa.cls has none, None).
