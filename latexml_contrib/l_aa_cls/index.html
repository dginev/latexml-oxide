l-aa.sty (also shipped as laa.sty, the same file, and as l-aa-ps.sty, the same with PostScript fonts: copy in astro-ph9606053, used by astro-ph9505054): Springer-Verlag’s LaTeX 2.09 style for Astronomy & Astrophysics, “L-AA vers. 3.0” (1992-1996), loaded as \documentstyle{l-aa}. Neither TeX Live nor most papers using it ship it, so the document fell to OmniBus and stopped at \thesaurus (843 run-336 papers: astro-ph9804097, astro-ph9405007, astro-ph0211472). It is the predecessor of aa.cls, which kept its document syntax (\institute with \inst, \offprints, \mail, \date, {abstract}, \keywords, {acknowledgements}, the astronomical symbols, plain TeX’s \cases and \pmatrix in displays: astro-ph9908044), so this is the aa class binding with what L-AA itself adds; a binding for the class, which \documentstyle prefers (latex_constructs.pool.ltxml:105-108). Rust-only: Perl has no l-aa binding. A paper shipping the file gets this binding too, as a binding outranks a raw file (astro-ph9601070, astro-ph9601165).
