multibib: the raw package, with each list’s bibliography style read at that list.

multibib.sty:234 defines \bibliographystyle<suffix> to write \bibstyle to the side aux file bibtex reads (<suffix>.aux); it never calls \bibliographystyle, so BIBSTYLE, which \bibliographystyle records for the .bib route (\lx@record@bibstyle, sect11.rs), stayed empty. A document with only such lists then read no .bst (bst_declared_fields, OXIDIZED_DESIGN_DIVERGENCES #823): the fields its style declares stayed raw data (urldate, quantum.bst:44, printed “(accessed:~12.07.2019)” at :719; the quantum-bibliographystyle-demo manual).

The record is keyed by the suffix \newcites declares, and \bibliography<suffix> reads its own in a group around the list: \bibliographystyle{alpha}\bibliographystyleweb{plain} gives alpha on the main list and plain on web, as pdflatex’s [Zet01] and [1], in either order of the lists; opticajnl.cls:288’s and osajnl’s \bibliographystylefullrefs{opticajnl} beside the document’s opticajnlnt (1908.11477, 2006.07118, 2008.09542, 2205.11481, 2308.15957, 2607.03975). Where \bibstyle is still the kernel’s the list takes the style’s citation style too; a package that took \bibstyle owns that (natbib’s \@gobble, natbib_sty.rs), and the list takes the style’s name and order (record_bibstyle, as \bibliographystyle). BIBSTYLE after the lists stays the main list’s, or with none the first declared. Limit: a style declared after its own list reaches BIBSTYLE only, not that list’s attribute.
