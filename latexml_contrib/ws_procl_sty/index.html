Module ws_procl_sty 

Source
Expand description

World Scientific’s proceedings styles for the article class: sprocl.sty (8.5 × 6 in), mprocl.sty (9.75 × 6.5 in) and stwol.sty (two-column, smaller size), “based on a style file by Lukas Nellen”, LaTeX 2.09 option styles (\documentstyle[sprocl]{article}). Not in TeX Live and not always shipped: missing, their \author was article’s, which keeps the last call, so a paper with an \author per author group kept only the last group (hep-ph9611287, hep-ph9611291, hep-ph9602339, hep-ex9910019, hep-ex9608006, nucl-th9809087, gr-qc9806116, hep-ph9905201; mprocl gr-qc9710030). The census of the shipped copies in the 92xx-99xx arXiv (704 papers, 203 variants of sprocl.sty; 59 papers, 23 of mprocl.sty; 42 papers, 10 of stwol.sty; cited from hep-ph9701265’s sprocl.sty) shows one document syntax: \author and \address append a line each to the title block (sprocl.sty:18-21, \@aabuffer), so an address is that of the authors given since the one before, \abstracts{…} the abstract (:32-38), \citeup/\citelow citations (:103-110), an {arabiclist} (:82-89), footnotes marked \alph (:65). Single variants add more: \collaboration (1 of the 10 stwol variants, stwol.sty:23-24, a title-block line as \author’s; hep-th9610159), and in sprocl \authora (= \author), \id (indexed text), \CaP (small caption text), \clearemptypage (1 variant each; hep-ph9708375’s family), bound as conveniences a document’s own definition replaces; \pnasus/\jtb/\jeem appear only commented out (hep-ph9708375’s sprocl.sty:170-178), so they are left unbound. The rest is page layout. Rust-only: Perl has no binding.
