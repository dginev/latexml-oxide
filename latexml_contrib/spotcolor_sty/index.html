spotcolor.sty (Jens Elstner, 2006; no Perl binding): read raw, as before. Its \AddSpotColor{<space>}{<name>} {<PDF name>}{<C M Y K>} (spotcolor.sty:31-41) writes the spot colour’s CMYK alternate only into a PDF object, so the binding keeps it for color’s driver models (color_sty::driver_alternate_color): a \definecolor{<n>} {spotcolor}{<name>,<tint>} that defines <n> first takes the alternate at that tint — the colour a viewer without the spot ink shows (the Separation’s tint transform, C0 0 0 0 0 to C1 the CMYK, N 1). ieeeaccess.cls:126-131’s PANTONE3015C (CMYK 1 0.3 0 0.2).
