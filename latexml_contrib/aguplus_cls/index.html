aguplus.cls (AGU++, P. W. Daly, 1999/08/19 1.6b): the class is loaded raw — it reads the AGUTeX package its option names (aguplus.cls:47-71 \getAGU, \InputIfFileExists{\AGUpack.sty}: agupp.sty, agums.sty, jgrga.sty, …) — and the title-page commands the AGUTeX packages share with AASTeX, which they derive from, become the frontmatter as the AAS binding makes them (aas_support_sty.rs, Perl aas_support.sty.ltxml:121-134). Under the raw class (the rawclasses lever) they were the class’s typesetting: \affil set its text into the \@title box (aguplus.cls:236) that \xmaketitle typesets at the first \section (:192, :225), so the affiliations were body paragraphs, and \authoraddr (agupp.sty:154-158) gathered \authaddr@list, printed only by the class’s own end of the references (agupp.sty:266-306 \endreferences, \endthebibliography), which the kernel’s bibliography replaces, so every author address was lost (1107.5305, 1203.5042, physics9702009, 1010.3998, 0811.3118).

The class also carries a copy of natbib 7.0 (aguplus.cls:861-1173, \ModuleVersion{natbib}[1999/05/28 7.0 (PWD)]) with square brackets (:864 \NAT@open{[} \NAT@close{]}): it loads natbib’s binding with square, as the copy is natbib’s. Without it \citet/\citep were the copy’s, printing a bold “?” for every reference (the kernel’s bibliography writes no \bibcite; 1010.3998: 75), and \cite[][]{key} the kernel’s (1107.5305).
