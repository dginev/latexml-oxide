“A stand-in’s copy provides” (OXIDIZED_DESIGN_DIVERGENCES #731): note this assignment of token’s meaning, made while the paper’s copy of an author file is read after the binding that stands in for it (binding::content::read_stand_in_copy), or while the \AtEndOfClass/\AtEndOfPackage code it registered runs at the end of that load (copy_provides_wrap). Every assignment of a meaning goes through here — TeX’s \def family, \let, \futurelet, \chardef and the \countdef family, and the LaTeX declarators (\newcommand, \renewcommand, \DeclareRobustCommand, \newenvironment, \newcounter, \newif, \newtheorem, \newlength…), at install_definition and assign_meaning. One of a name LaTeXML’s semantic layer owns (owned_by_the_semantic_layer; an environment {X} is owned when \begin{X}, \X or \endX is) holds only inside the copy’s own code: the binding’s meaning is kept aside and put back when the copy’s read ends (leave_copy_provides_frame), so for the document the definition acted as \providecommand does, while the copy’s load-time logic sees what it defined, as in TeX: aipproc.cls:559 \ifnum\pageref>0 after its option’s \chardef\pageref (astro-ph0105128); epl2.cls:1317-1318’s \let\epl@org@bibitem\bibitem before its \def\bibitem, which the epl binding makes too (a kept \let would take the binding’s wrapper for the original, and \bibitem would call itself: 0906.2627, 1102.2776, 1203.4765). Every other assignment stands as TeX makes it: an undefined name (the copy’s extras), a raw kernel name, an earlier raw file’s or the document’s, a stub or borrow. Not while the state is unlocked (a binding’s before/after code, an AddToMacro! append), nor for a locked name, which install_definition refuses first (copy_provides_refuses_locked). Each name kept for the binding is logged once per copy, at Info.
