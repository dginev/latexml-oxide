Does a stand-in’s copy, read now, \newcommand a text default its binding does not own that a base class it \LoadClassed defines (copy_base_class_defines: article.cls:616 \newcommand\refname, :618 \figurename, which the article binding assigns in its own load; a raw base class’s own definition)? The real class has the name, so LaTeX stops with “Command … already defined” and keeps the first definition: an Error here as there (sect08.rs \newcommand; the reviewer’s probes newcmd_base and nc_chain, pdflatex 2 errors, “References”/“Figure 1”; nc_namedef 1). A name the base class made \relax is definable, as LaTeX’s \newcommand finds it. \def/\renewcommand redefine as before.
