pub fn isolated_input_ends_here() -> bool
Expand description

Whether the token just read ends an isolated reading context (reading_from_mouth: a token list digested on its own, such as a constructor’s argument {$x}, which may come wrapped in a further brace pair): only }s left in its pushback and its mouth exhausted. A } read here is the argument’s own closing brace, which TeX strips with the argument — one end of a construct digested as a unit (stomach.rs formula_ends_with_its_unit, OXIDIZED_DESIGN #553). false whenever a mouth of its own is still open in the context.
