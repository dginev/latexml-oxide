LaTeXML’s own .cls/.sty/.tex bindings that TeX Live does not distribute: they are the files they are named for — LaTeXML’s styles (latexml.sty, lxRDFa.sty, ar5iv.sty, latexmlman.sty, xylatexml.tex), its fallback class OmniBus.cls, the shared cores the class bindings load (ams_core.cls, the _support styles) and the test fixtures (keysetopt.sty, lxtesttemplate.sty).
