pub fn hook_use_tokens(hook: &str, once: bool) -> Vec<Token>
Expand description

The tokens running the kernel hook hook as \UseHook (or, once, \UseOneTimeHook) does, or none when it has no code: an empty \UseHook does nothing; an empty one-time hook only marks itself used (\__hook_use_once_set:n, latex.ltx:6399-6411, so later code runs at once), which an already used one needs not. Not kept: the clear code \__hook_use_once:nn leaves in an undeclared hook’s next slot, which only \IfHookEmptyTF on it would see.
