The state value listing the files read as the document’s content (load_tex_content: the main file, each \input/\include of content, a literal: source as its text), parted by NUL: the document’s own text, which the title-page check reads for the words the document wrote (latexml_engine base_utilities::frontmatter::title_page_check). Rust-only.
