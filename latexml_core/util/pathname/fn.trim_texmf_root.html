Function trim_texmf_root 

pub fn trim_texmf_root(value: &str) -> Option<String>
Expand description

A TEXMF root value without its trailing directory separators, or None when there is none to trim.

A value that is a path list or a brace expansion (holding the path-list separator, , or {, as {/a/,/b/}) is a search spec and stays as written; a file-system or drive root (/, C:/, C:\) keeps one separator (a root of / is no working install either way); only the end is trimmed (a !! prefix or a // inside the path stays). The separators are /, and on Windows also \. Program-qualified names (TEXMFROOT.<progname>, TEXMFROOT_<progname>) are not among TEXMF_ROOT_VARS and stay as written.
