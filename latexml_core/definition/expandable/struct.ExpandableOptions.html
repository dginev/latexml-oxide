§tex_declared: bool

Declared with TeX’s long-ness: the \def family, LaTeX’s starred \newcommand family. Such a macro, made by a format, a raw-loaded file or the document, checks its arguments for \par (Expandable::checks_par).

§short: bool

A binding’s port of a TeX macro that is not \long: it checks its arguments for \par as the original does (Expandable::checks_par), wherever it is made. amsppt.sty:804/:814’s \footnote/\footnotetext, whose arguments stop at a paragraph’s end (amsppt_sty.rs).

§extends: bool

Wraps the name’s current meaning and delegates to it (OmniBus’s \bibitem, which loads natbib for a [\protect\citeauthoryear…] label and otherwise calls the \bibitem it saved): it extends the name rather than replacing it, so a provide-only load installs it too (state::provide_only_declines).

§drops: &'static [u8]

The arguments (their numbers, #n) this binding macro drops by design: the real package or class prints nothing of them (hyperref’s \texorpdfstring #2, the PDF bookmark’s text), or they are page furniture (FIDELITY_CHARTER §2). The title-page check wants none of their words (state::DocumentArgument::used, OXIDIZED_DESIGN_DIVERGENCES #953 “106t”); the expansion is unchanged (Expandable::dropped_by_design).
