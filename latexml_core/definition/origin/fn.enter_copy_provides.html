pub fn enter_copy_provides(id: u32)
Expand description

Enter copy id’s provides-mode (0: suspend it, for a file the copy loads), until the matching leave_copy_provides. A stack, not a guard: the scope markers \lx@copy@provides@begin{N} and \lx@copy@provides@end wrapped around a hook the copy registers bracket a token run, not a Rust call. Entering from no mode (or leaving to none) puts \AddToHook’s registration seam in place (or back out, state::swap_copy_provides_hook_seam).
