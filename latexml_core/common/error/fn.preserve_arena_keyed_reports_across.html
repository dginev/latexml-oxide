pub fn preserve_arena_keyed_reports_across(f: impl FnOnce())

Run f (which resets the string arena) while preserving REPORT’s undefined and missing tallies: their SymStr keys are materialized to owned strings before f and re-interned into the fresh arena afterwards, so get_status_message / conversion_verdict remain byte-identical after dropping the core engine’s arena between core and post-processing.
