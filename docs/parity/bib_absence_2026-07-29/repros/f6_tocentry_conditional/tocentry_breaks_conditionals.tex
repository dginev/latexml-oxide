% Where the `\iffalse` comes from: `\acs@tocentry@print` (achemso.cls

%   * a `\let` alias of `\fi` is honoured, plain and inside a
%     catcode-modified group;
%   * `\endgroup` inside a conditional branch is handled correctly;
%   * the `\ifx…\else…\expandafter…\fi` tail recursion inside `\edef`,
%     transcribed on its own, converts cleanly — including with several real
%     recursion steps (the first attempt terminated on the first comparison
%     and proved nothing);
%   * a delimited `\long\def\grab#1\end#2` scan followed by a conditional is
%     fine;
%   * `\AtEndDocument{\if@twocolumn …\else …\fi}` is fine on its own, with the
