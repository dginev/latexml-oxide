REVTeX 4.0 provides \bm at \begin{document}, only while it is still undefined (revtex4.cls:6030-6032 \appdef\class@inithook{…\@ifxundefined\bm{\let\bm\REV@bm}{}…}, run from \class@documenthook at \AtBeginDocument, :213-215; \@ifxundefined counts a \relax as defined), so a preamble’s own \newcommand{\bm}{\bibitem} (nucl-th0307033) stands; defined at load, the binding’s took it away (Perl revtex4_support.sty.ltxml:167 the same, KNOWN_PERL_ERRORS #965). REVTeX 4.1/4.2 define it at load. Guards: perfect_kernel_batch73a::{revtex_bm_is_provided_at_begin_document, revtex41_bm_is_defined_at_load}.
