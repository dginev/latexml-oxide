Module lmc_fontmap 

Source
Expand description

LMC font encoding: montex’s Mongolian Cyrillic (lmcenc.def, the kmr/kmss/kmtt fonts).

Each slot decodes to the glyph the kmr fonts draw there (montex’s METAFONT driver mcyrill.mf: mccoding.mf’s slots, mcyrsymb.mf’s < > «» № ₮). The Cyrillic letters sit at the Latin slots they transliterate — W is В, X Х, J Ж, Q Ч, C Ц, H Һ, Y Ы — and the rest of the alphabet above 127 (lmcenc.def’s \DeclareTextSymbols); punctuation, digits and accents are cmr’s, as OT1’s (punct.mf, romanp.mf, accent.mf, comlig.mf), and V/v hold no glyph. Perl has no LMC map: the encoding falls back to OT1, so {\mnr Xalx} read “Xalx” where pdflatex prints “Халх”, and \No/\MyTogrog printed nothing (KNOWN_PERL_ERRORS #438). Witnesses: montex/montex, montex/mlsquick.
