The amsart class internals that documents and .ldf files call directly (amscls/amsart.cls; amsproc.cls and amsbook.cls carry the same lines), for the three class bindings (ams_core_cls.rs), not the ams_support loads an autoload makes in other classes. The class lines verbatim, a \newcommand as \def:

  • :75-96 \except, \for, \forany over the \newswitch switches, with the switches the class declares, runhead (:305) and toc/lof/lot (:1143-1145): \section{\for{toc}{<short>}\except{toc}{<long>}} keeps the long title in the body (run-347 inventory 89 + 73 papers; 1304.2934, 1601.05128, 1912.08145).
  • :554, :564 \@keywords and \@subjclass, empty: \keywords and \subjclass give the frontmatter, so a document’s own print of them (2510.22858 \ifx\@keywords\@empty\else…) prints nothing twice, as \@dedicatory; :114 \@dateposted and :710-711 \@PII alike (memo-l.cls:116-171’s abstract-page notes read them: 2412.15928). A document’s own \subjclass or \keywords that stores them as amsart’s does (amsart.cls:553-564; 2004.06211:12 \renewcommand*\subjclass[2][2000]{\def\@subjclass{#2}…}) has them printed by amsart’s \maketitle (:657-658, a first-page footnote): the \maketitle hands a non-empty one to the frontmatter, as the binding’s own setter would (\lx@ams@stored@topmatter, at \lx@maketitle@begin), unless that setter ran (\lx@ams@subjclass@given, \lx@ams@keywords@given), so a paper using the class’s commands is unchanged, nor when the K11 reroute owns a raw class’s \keywords store (\iflx@ams@keywords@rerouted; a class wrapping acmart, which loads amsart). Perl loses them (OXIDIZED_DESIGN_DIVERGENCES #902; 1009.1929 too).
  • :687-689 \copyrightinfo{0000}{(copyright holder)}, the defaults \copyrightyear/\copyrightholder (2403.17965).
  • :837, :856-864 \abstractbox and \@setabstract/\@setabstracta, which set a box an abstract-like environment of the document’s fills (1512.02361 and 2602.22909 {abstracts}, 2303.07306 and 2201.00740 {acknowledgements}, all amsart’s own {abstract} code under another name): \maketitle sets it and makes \@setabstract \relax, so one after the title is set where it ends (\ifx\@setabstract\relax \@setabstracta \fi; the acknowledgements). The box \maketitle sets is the title page’s abstract, as amsart’s {abstract} fills it: the frontmatter abstract (<ltx:abstract>, 1512.02361’s English and French abstracts). The kernel {abstract} gives the frontmatter and leaves the box void. Before, \@setabstract was an empty macro and the box was never set (1512.02361 kept its text only through an Error’s recovery, with a stray “=”).
  • :1189-1218, :1240-1241 the contents-line code, \@tocwrite/\@tocwriteb (2004.14791’s own \chapter, 1805.00244) and \l@figure/\l@table (magyar.ldf:1696-1697 patches them; 2503.14638).
  • :1244 \@defaultbiblabelstyle, :1262 \bibliofont (2105.14892, 2312.03234).

Not ported: :320-322 the section names, empty until \appendix (1504.08082 \markboth{\sectionname}…, a running head): the refnum composition reads a defined \<counter>name as the unit’s name (base_utilities.rs \lx@refnum@compose), so an empty one put a space before every section number.

Perl’s binding defines none of them (ams_core.cls.ltxml, ams_support.sty.ltxml), KNOWN_PERL_ERRORS #721.
