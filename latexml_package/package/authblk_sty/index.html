FRONTMATTER_CONVENTIONS
This binding’s frontmatter conventions (the observer’s, OXIDIZED_DESIGN_DIVERGENCES #837), declared at its load (declare_frontmatter_conventions, user ruling 2026-10-28: each binding declares its own): authblk: an unlabelled \author shows \AB@thenote and an unlabelled \affil is labelled by it (ruling 1, review revfms2a2’s answer to question 6b): when the marks show, the affiliation is the authors’ showing its number, a labelled author’s too (2605.25017); in block mode (no marks shown) the run of authors since the last \affil, as this binding declares it at the call (annotate=run:<n>). written: the observer’s writer writes authblk’s creators (brief 95b, OD #942: 2511.07020, 2008.07734, 2110.01283, 2008.13643; a paper whose reading it cannot apply keeps today’s output). title_page Block: its own \@author (authblk.sty:168-171) prints the block and what a document appends to it (FX24b, OD #996: 2511.15315).

author_names_a_list
Whether a per-author class’s author argument names several authors (author_call’s list branch, the marks aside): a comma, the word “and” or a kernel \and between names, a separator the kernel’s author read parts at. Shared with the meta-class binding (latexml_contrib meta_class.rs, 2605.17829).
define_author_and_affil
authblk’s \author[mark]{name} and \affil[mark]{affiliation} (authblk.sty:114-167) as frontmatter calls; also run by a class that copies authblk’s code over them (lni.cls:384-464, lni_cls.rs in latexml_contrib), so the copy’s accumulators — read only by its refused \maketitle — do not take the author block.
