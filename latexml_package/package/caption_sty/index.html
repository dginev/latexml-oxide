CLASS_CAPTION_FONTS
The class caption fonts knob (user ruling 2026-10-22), off by default: a class binding ports its caption format as names and separators (“Fig. 1. text”, “TABLE I” over the text), and the fonts the class sets its caption labels and text in (acmart’s bold or small sans serif, IEEEtran’s small caps and compsoc sans serif, jfm’s small caps, webofc’s and jinstpub’s bold label) only with this set, so an HTML theme styles every caption alike. Set by latexml.sty’s classcaptionfonts option ahead of the class, which ar5iv.sty takes too and passes on with its own options (ar5iv_sty.rs): --preload=[classcaptionfonts]ar5iv.sty, or --preload=[classcaptionfonts]latexml.sty without ar5iv. Not a second preload of latexml.sty beside ar5iv.sty’s: a preload’s options go to opt@<name>.<ext> only (core_interface.rs), so after ar5iv.sty a repeat load has no new options to apply (content.rs apply_repeat_options), and before it latexml.sty takes its options alone and ar5iv’s are lost (docs/SYNC_STATUS.md); noclasscaptionfonts clears it. Readers: class_caption_fonts. Not the class’s, so not behind it: a package’s own caption fonts (algorithm2e’s \fnum@font@algorithm) and the document’s \captionsetup keys. OXIDIZED_DESIGN_DIVERGENCES #884. Guards perfect_kernel_batch78y::*_with_class_caption_fonts.

class_makecaption_label
A class’s own \@makecaption whose label is set in font and closed by close, the close set in the label’s font too when close_in_font: “Figure 1. …”, the period in the bold (webofc.cls:788-812 \@CaptionTitleFont #1 \@FloatCounterEnd\@FloatCounterSep in one group, \@FloatCounterSep “. “, :786), or “Figure 1. …”, the period after it (jinstpub.sty:362-378 \textbf{\figurename\nobreakspace\thefigure} with #1. #2): the class’s caption format \lx@makecaption (latex_constructs_rust_only.rs), which the figure’s and table’s title formats (\format@title@<type>, their label font \fnum@font@<type>, sect09.rs) and every other kernel float’s (newfloat_sty.rs, listings_sty.rs) take, installed as class_makecaption installs it. The kernel’s caption keeps LaTeXML’s own \@makecaption, so the class’s label format was “Figure 1:” (2610.23498 webofc, 2006.05543 jinstpub). The font is the class’s caption font, set only under CLASS_CAPTION_FONTS; without it the label is unstyled and its close the tag’s (“Figure 1” closed by “. “).

sub_label_tokens
A sub-caption’s label (\fnum@sub<type>): its label format applied to the sub-float’s number (caption3.sty:734-737). The format is the first non-empty \captionsetup setting among keys (state keys, the most specific first: CAPTION_sub<type>_labelformat, then the package’s family — subcaption’s [sub], subfig’s [subfloat]), else the package’s default (parens for both: subcaption.sty:218-222, subfig.sty:285-288). An undefined format is caption3’s \caption@Error{Undefined label format}, the label keeping the default.
