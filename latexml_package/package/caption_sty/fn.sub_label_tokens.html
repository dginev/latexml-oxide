A sub-caption’s label (\fnum@sub<type>): its label format applied to the sub-float’s number (caption3.sty:734-737). The format is the first non-empty \captionsetup setting among keys (state keys, the most specific first: CAPTION_sub<type>_labelformat, then the package’s family — subcaption’s [sub], subfig’s [subfloat]), else the package’s default (parens for both: subcaption.sty:218-222, subfig.sty:285-288). An undefined format is caption3’s \caption@Error{Undefined label format}, the label keeping the default.
