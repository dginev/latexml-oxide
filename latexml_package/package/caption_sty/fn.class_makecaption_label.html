A class’s own \@makecaption whose label is set in font and closed by close, the close set in the label’s font too when close_in_font: “Figure 1. …”, the period in the bold (webofc.cls:788-812 \@CaptionTitleFont #1 \@FloatCounterEnd\@FloatCounterSep in one group, \@FloatCounterSep “. “, :786), or “Figure 1. …”, the period after it (jinstpub.sty:362-378 \textbf{\figurename\nobreakspace\thefigure} with #1. #2): the class’s caption format \lx@makecaption (latex_constructs_rust_only.rs), which the figure’s and table’s title formats (\format@title@<type>, their label font \fnum@font@<type>, sect09.rs) and every other kernel float’s (newfloat_sty.rs, listings_sty.rs) take, installed as class_makecaption installs it. The kernel’s caption keeps LaTeXML’s own \@makecaption, so the class’s label format was “Figure 1:” (2610.23498 webofc, 2006.05543 jinstpub). The font is the class’s caption font, set only under CLASS_CAPTION_FONTS; without it the label is unstyled and its close the tag’s (“Figure 1” closed by “. “).
