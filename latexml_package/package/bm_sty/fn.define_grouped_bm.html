The \bm a class defines for itself, setting its argument in a box or group (BoldArgument::Grouped): the World Scientific classes (ws_journal_cls.rs), interact.cls (interact_cls.rs) and RevTeX (revtex4_support_sty.rs, Perl revtex4_support.sty.ltxml:167).
