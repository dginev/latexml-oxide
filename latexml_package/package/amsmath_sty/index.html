amsmath_loaded_beyond_original
The state after amsmath’s binding was loaded where the original file does not load amsmath (require_amsmath_beyond_original; aa.cls’s aa_support): amsmath’s definitions stay in force, its old-form error is off (\matrix@error gobbles the command), and amsmath counts as not loaded (latexml_core::state::mark_unloaded), so the next request for it runs its binding again.

define_amsfonts_macro_accent
amsfonts’ \widehat#1, \widetilde#1 (amsfonts.sty:78-87, unless stix is loaded): macros of one argument over LaTeXML’s own accents, kept as \lx@ams@kernel@<name>, their argument passed through \lx@undelimited@argument. Unlike amsmath’s accents these take a mandatory argument of their own (\hat\widehat x errs in TeX), and an amsmath accent is no nested accent under them (\widehat\hat z errs: \mathaccent has no \macc@nested).
define_undelimited_argument
\lx@undelimited@argument{<package>}{<reader>}{<head>}{<argument>}: <head> (a LaTeXML accent or script, which reads the next math item) followed by the undelimited macro argument the TeX macro <reader> of <package> gave it — amsfonts’ \widehat/\widetilde (amsfonts.sty:78-87), mathstyle’s \sb/\sp (mathstyle.sty:126-127, \mathsub{…#1}, named by what they stand for, _/^) — braced, as those macros brace it, so a parameterless macro (or one with optional parameters only: \newcommand{\tasknum}[1][]{\tau_{#1}}) is the item with its whole expansion. amsmath’s accents (amsmath.sty:754-797, \mathaccent"…{#5}) go through \lx@ams@mathaccentV, the same with amsmath’s nested accent. A single command is passed as its definition says (UndelimitedArgument): one that reads a mandatory argument is read with its own arguments, braced, the call the author wrote (\hat{\mathbf{x}}, \hat{\pair{a}{b}}), with one Warning that TeX errs there (\hat\mathbf{x}: “Argument of \select@group has an extra }”; breqn’s x_\text{a}: “Argument of \text@ has an extra }”), whose recovery loses the formula (user ruling 2026-10-17, OXIDIZED_DESIGN_DIVERGENCES #721).

require_amsmath_beyond_original
amsmath for a binding whose original file does not load it — spie.cls (TeX Live’s; spieman.cls), the old ws-procs9x6.cls and ws-ijmpb.cls copies, Scientific Word 2.5’s tcilatex.tex, OmniBus’s autoload, the old aa.cls — so that a paper using amsmath’s commands without loading it still gets them (original_loads: the original does load it, as the paper’s copy reads, crate::shipped_class::shipped_copy_loads; then this is the plain load), with the options the original passes to it (imsart.cls:84-118 \PassOptionsToPackage{leqno}{amsmath}). In pdflatex amsmath is not loaded there: a \pmatrix{…}, \matrix{…} or \cases{…} is Plain TeX’s, with no “Old form \pmatrix'" error (amsmath.sty:1077-1090 \matrix@check), and @ifpackageloaded{amsmath} is false (0805.4522 tcilatex, 1003.3524 spie, nucl-th0206027 ws-procs9x6, quant-ph0607049 ws-ijmpb: no error in pdflatex). So the old-form error is off ([amsmath_loaded_beyond_original]) until the real amsmath.sty loads: the document's own \usepackage{amsmath}, a raw class or package that loads it (ptptex.cls:362 \if@ams; a copy's own load, read as the stand-in's copy, binding::author_files), or a binding whose original does (mathtools, physics). That load runs the binding again, its \matrix@errorthe error again, as Perl's aa.cls.ltxml:57 reload does for aa. A second such binding finds amsmath's definitions in force and loads nothing. Guardsperfect_kernel_batch77q::{old_form_matrix_is_plain_tex_where_amsmath_is_not_loaded, old_form_matrix_errs_once_the_document_loads_amsmath}`.
