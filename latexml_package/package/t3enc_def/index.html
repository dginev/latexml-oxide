t3enc.def (tipa’s T3 encoding, FUKUI Rei): the raw file, with its accent machinery set as Unicode combining marks.

t3enc.def sets every tipa diacritic by stacking boxes: \upper@accent/\lower@accent (t3enc.def:268-294, the same as exaccent.sty’s) put \hbox{#2\char#4} — slot #4 of the font #2 selects (\tipaencoding, or the current font for \empty) — above or below \hbox{#5} in a \vbox/\vtop, \ipaclap (:330-333) overlaps two boxes and \ipabar (:343-354) rules a bar across one. Read raw, the accent box came apart from its letter or was lost (\textsubring{n} printed “n”, \textbarb a two-row table). Here the slot’s glyph is the combining mark the tipa font draws there (t3_fontmap.rs t3_accent_mark: \textsubring{n} n̥, \~*{a} a̰, \textroundcap{a} ȃ, \t{ts} t͡s), applied as the kernel applies \accent (\lx@applyaccent); a box accent (\Upperaccent’s b form: tipa.sty:477 \sups) stays raw. In T3 the kernel accents \', \~, \r … are t3enc.def’s own (:489-516, with their * forms below the letter), as LaTeX’s encoding-dispatched accents are. OXIDIZED_DESIGN_DIVERGENCES #781. Witnesses 1802.05444, 2405.01972.
