OmniBus.cls — fallback class for documents with unknown document classes. Port of LaTeXML/Package/OmniBus.cls.ltxml (312 lines).

Defines common frontmatter commands, theorem environments, natbib autoloads, and various compatibility macros encountered in real-world arxiv submissions.

provide_over_base_class
OmniBus over the base class a stand-in binding loaded as its real file does (OXIDIZED_DESIGN_DIVERGENCES #736): provide-only (ProvideOnlyGuard, as \documentstyle loads it over a class, sect01.rs), so it adds the frontmatter commands and environments the base class leaves undefined ({keywords}, \email, \affiliation, …) and replaces none of the base class’s. A binding that once loaded OmniBus as its base (ceurart, atlasdoc, lmcs, pnas-new, czipreprint) keeps what OmniBus gave it where the real base class (scrartcl, amsart, extarticle) has nothing: ceurart’s {keywords}, OmniBus’s ltx:classification, which a trial without it lost (-10 to -15 words a paper; ceurart witnesses 2509.11496, 2608.23214).
