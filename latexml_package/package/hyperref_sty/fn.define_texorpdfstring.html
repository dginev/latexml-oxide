\texorpdfstring{TeXString}{PDFstring} outside a PDF string (inside one, \pdfstringdef keeps #2). The PDF string goes to the bookmarks only; nothing of it is printed: the binding’s declared drop, which the title-page check wants none of (OXIDIZED_DESIGN_DIVERGENCES #953 “106t”; 2306.06741’s {$Y(4230)…$}{Lg}, 2306.06006). The ar5iv preload provides it to a document that never loaded hyperref (ar5iv_sty.rs, OXIDIZED_DESIGN #588; hep-th0702068).
