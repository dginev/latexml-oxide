The markup the VTeX IMS journal classes share: arximspdf.cls / arxstspdf.cls (Annals of Probability/Statistics) and arxbj.cls (Bernoulli) define the same structured bibliography ({barticle}/… with \b* fields; arxbj.cls: 2599-2897), the same {pf} proof and automatic \qed (arximspdf.cls:1417-1434 = arxbj.cls:1428-1445) and the same \tablewidth table notes (arximspdf.cls:1729-1790, arxbj.cls:1665-1809). Their bindings load this beside their own options, math and frontmatter.

Bibliography note: these classes use natbib + \bibitem/thebibliography, so a bibitem produces ltx:bibitem > ltx:bibblock (Flow.model). The structured ltx:bib-* vocabulary is schema-valid only inside ltx:bibentry (the BibTeX path), NOT inside bibblock, so the \b* field macros are PASSTHROUGH text (readable + schema-valid), not mapped to ltx:bib-*.

vtex_keyword_markup
The {keyword}[class=<class>] block with \kwd[<sep>]{<text>} entries that the VTeX classes share: arxbj.cls (2490-2541 of 1106.2467’s copy), arximspdf.cls (2404-2450 of 1107.3284’s) and imsart.sty (1518-1567 of 1410.4462’s copy, 2334-2393 of 2605.27137’s). The entries are joined by \sep (none before the first, an explicit [<sep>] in its place: \kwd[Primary ]{60F05}\kwd[; secondary ]{62G20}), headed by the class’s \keyword@<class> (\setattribute{keyword}{KWD}{Keywords:}, imsart.sty’s \setpkgattr{keyword}{MSC2020}{…}; the caller sets the headings and \sep, or the class file it reads after does). The blocks add up, as the classes keep each (arxbj’s and imsart’s \keyword@box, arximspdf’s \keyword@toks): a keywords block per {keyword}, and a block of a subject classification class — AMS, MSC, MSC2010, MSC2020 (imsart.sty:1521-1525, :2338-2341) — the paper’s classification under that scheme. Each \kwd had started the list afresh (elsart’s {keyword}: arxbj 1106.2467, 0811.0643 lost every entry; OmniBus’s \kwd, KNOWN_PERL_ERRORS #1196: imsart 1410.4462, 2407.13970, 2605.27137 kept only their last keyword) or a second block replaced the first (arximspdf’s: the AMS codes of 1107.3284 and 1309.4864), and imsart.sty’s own blocks set a box nothing typesets (the MSC codes of the three imsart papers). The classification’s scheme is its printed heading, edition included, without the closing “:” or “.” its name keeps (\lx@ims@scheme): the HTML shows the scheme as the classification’s heading, its name only when it has none (LaTeXML-structure-xhtml.xsl:239-240, as Perl’s), so the class key alone showed “MSC” where pdflatex prints “MSC 2010 subject classifications:” (1410.4462) or “MSC2020 subject classifications.” (2605.27137, 2407.13970), as the AMS classes’ \subjclass gives “2020 Mathematics Subject Classification”. A class without a heading for the key (arxbj’s class=MSC) keeps the key. Needs keyval.
