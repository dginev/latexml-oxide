pos.sty (SISSA Medialab’s PoS template, v2.1 2018/11/13 and v2.2 2021/09/21, loaded under article): the papers ship the package (it is not in TeX Live), which is read raw, its title page made by the frontmatter. pos.sty keeps that page in stores only its own \maketitle prints (:450-530), which the kernel’s locked \maketitle refuses: the authors in expl3 sequences (:88-127 \RenewDocumentCommand\author{som}, which the kernel’s locked \author refused too, so \author*{Javier M. Duarte} read * as the name and the name as an affiliation), the affiliations and e-mail addresses in token registers (:411-430), the conference in a box (:364-369). Every one is the frontmatter’s here, defined before the copy is read, whose \newcommands of the same names are then ignored as those of any name LaTeXML defines (and its \NewDocumentCommand\onbehalf, :249). Perl has no binding: it does not read the package, keeps an empty name and raises an error for each \affiliation and \emailAdd (KNOWN_PERL_ERRORS #1198). Witnesses 2409.20413, 2512.14592, 2602.22379 (OXIDIZED_DESIGN_DIVERGENCES #904).
