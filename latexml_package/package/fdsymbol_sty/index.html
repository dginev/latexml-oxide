fdsymbol.sty — a math symbol font (Michael Ummels) for the symbols of amssymb and many more.

The package is not raw-loaded: its \fdsy@DeclareSymbol does \if\relax\noexpand#1\let#1\undefined\fi before each \DeclareMathSymbol (fdsymbol.sty:110-114), which left locked kernel math chars (\prime, \downarrow, …) undefined (2406.19499, 2411.08746). Perl has no binding, and with INCLUDE_STYLES off skips the package. The binding loads what fdsymbol.sty loads, defines the AMS symbols and alphabets it redeclares from amsfonts’ and amssymb’s bindings without loading either (fdsymbol.sty:194-195; \@ifpackageloaded{amssymb} stays false, and the AMS names it never declares stay undefined: NOT_FDSYMBOL), and its own symbols as Unicode: FDSYMBOL_SYMBOLS.
