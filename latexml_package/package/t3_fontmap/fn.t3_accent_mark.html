pub fn t3_accent_mark(slot: i64, place: AccentPlace) -> Option<char>
Expand description

The combining mark of T3 slot slot set place on a letter, the glyph tipadiac.mf/tipatone.mf draw there as t3enc.def:368-516 sets it: the tilde (3) above is U+0303, below (\~*, \textsubtilde) U+0330; the round cap (16) above is the inverted breve U+0311, below (\textsubarch, \u*) U+032F; the stroke of " (34) below is the syllabicity mark U+0329 (\textsyllabic, \s). None where Unicode has no mark: the subscript W set above (\textoverw).
