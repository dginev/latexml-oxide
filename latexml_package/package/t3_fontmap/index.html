T3 font encoding: tipa’s IPA fonts (tipa10 …, t3enc.def, FUKUI Rei).

Each slot decodes to the glyph the tipa fonts draw there — tipa.mf’s driver and its parts, whose cmchar names identify the glyph (tipadiac.mf accents and diacritics 0-31 and the marks at 34-38, 58-62, 92-95, 126-127, 152-159, 189-191; tipapnct.mf punctuation; tiparoml.mf letters; tipasym1-4.mf, tipagerm.mf, tipasc.mf IPA letters; tipatone.mf tone letters 128-151) — as the IPA letter Unicode has for it, by t3enc.def’s command names (\textschwa 64, \textesh 83, \textltailn 241 …), cross-checked against tipauni.sty’s Unicode table (TL tipauni 0.7a: \textltailn “272, the input letters @ ə, N ŋ, : ː …). The ASCII slots are tipa’s input convention (tipaman §3): digits, capitals and @ : ; " | are IPA letters, so \textipa{[D@"lIm@]} reads [ðəˈlɪmə]; g (103) is the single-storey ɡ (\textscriptg), the two-storey g is \textg (165). The fonts’ ligature program (tipa10.tfm LIGTABLE, tipa.mf:66-67) makes "" the secondary stress ˌ (127) and || the double pipe ǁ (123): t3_ligature.

Where the glyph the font draws and its IPA meaning differ, the slot is the IPA meaning, as tipauni.sty maps it (user ruling 2026-10-20): ! the alveolar click ǃ, & ɞ, \textcorner U+031A, \textsubbar U+0320; the open corner, which tipauni.sty does not map, stays ˹.

An accent slot holds the combining mark it is set as (decoded alone on a no-break space, the Perl fontmaps’ shape), or the spacing accent where T1 has one (0-12); t3_accent_mark gives the mark above or below a letter that t3enc.def’s \upper@accent/\lower@accent set it as (t3enc_def.rs). Slots with no Unicode character — the tone letters’ parts 128-145 and stem 191 (tone.sty assembles them; tone_sty.rs maps \tone{51} to ˥˩), the Celtic palatalization mark 32, the hooktop 35, the Viby and left-hooktop long letters 166, 167, 182, 183 — decode to nothing, and a text symbol at one warns where it is used (\lx@unmapped@text@symbol, sect08.rs).

Perl has no T3 map: tipa’s symbols printed nothing and \textipa’s input letters decoded as OT1 (“D@“lIm@” for ðəˈlɪmə). OXIDIZED_DESIGN_DIVERGENCES #781. Witnesses 1802.05444, 2405.01972 (\textipa{\textltailn} ɲ, \!b ɓ).

t3_accent_mark
The combining mark of T3 slot slot set place on a letter, the glyph tipadiac.mf/tipatone.mf draw there as t3enc.def:368-516 sets it: the tilde (3) above is U+0303, below (\~*, \textsubtilde) U+0330; the round cap (16) above is the inverted breve U+0311, below (\textsubarch, \u*) U+032F; the stroke of " (34) below is the syllabicity mark U+0329 (\textsyllabic, \s). None where Unicode has no mark: the subscript W set above (\textoverw).
