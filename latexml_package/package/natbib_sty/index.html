natbib_invocation
cs re-invoked over a natbib citation’s arguments as they were read: a present note is […] even when empty, which natbib’s commands tell from an absent one (swap_pre_post), and a post-note given without a pre-note has an empty one before it. Invocation! reverts an empty optional argument to nothing, as Perl’s Optional reversion does (Base_ParameterTypes.pool.ltxml:55-62): \citealt[e.g.][]{k} became \citet[e.g.]{k}, its pre-note the post-note (KNOWN_PERL_ERRORS #868; natbib.sty:702-730 passes both to \NAT@citetp). The bindings that delegate to natbib (apacite’s \cite<pre>[post], nmbib’s \citeall) re-emit their notes through it too.
natbib_merge_citations
natbib.sty:1135-1160 \NAT@star@cite, with \NAT@merge above zero (the mcite, merge and elide options, :272-274, at level \@ne, \tw@, \thr@@; revtex4-1.cls:7046 and revtex4-2.cls:7067 \let\NAT@merge\thr@@): a key written *key in a citation’s list is key. Perl’s natbib binding never merges, and cites the key “*b”: “missing citation” (1808.00247; KNOWN_PERL_ERRORS #1081). Guard perfect_kernel_batch78n::revtex_merged_citation. A residual: natbib also merges the entry into the one before it in the bibliography (\NAT@b*@key, :1160, read by its \bibitem, :841-860), so the citation prints the one number “[1]”; here the entry stays its own, “[1, 2]”. mcite and the classes set the level; merge and elide only raise it (natbib.sty:273-274 \@ifnum{\NAT@merge<\tw@}{\let\NAT@merge\tw@}{}), so [elide,merge] stays at elide’s: raise_only.
