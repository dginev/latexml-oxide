TU font encoding (tuenc.def): the encoding of the Unicode engines, whose slots are Unicode code points. fonttext.ltx:57-68,93 makes it the default encoding of a LuaTeX/XeTeX format, and the luatex/xetex profiles select it (latexml_sty install_unicode_format_encoding). Without a map \lx@fontencoding falls back to OT1 (TeX_Fonts.pool.ltxml:169-175), so \char{printed OT1's en dash and a typed<its inverted exclamation mark (nlctuserguide's\marg`, glossaries-user under lualatex: “\name{first-name}{surname}”).

The format’s Latin Modern fonts load with TeX ligatures (tuenc.def:60 +tlig;, :100 mapping=tex-text;; tulmr.fd, tulmss.fd): " ' ` become ” ’ ‘, and the ligature rules (tex_fonts.rs) build “ ” – — ¡ ¿ from them. The typewriter fonts load without (tulmtt.fd), so their map is the identity. Control slots (C0, DEL, C1) have no glyph.
