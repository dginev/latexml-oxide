Module float_description 

Source
Expand description

The accessible description of a float’s image (acmart’s \Description[short]{long}, oup-authoring-template’s \figalttext[short]{long}): a hidden note in the float’s caption, which the lone image takes as its @alt or aria-describedby. Shared by the class bindings whose classes carry such a command (acmart_cls, oup_authoring_template_cls).
