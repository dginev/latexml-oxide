pub fn shipped_class_text(binding: &str) -> Result<Option<String>>
Expand description

The text of the class file requested_shipped_class finds, its bytes read as Latin-1 characters; None when the source does not have it or it cannot be read (so a family binding takes its no-copy choices). A family binding reads the copy the paper ships to follow its version where the versions conflict (mn2e_cls, mdpi_cls, jfm_cls). A copy the document writes with {filecontents} is read where the dependency scan reads it, from the virtual files (require_dependencies_only).
