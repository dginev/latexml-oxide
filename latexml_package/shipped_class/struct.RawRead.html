Expand description

A file a binding reads raw — a TeX Live class or package, or an author’s class the paper ships — with the binding’s adjustments, each placed where the file defines what it adjusts (read_raw). One declaration per binding, so the read, the no-copy fallback and the order of the adjustments cannot drift between bindings.

Fields§

§name: &'a str

The file’s name, without its extension (pasa; a family binding’s, chosen as it loads: compositio).

§ext: &'static str

Its extension (cls, sty).

§shipped: bool

An author’s class, not in TeX Live: read from the paper’s copy (requested_shipped_class); without one the document gets OmniBus and the missing-file warning, as for any class the paper names and lacks.

§held: &'static [(&'static str, &'static str)]

(cs, definition): held while the file is read — definition (TeX) replaces the meaning of cs, locked against the file’s own definition — and the meaning before returns after it (pasa.cls’s era \@popfilename).

§restored: &'static [&'static str]

Meanings the file overrides with copies of an older kernel’s: left to the file while it is read (its own code may need them), and the meaning before restored after it (pasa.cls’s era \@pushfilename).

§setters: &'static [(&'static str, &'static str)]

(setter, body): a store the file defines (\aaabstract), redefined after the read to body, a frontmatter API call with #1 the setter’s argument (the body grammar of K11’s STORE_SETTERS) — only when the file defines it.

§after: &'static str

TeX run last, for what the declarations above do not cover.
