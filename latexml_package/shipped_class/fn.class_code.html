text without its comments (% to the end of the line). A line ends where TeX Live’s TeX ends it, at a carriage return, a line feed or the pair: a copy saved with classic Mac line ends (23 of the census’s 164 sn-jnl.cls: 2609.04047’s, 2106.13602’s), which pdflatex reads line by line (2609.04047’s “Table A1”), was read here as one comment, and none of the code a binding looks for in it was found.
