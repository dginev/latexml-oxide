Shared helper: the shipped class file a class-family binding reads or inspects (compositio_cls, jinst_cls, mn2e_cls).

Structs§

RawRead
A file a binding reads raw — a TeX Live class or package, or an author’s class the paper ships — with the binding’s adjustments, each placed where the file defines what it adjusts (read_raw). One declaration per binding, so the read, the no-copy fallback and the order of the adjustments cannot drift between bindings.

Constants§

ALGORITHM_PACKAGES
The algorithm packages, whose choice differs between copies of one class or package: the ICML styles load algorithm and algorithmic (icml2016.sty:70-71 … icml2025.sty:95-96) and papers edit algorithmic out for algpseudocode (icml2024.sty:94 “removed due to conflict with algpseudocode”, 2402.05403); WileyNJD-v2.cls:3331 and WileyNJDv5.cls:6820 load algorithm, algorithmicx, algpseudocode, a copy algorithm2e (2002.02812); bmvc2k.cls algorithm with algorithmic (2002.09958:132-133) or with algpseudocode (2210.06270:139-142).
SUBFIGURE_PACKAGES
The sub-figure packages, whose choice differs between copies of one class: bmvc2k.cls loads \RequirePackage{graphicx,subfigure} (1507.05726’s copy:121, 54 of 60 sampled copies), a copy {graphicx,subcaption} (2110.13859:133, 1311.3715:117), \usepackage{caption,subcaption} (1709.02848:135) or \usepackage{subfig} (2107.03463:150) instead; loading one a copy replaced clashes with the paper’s own (subfigure and subcaption both define {subfigure}).

Functions§

class_code
text without its comments (% to the end of the line). A line ends where TeX Live’s TeX ends it, at a carriage return, a line feed or the pair: a copy saved with classic Mac line ends (23 of the census’s 164 sn-jnl.cls: 2609.04047’s, 2106.13602’s), which pdflatex reads line by line (2609.04047’s “Table A1”), was read here as one comment, and none of the code a binding looks for in it was found.
class_code_argument
The braced argument of the first call in text (a class file’s) outside a comment that is followed by one, its braces balanced: the default a copy gives a setting command (sn-jnl.cls’s \def\interntxt#1{…}\interntxt{Work done as an intern at Westlake University.}, 2606.24824’s copy :598).
class_code_contains
Does text (a class file’s) contain needle outside a comment? (mdpi.cls’s \begin{paracol} in its \AfterEndPreamble, which a copy may have commented out.)
class_option_given
Does the document’s class option list (\@classoptionslist) name option? For a class option a binding that does not process its options reads (ieeeaccess’s jtehm).
class_options
The document’s class options (\@classoptionslist) in the order given, for a binding that reads them as its class does rather than in the order they are declared (REVTeX’s journal, revtex4_support_sty::selected_journal).
class_text_loads
Does text (a class file’s) load package with \RequirePackage/\usepackage outside a comment, alone or in a list (\RequirePackage{graphicx,epstopdf}), its options spanning lines or not (aa.cls’s \RequirePackage[colorlinks=true,⏎ linkcolor=blue, …]{hyperref})? A load inside a conditional or a hook (\IfFileExists, \AtBeginDocument) counts; \RequirePackageWithOptions does not.
omnibus_without_copy
A stand-in binding’s answer when the source lacks the class it reads raw (requested_shipped_class is None): OmniBus, with the loader’s missing-file status and missing_file Warning for a class it has no binding for (load_class; Perl Package.pm:2717-2728), which the binding’s presence kept the loader from raising — pdflatex stops on the missing file. Not again for a request the prefix fallback answered with this binding: the loader warned for it. an.cls (astro-ph0611016), cimento, compositio, jinst, the apa family.
provide_shipped_aas_macros
The astronomical journal abbreviations (\apj, \mnras, \aap…), aas_macros.sty pasted into individual copies of a class whose releases have none: aas_macros’ binding provides them where the paper’s copy of binding defines them, and only the names still undefined (ProvideOnlyGuard), so a paper’s own definition stays its own. elsarticle (0812.4232 \def\apj{ApJ}, 1504.02326, 1807.02064 \newcommand*\apj{ApJ}, 2003.05953, 2401.03908 \newcommand\mnras{\ref@jnl{MNRAS}}), PoS (16 of 92 copies: 0810.0108, 1212.1356, 1708.06808, 1802.02766), svmult (0803.2826, 1801.09940’s svmult_aa.cls), svjour3 (0811.4367, 1111.3868) and mdpi (Definitions/mdpi.cls: 2005.05017, 2111.02495; 2510.22959’s mdpi_mod.cls).
read_raw
Read the file spec declares, raw, with its adjustments in their order: the held meanings in place and locked, the file, the held and restored meanings back to what they were before it, the setters the file defined redefined, then after. false when a shipped class is not in the paper’s source: the document then has OmniBus (omnibus_without_copy) and the binding stops there.
requested_shipped_class
The class file in the paper’s source that the family binding binding interprets: the class the document asked for when the loader answered it with this binding, else the binding’s own name; None when the source does not have it. The request is the fallback’s (fallback_request, when its fallback_target is this binding: a renamed JINST_mod or myJINST, 1307.5525, 1407.3938, and a path-prefixed request loaded as its basename’s binding, JINST-Sample-files/JINST, whose class is in a subdirectory: 1504.01965, 1410.4420, 1805.09245; load_class), or the load’s own \@currname when it names the binding with a directory (the raw load of a basename-keyed package binding resolves its directory the same way, input_definitions).
require_shipped_algorithm_packages
A binding standing in for the class or package being loaded — as the paper asked for it: the load’s \@currname, or the request a versioned fallback answers with this binding (fallback_request while its fallback_target is the binding: icml2026, ./icml2018 → icml.sty, 1706.04964) — leaves the algorithm packages to the paper’s copy of that file: those of ALGORITHM_PACKAGES the copy loads are required in its order with its options (Perl’s dependency scan, Package.pm:2776-2813, kept to that family: require_dependencies_only). false when the source has no copy, so the binding takes its own default. Algorithmicx’s \State stays undefined when a stand-in loads algorithmic, which bails algorithmicx (algorithmicx.sty.ltxml:9-12), where the paper’s copy loads none (icml 1706.03643, 2002.06473, 2106.05074), and {algorithm} when it omits the class’s own (WileyNJD-v2 1810.03033, 2106.06046; bmvc2k 2210.06270).
require_shipped_packages
require_shipped_algorithm_packages for any such family of packages whose choice differs between copies of the file a binding stands in for: those of family the paper’s copy loads are required in its order with its options; false when the source has no copy.
shipped_class_loads_or
Does the paper’s copy of the class binding stands in for load package (class_text_loads)? default when the source has no (readable) copy — the class as distributed. For a package without a binding, which the dependency scan (require_shipped_packages) does not load: the binding requires it itself, raw.
shipped_class_text
The text of the class file requested_shipped_class finds, its bytes read as Latin-1 characters; None when the source does not have it or it cannot be read (so a family binding takes its no-copy choices). A family binding reads the copy the paper ships to follow its version where the versions conflict (mn2e_cls, mdpi_cls, jfm_cls). A copy the document writes with {filecontents} is read where the dependency scan reads it, from the virtual files (require_dependencies_only).
shipped_copy_loads
Does the paper’s copy of the file a stand-in binding answers (shipped_copy_text) load package (class_text_loads)? false when the source has no copy: versions of one class differ (sn-jnl.cls, ws-procs9x6.cls load amsmath in some copies, not in others; amsmath_sty::require_amsmath_beyond_original).
shipped_copy_text
The text of the paper’s copy of the file a stand-in binding answers (require_shipped_packages’s request: the load’s \@currname, or the request a versioned fallback answers with this binding), read as shipped_class_text reads a class; None when the source has no copy. The ICML styles read the notice strings a copy edits (\ICML@appearing: 2606.28747’s “3rd AI for Math Workshop”, 2604.14572, 2507.02987, 2506.09099).
shipped_file_loads
Does the paper’s own file of type ext (not a binding) load package (class_text_loads)? false when the source has none: for a file read by \input, which has no \@currname of its own (shipped_copy_loads): Scientific Word 5.x’s tcilatex.tex loads amsmath (2212.12000’s :851), 2.5’s does not (0805.4522’s).
shipped_file_text
The text of the file file of type ext in the paper’s source (not a binding), its bytes read as Latin-1 characters, or the virtual file a {filecontents} wrote. A binding that serves every version of a generic file reads the copy TeX would load where the versions conflict (epsf’s size reset, epsf_sty).
