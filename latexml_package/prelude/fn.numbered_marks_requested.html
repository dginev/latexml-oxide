pub fn numbered_marks_requested() -> Result<bool, Error>
Expand description

Do the queued authors’ marks request numbered entries: each mark a comma list of numbers (\inst{1,2}), at least one, beside which only symbols stand — a legend’s \textsuperscript{\dag}, * (comsis2.cls’s names, 2207.09249), an empty piece (edpsci’s \inst{1,2}$^{,}$, 2501.08874), a command (a \ref{…} key, an unread name’s spelling) —, never a letter label (\inst{a}), which no number answers? The marks by printed text (queued_author_marks).
