§is_protected: bool§peeks_by_futurelet: bool

See Definition::peeks_by_futurelet: set by the kernel’s peeking closures, and for every macro whose leading argument is a \newcommand optional one (crate::parameter::Parameter::testopt).

§is_long: bool§checks_par: bool

tex.web §392/§399: reading this macro’s arguments, a \par token ends the call — “Paragraph ended before \x was complete” (§396). Only a non-\long macro whose long-ness is TeX’s (tex_declared, made at a Format, File or Document origin): LaTeXML’s own DefMacro!s are non-long without meaning it (Perl stores isLong and never reads it, Expandable.pm:46), so they are not checked. A \let copy keeps it (the meaning carries the long-ness). Witness 1001.1670; guards scanner_status::a_par_*, DIVERGENCES #442.

§plan: OnceCell<Box<[BodyPiece]>>

The token-list body’s Tokens::substitution_plan, built at the first call that substitutes.

§dropped_by_design: u16

The arguments the binding declares this macro drops by design (ExpandableOptions::drops), bit n for #n. Not part of the meaning (PartialEq).

§made_in_own_file: bool

Made while a raw class or a raw file of the document’s own directory was read (crate::definition::origin::reading_own_file), which the title-page check’s third source reads (Self::watched_call). Not part of the meaning (PartialEq).

fn peeks_by_futurelet(&self) -> bool

Whether this macro peeks at the next token the way latex.ltx’s \@ifnextchar does (1756-1760): by \futurelet, behind an unexpandable \let. A number scan (tex.web §445) ends at such a macro instead of expanding it (see gullet::expands_now). A binding closure that makes an assignment as it expands carries it too when its TeX original reaches an unexpandable token (\begingroup, \let, \relax) before it acts: etoolbox’s \newrobustcmd and \patchcmd, amsthm’s \pushQED.
