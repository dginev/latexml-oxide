Source
Expand description

Definition provenance — K1 of the generalized kernel-capability program (docs/perfect_kernel/KERNEL_CAPABILITIES.md).

Every definition records WHO made it: LaTeXML’s own layers (the format dumps, the Rust pools, a compiled binding, the raw format files) or the document’s world (a raw .sty/.cls/.def the document loaded, or the document itself). The origin is captured at construction from a thread-local set by the loader seams, the same moment a definition’s locator is, and travels with the object through \let.

Its first consumer is the l3/ltcmd “already defined” leniency (\lx@if@pooldefined): real LaTeX keeps \section, \thepage, {figure}… in article.cls, our pool pre-defines them for class-less robustness, so a standalone class redeclaring them is not an error — while a genuine double declaration between two raw files still is.

Structs§

CopyProvidesGuard
RAII form of enter_copy_provides/leave_copy_provides, for a Rust-bracketed scope (the copy’s read, a nested load’s suspension).
OriginGuard
RAII guard: definitions made while it lives carry origin; the previous origin is restored on drop (loaders nest: a binding raw-loading its .sty yields File for that file’s definitions and Binding for its own).
ProvideOnlyGuard
RAII guard: while it lives, a load only provides — a binding’s definition (the fallback class OmniBus, or any binding it requires) of a name defined before the guard began is dropped, as a \providecommand of it is (state::provide_only_declines); the previous mode is restored on drop.
StandInLoadGuard
RAII guard: while a binding that stands in for an author’s file loads (binding::content::input_definitions), every name assigned is recorded as that binding’s (state::State::stand_in_meanings), whatever made it — its DefMacro!s, its Let!s and RawTeX, the bindings it requires — so the paper’s copy read after it only provides them (state::note_copy_provides_assignment). The names its own code assigns, not a file it loads (StandInLoadGuard::suspend: OmniBus, natbib, a nested stand-in’s own), are also its command set (state::State::stand_in_last_load), which the copy must define to be the file the binding stands in for (binding::content copy_is_the_stood_in_file).
