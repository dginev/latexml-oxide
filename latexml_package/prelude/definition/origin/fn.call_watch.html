pub fn call_watch() -> Option<bool>
Expand description

What a macro’s call must be for one of the watches on to see it, read at every macro call: None when no watch is on, Some(true) when only watch_document_calls’ and watch_store_calls’ are, which see only a macro with parameters that LaTeXML or a raw class’s own file made. Those two stay on from a conversion’s start until its title page, or to its end in a document with none, so a package’s macro calls in the document’s text would otherwise all pay for the watch’s cold path.
