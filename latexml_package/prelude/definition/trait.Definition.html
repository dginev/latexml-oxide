fn invoke_onto_input(&self, once_only: bool) -> Result<(), Error>

Expand onto the input: Self::invoke’s result pushed back with crate::gullet::unread_expansion, as the gullet’s macro expansion does. An expandable with a token-list body substitutes its arguments straight onto the input instead (tex.web §390 macro_call).

fn native_expansion(&self) -> Result<Option<Tokens>, Error>

expandable::SpecialCall::Native, for a call the gullet expands in full: only there, so a one-step \expandafter and every other reader of the expansion get the macro’s own body.

fn declared_mode(&self) -> Option<DeclaredMode>

The mode transitions the binding declared (DeclaredMode); None for definitions not made by a definer that takes mode options (macros, registers, raw-TeX definitions, a primitive built by hand). The audit reads None on a primitive or constructor as declaring nothing.

Source

fn declared_font(&self) -> Option<&FontDirective>

The font a primitive or constructor was declared with (its font => {…} option), which its digestion merges into the current font; None for every other definition. latex.ltx’s \@fontswitch reads a math alphabet as a switch to the group’s end (\mathrm\relax with \math@bgroup let to \relax, latex.ltx:14312-14321): the binding’s switch merges this font (\lx@math@alphabet@switch, latex_constructs/sect13.rs).

Source

fn replacement_template(&self) -> Option<&'static str>

The literal XML template that is a constructor’s whole construction: its replacement’s source (DefConstructor! with a string replacement), when no construction hook (before_construct, after_construct) adds to it. None for a closure replacement, a constructor made at run time and every other definition: what it builds cannot be read off it (the frontmatter’s no-ink test, latexml_engine util_text.rs first_ink, counts such a whatsit as ink).

fn peeks_by_futurelet(&self) -> bool

Whether this macro peeks at the next token the way latex.ltx’s \@ifnextchar does (1756-1760): by \futurelet, behind an unexpandable \let. A number scan (tex.web §445) ends at such a macro instead of expanding it (see gullet::expands_now). A binding closure that makes an assignment as it expands carries it too when its TeX original reaches an unexpandable token (\begingroup, \let, \relax) before it acts: etoolbox’s \newrobustcmd and \patchcmd, amsthm’s \pushQED.
