pub fn digest_in_own_group<T>(
    digestion: impl FnOnce() -> Result<T, Error>,
) -> Result<(Result<T, Error>, isize), Error>
Expand description

Runs digestion in a group of its own, as a text built ahead of its use and not read from the document: a tag a reference prints (latexml_engine tags_refnums.rs \lx@tag@intags@held), a form cleveref typesets only at a reference (latexml_package cleveref_sty.rs \lx@cref@docformat), whose text need not close what it opens — the derived \Cref format \MakeUppercase#2\color{blue}…, whose \MakeUppercase takes \color alone (2008.12750, 2604.24399). Whatever the digestion leaves is undone, so the document reads on as it was: the groups it left open are popped as abandon_stack_frame pops one, their \aftergroup discarded, but not counted as an abandonment, and the group is closed; the alignment brace count (tex.web’s align_state, §789) is put back, as the { such a text scanned is not the document’s — left counted, a figure’s tabular of two captioned minipages read its next & as text and moved the following cell into the row above (“Missing } inserted”, “Extra alignment tab”; guards perfect_kernel_batch78j::cleveref_format_form_keeps_the_alignment_brace_count, ::cleveref_format_form_keeps_an_alignment_row_end). Returns the digestion’s result and the group balance: the groups it left open, or, negative, how many it closed that it did not open.
