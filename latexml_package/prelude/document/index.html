ABSORB_WARNING_LOCATOR_PROPERTY
The source position, recorded at digestion, at which a constructor’s ABSORB_WARNING_PROPERTY Warning is raised: the gullet’s as the constructor’s arguments are read (core dialect::transfer_common_constructor_options), the position a Tbox carries as its locator. A whatsit’s own locator is set only under --source-map.
ABSORB_WARNING_PROPERTY
The box property of a Warning that belongs to the box’s print, not to its digestion (absorb_warning): raised when Document::absorb takes the box (a Tbox or a whatsit) into the document, once per key. A box digested and never absorbed — measured (\settowidth), saved and never used (\sbox), made by a rehearsal or a speculative digestion, or under a DiagnosticsHold it discards — raises nothing and leaves no key set, so the box the document prints still raises it. An undecodable math glyph’s once-per-font Warning (latexml_engine sect08.rs undecodable_math_slot, OXIDIZED_DESIGN_DIVERGENCES #27).
FIELD_BOX_ATTRIBUTE
The bookkeeping attribute (stripped at finalize, as every _ attribute) of the element a TeX box’s constructor opened for its material (Document::mark_field_box).
FIELD_BOX_PROPERTY
The whatsit property of a TeX box’s constructor (OXIDIZED_DESIGN #715), set where it is digested while field ink is recorded (field_box_whatsit): a constructor whose declared mode is restricted_horizontal outside math (\hbox, \mbox, \makebox, \raisebox, \fcolorbox, \scalebox/\resizebox/\rotatebox/\reflectbox, core Constructor::digest_to_whatsit), \framebox/\fbox (its text branch), an environment whose begin code opens a box group (a minipage, dialect::def_environment). Document::absorb marks the first element its constructor opens (FIELD_BOX_ATTRIBUTE), before it absorbs anything; one that opens none marks nothing.
FIELD_FORMULA_START_PROPERTY
A formula’s first position in a field, under a rehearsal’s notes only (the engine’s field_notes): the opening shift’s, its box stamped by the closing one, whose invocation built it.
FIELD_MARK_TARGET
The target of the processing instructions marking a run of a frontmatter field’s ink (FieldRun): construction-time scaffolding, never in the output (the engine’s frontmatter placement removes them; the finalize drops a stray one).
FIELD_PROV_PROPERTY
The box property holding the field provenance of the token a box or whatsit was digested from (the stomach sets it, invoke_token; Token::prov).
FIELD_SERIAL_PROPERTY
The box property holding the serial of the box’s cover in the field ledger (field_ledger_push: its own position, the arguments its invocation consumed, a boxless font switch before it).
FIELD_TAKEN_PROPERTY
The box property of an alignment’s whatsit holding the field-ledger serials of the row-end markers its body consumed (a field value’s \\, field_ink_taken_serials): taken when the document absorbs the whatsit.
RAW_REFSTEP_MARK
The bookkeeping attribute (dropped at the end, as every _ attribute) on an object a raw counter step numbered: the step’s serial (Document::take_raw_refstep_number, OXIDIZED_DESIGN_DIVERGENCES #813).

It does not wait for a field to be stamped: a header box may be digested before the document declares its \title (fms1 round-6 review finding 1); Document::mark_field_box applies the stamp at absorb time.

field_ink_taken_serials
The field-ledger serials of the boxes in digested (an alignment’s row-end marker, a value’s \\, latexml_engine digest_alignment_body), pushed onto serials: the structure the print is set in consumes them, never absorbed. The alignment keeps them on its whatsit (FIELD_TAKEN_PROPERTY), and they are noted taken (field_ledger_take) only when Document::absorb absorbs that whatsit, so the run of ink the row ends may cover them and no other run does; an alignment never shown (in an unused \setbox, \sbox, {lrbox}) takes nothing (OXIDIZED_DESIGN #715; review r4 finding 2, probes s25, s27, s28).
