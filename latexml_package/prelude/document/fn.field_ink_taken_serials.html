pub fn field_ink_taken_serials(digested: &Digested, serials: &mut Vec<u32>)
Expand description

The field-ledger serials of the boxes in digested (an alignment’s row-end marker, a value’s \\, latexml_engine digest_alignment_body), pushed onto serials: the structure the print is set in consumes them, never absorbed. The alignment keeps them on its whatsit (FIELD_TAKEN_PROPERTY), and they are noted taken (field_ledger_take) only when Document::absorb absorbs that whatsit, so the run of ink the row ends may cover them and no other run does; an alignment never shown (in an unused \setbox, \sbox, {lrbox}) takes nothing (OXIDIZED_DESIGN #715; review r4 finding 2, probes s25, s27, s28).
