The stand-in LaTeXML reads for an undefined token, if one is named (name_undefined_fallback): the name stays undefined — \ifdefined, \@ifundefined and \meaning see what TeX sees — and a use of it reads the stand-in, which is responsible for saying that TeX errs there. The class-less \chapter is the one named (OXIDIZED_DESIGN #734, latexml_engine supply_chapter_fallback). Asked at the two undefined-CS sites, after try_autoload and try_refused_environment_definition: Some ⇒ read the stand-in in place of token.
