pub fn record_load_as_the_files_own(file: &str)

A compiled binding’s load of file that the real file it stands for makes too (elsarticle.cls:1243, acmart.cls:300, jmlr.cls:150, jheppub.sty:37): the file’s own, so a document’s later repeat with other options is LaTeX’s “Option clash” (apply_repeat_options). The binding records it only where the paper ships no copy of that file or one that makes the same load (shipped_class::shipped_copy_makes_load): a copy loading it otherwise or not at all leaves the binding’s early load, and the document’s options apply (elsarticle.cls copies: 2105.06643 [authoryear], 2206.02837 none, 2402.13480 [numbers,sort&compress]; 2209.10785’s cidr.cls, an acmart.cls copy without natbib).
