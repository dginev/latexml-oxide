pub fn drop_cover_title_ink(document: &mut Document, scope: &Node)
Expand description

The class’s own printing \title run on a cover inside scope (sect05.rs titlepage_class_run): everything that lies between each pair of cover-title marks in document order — elements and bare text (\def\title#1{#1} in the cover’s open paragraph) — removed with the marks, and the wrappers it leaves empty (a center’s paragraph). Called where a {titlepage} stops standing in for the document’s <ltx:title>, so the HTML displays that title (LaTeXML-structure-xhtml.xsl:374-375 hides it only beside an ltx:titlepage): \unwind@titlepage (a \maketitle inside the cover), demote_stranded_titlepage, and settle_cover_title_ink. An unmatched mark is removed alone. OXIDIZED_DESIGN #629.
