pub fn unmarked_by_document(file: &str) -> bool
Expand description

Has the document unloaded file (amsthm.sty), which a class binding marked loaded on its class’s behalf, by letting its \ver@<file> to \relax or \undefined? LaTeX’s loaded test is that macro (latex.ltx \@ifl@aded: \expandafter\ifx\csname ver@#2.#1\endcsname\relax, true for both), which a binding load defines (content.rs, Perl Package.pm:2326). The rule is narrow, as floatrow’s marks are (user ruling 2026-10-14: no general loader \ver@ rule; floatrow_sty.rs): only a file a binding recorded as <file>:class_marked — ams_support_sty.rs for amsart’s \@namedef{ver@amsthm.sty} (amsart.cls:41-42; amsproc, amsbook alike) — is so taken back; every other file keeps the loader’s own record. The amsart idiom is \expandafter\let\csname ver@amsthm.sty\endcsname\relax before \usepackage{amsthm} (1510.08833, 1704.05671, 1707.00258, 1611.00843, 2106.07418, 2304.10644). Perl’s loader reads only <file>_loaded (Package.pm:2327-2329), KNOWN_PERL_ERRORS #720.
