The scope of a binding’s AddToMacro: global (Perl Package.pm:2545-2547), except in a package loaded inside a standalone subfile bracket (OXIDIZED_DESIGN #63/#65), where the package’s own definitions are local to the bracket: a global addition outlived them, and every later table of the main document called xcolor’s undefined \@xcolor@tabular@before (2512.09430; Perl the same, KNOWN_PERL_ERRORS #614). The addition then lives as long as the package does — and as in pdflatex, where standalone.sty skips the sub-file’s preamble, the main document’s tables carry no hook of a package only a sub-file loaded.
