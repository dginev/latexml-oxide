Push EXPANSION OUTPUT (macro bodies, conditional-branch replays, \the results) to the start of the token stream WITHOUT touching the alignment brace ledger.

tex.web distinguishes two insertion flavors: back_input (§325) RETRACTS align_state for a brace token because that token was already counted when scanned (get_next §342-344 counts every scanned brace, token lists included §357); begin_token_list — how an expansion enters the input — adjusts NOTHING, because expansion output was never scanned and its braces will be counted when they are. Retracting never-scanned braces here is not merely a transient skew: expl3 brace-tricks (\if… { \else: } \fi: under \exp_after:wN, the l3tl replace machinery) legitimately push UNBALANCED fragments whose skipped half was counted by the conditional skipper — the Perl-style retract-everything protocol (Gullet.pm L343-358, which Perl LaTeXML still has) then drifts ALIGN_STATE permanently negative and every later & in the alignment goes stray (l3doc {function} manuals; repro: \tl_greplace_all:Nnn + a protected macro emitting & inside a tabular cell). See cluster_package_guards::alignment_ledger_expansion_pushback.
