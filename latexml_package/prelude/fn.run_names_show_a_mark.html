Do the names of the run an affiliation continues request affiliations by their marks — a mark a name prints, as digested (queued_author_marks: Ann Able$^{1}$, \textsuperscript{1}, a document macro’s), that is no footnote symbol (Ann Able$^{*}$, the corresponding author’s, requests none)? The run is the authors queued before the affiliations that end the queue, back to the affiliation before them. AASTeX 5’s \altaffilmark{1} requests an \altaffiltext (label altaffil:1), no affiliation: a line its number labels goes by it (aas_support_sty.rs \affiliation, leading_line_label), and an unlabelled line stays with the row (user ruling R1, 2026-11-01: 1210.4079’s Pavel\altaffilmark{1} and D. P. Clemens over two \affil lines of one address). A binding whose group rule is annotate=run declares annotate=new for a run whose names do request affiliations, as a convention may not give them an unlabelled line as a group (1202.0629’s $^{n}$ names over unnumbered lines; aas_support_sty.rs).
