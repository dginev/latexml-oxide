Generic support layer for any LaTeXML package binding file.

Re-exports latexml_engine::prelude::* (the shared macro layer + latexml_core re-exports) and adds package-specific symbols that are only meaningful at the binding layer (crate::package::*, GetKeyVal constructor helper).
