pub fn leaves_no_ink(d: &Digested) -> bool
Expand description

Whether digested material prints nothing: every item in it is one known to leave no ink (first_ink finds none). The inverse of typesets_content, failing safe: what is not known to print nothing is ink. A frontmatter note is dropped as one with no ink only on this test, the XML’s (frontmatter_api.rs) and the frontmatter observer’s (the rehearsal’s note event, Event::inkless) alike (OXIDIZED_DESIGN_DIVERGENCES #916): a false “no ink” loses the note’s content, a false “ink” keeps a blank note.
