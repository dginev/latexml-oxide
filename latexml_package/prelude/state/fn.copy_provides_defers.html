pub fn copy_provides_defers(seam: &str) -> bool

Does a stand-in’s copy, read now, defer code to the document through seam (\AtBeginDocument, \AtEndDocument, etoolbox’s \AtEndPreamble/\AfterEndPreamble/\AfterEndDocument, lthooks’ \AddToHook)? Then the code is not registered: it is the class’s or style’s document-time machinery, which the binding has taken over — layout checks against the class’s page dimensions (icml2024.sty’s “The page layout violates the ICML style”, 2407.02750), validations of the class’s own setters the document called as the binding’s (PoS.cls “\abstract{…} should appear before \begin{document}”, 1001.3214; ieeeaccess.cls’s \EOD, 2007.03025; aipproc.cls’s \layoutstyle, astro-ph0105128), patches of the kernel’s \enddocument (aastex7.cls:459, whose \rvtx@enddocument@patch reads up to \@checkend and ran off the file: 2504.00922, 2605.15371, 2607.03848). On the 2026-10-17 census sample no Error was fixed by such code. Logged once per copy and seam, at Info.
