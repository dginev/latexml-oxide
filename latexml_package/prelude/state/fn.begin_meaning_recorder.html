pub fn begin_meaning_recorder() -> usize

Begin recording which meanings are assigned, each with its value before its first assignment since (end_meaning_recorder): what AssignmentJournalGuard::assigned reads of TableName::Meaning, without the journal — recorders nest, and a journal (a speculative run’s, a replay’s) may open and close inside one. Made for a displaced setter’s call (frontmatter_stores.rs \lx@displaced@begin), whose own code may run a speculative label read (queue_digest.rs speculative_label_ink: utarticle.cls:125’s \address prints its \@makeadmark{\@tempb}, 1209.6020). Kept in the state, so a document that stops inside a call leaves none to the next. Returns its depth: how many were open before it, which end_meaning_recorder_at closes it by.
