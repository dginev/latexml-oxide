pub fn begin_assignment_journal() -> Option<AssignmentJournalGuard>
Expand description

Begin recording what assignments change, to undo them all (AssignmentJournalGuard::rollback) or keep them (AssignmentJournalGuard::keep; also on drop, so a panic leaves no journal open): a transaction over the binding tables, of every assignment however scoped and of the in-place edits of the tables (push_value, assign_mapping, lookup_value_mut, checkout_value/checkin_value, named-scope activation, rebind_let_copies, the graphics path list), of a font’s parameter array (set_font_parameter, saved as a copy), an input stream’s mouth (input_stream_to_change) and a box register’s dimensions (journal_box_dimension), each edited in place, and of a name’s standing in the fallback-guess set (AssignmentJournal::fallback, FM S2a.2 r9: siamart’s \AND, 2409.10200). Not of what lives outside the tables: the provide-only and stand-in name sets, which change only while a package or class loads. Made for the replay of a refused frontmatter setter (sect05.rs replay_class_setter), which a setter that errs half-way must not leave half-done (jsty3-author.sty:542’s expl3 author list, which its printer then looped over: 2607.24171). None, recording nothing, while one is already open (journals do not nest); a journal its guard could not close (the state was borrowed when the guard dropped) is discarded here.
