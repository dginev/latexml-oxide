Does a routed copy, read now, \newcommand (or \providecommand) a declared text name (copy_text_name_declared) that LaTeXML’s code defined (owned as rule 1 tells, owned_by_the_semantic_layer) and no base class the copy \LoadClasses defines? Then the declaration defines it, as the real class’s first definition (proto.cls:798’s \abstractname, :1731 \newcommand\apj{\ref@jnl{\it Astrophys.\ J.}} over the aas_macros binding’s “ApJ”, 1402.7103; OXIDIZED_DESIGN_DIVERGENCES #731 rule 14); a name the copy’s base class has is LaTeX’s “already defined”, as before. Whether its definition stands for the document is decided when the copy’s read ends (leave_copy_provides_frame, copy_text_refusal).
