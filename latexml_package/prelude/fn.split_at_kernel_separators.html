pub fn split_at_kernel_separators(

Expand description

arg split as split_tokens_delimited splits it at delims, cut first at each kernel_separator_runs run: each segment between the runs split by spelling as it is, never a token rewritten (a run is cut where it stands, eptcs’s cells’ way), the segment a run ends keeping its last piece even when empty (split_tokens_segment: the split of the whole list keeps a piece a delimiter ends) and each segment’s first piece the run before it as its delimiter; and the number of runs cut that hold no delimiter of delims by spelling (split_tokens’ match, delimiter_token_matches): the cuts by meaning alone — a macro holding only \and, a \let copy of the kernel’s \and where the document renewed \and. A run is cut inside balanced parentheses too, which the spelling split protects, as TeX’s column break parts them (Univ A (North \myand South) after a document’s \let\myand\and), and a run the spelling also cuts is cut once. The spelling’s cuts in the segments stay, whatever their token means (a document’s renewed \and, an undefined \And: trap T8, the cut the split made before, which aa.cls’s own title-time \and keeps, aa.cls:866), as do its trimming and its protections inside a segment. Where the query reads nothing or finds no run, the spelling split of arg alone. Option C P2-2, P2-3 (OXIDIZED_DESIGN_DIVERGENCES #995): the \institute lists of inst_support (\lx@splitting@by@meaning), aa (aa_cls.rs \lx@aa@institute@dispatch) and llncs (llncs_cls.rs \lx@llncs@institute@dispatch), one contact call per piece, and llncs’s marked \author list (\lx@llncs@author@split), one author entry per piece.
