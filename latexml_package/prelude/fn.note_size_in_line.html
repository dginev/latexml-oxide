A note’s size in the line it sits in: its displayed mark (the mark property, or plain’s prenote), nothing without one — Perl’s \lx@note sizer => '#mark' (latex_constructs.pool.ltxml:460), which the port had dropped; extended to every note constructor (OXIDIZED_DESIGN_DIVERGENCES #391). The note’s text is an insertion, set out of the line (tex.web §1100 begin_insert_or_adjust; in the HTML a popup, .ltx_note_content display:none). Measured with its body, a note holding a \par added its paragraphs’ lines to the line; measured as its tags, it counted every registered tag form (cleveref’s six: a \resizebox of a tabular with a footnote shrank to half); a \footnotemark summed its arguments, the counter’s name included. Witnesses 2605.18427 S3.T4 (natural width 802.6 → 556.7pt, pdflatex 521.7), 2605.14713 S2.T1 (aa \tablefoot: innerwidth 2793.7 → 1644.8). Guard perfect_kernel_batch58::notes_measure_as_their_mark.
