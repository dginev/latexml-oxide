Material TeX writes out raw for a later run to print — an \index phrase (latex.ltx:17713-17726 \@sanitize and \protected@write to the .idx), a \nomenclature entry (nomencl.sty:208-219, the .nlo) — is typeset only when the document prints that list (\printindex, \printnomenclature); without one it is never typeset, and its errors are never TeX’s. defer_print keeps the entry’s tokens (already expanded as the write expands them) under a fresh id and returns that id for the anchor (\lx@deferred@print{id}, which marks the entry’s place); resolve_deferred_prints digests them when the list is printed, and the anchor absorbs what was digested. Witnesses 1112.3972, 2506.02168 (user ruling 2026-10-18).
