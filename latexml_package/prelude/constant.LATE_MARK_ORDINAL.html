The ordinal of a late abstract’s marker (\lx@frontmatter@mark, counted in LATE_MARKS), which the abstract its command adds carries too (queue_front_matter, frontmatter_push): the marker places its own abstract, and a command that added none (a repeat dropped, an empty body) places nothing. Internal, stripped from the output.
