pub fn run_cap_past_labels(role: &str) -> Option<usize>
Expand description

The cap a contact of role placed by its run (annotate=run:N) needs when a labelled contact of the role stands in that run: the kernel’s run reaches every author since the last contact it attached — a labelled one waits for its label and ends no run —, which gave a later unlabelled line every author since the run’s start (2608.19687’s \affil{$^10$…}, its $^10$ no mark a line reader reads, after the labelled \affil{$^8$…} and \affil{$^9$…}: every author since line 2); the line’s own run is the authors queued since the contact of the role before them. None when no labelled contact stands in the run (the kernel’s run is that).
