pub fn defined_cs(arg: &Tokens) -> Result<Option<(Token, Tokens)>, Error>
Expand description

The command a defining macro’s {\cs} argument names, read as TeX’s \def#1 reads it (get_r_token, tex.web §1215, skips spaces): its first non-space token, and the tokens after it, which a \def takes as its parameter text. An argument with no control sequence there is TeX’s “Missing control sequence inserted”: an Error, and None. The argument’s text, re-read as a prototype, made { \mathcal} and {\survey2011} Fatal on the parameter types mathcal and 2011 (witnesses 1810.09714, 1906.05222, 2011.04603, 2206.00709, 2209.01842; 1312.0976).
