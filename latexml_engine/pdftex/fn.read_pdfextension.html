LuaTeX’s \pdfextension <keyword> <operands> (LuaTeX manual, luatex-modifications.tex:592-907; luatex85.sty:69-92 defines pdfTeX’s \pdf<keyword> as it): each keyword’s operands are read as \pdf<keyword>’s, with LuaTeX’s additions (literal modes raw/text/origin, lateliteral, obj … uncompressed, outline useobjnum, linkstate; luatex-modifications.tex:611, :635). Read here, never through \pdf<keyword>, which luatex85 makes \pdfextension <keyword> again. An unknown keyword is an Error and stays text, as lualatex’s (extensions.c:312 tex_error("unexpected use of \pdfextension")). xfakebold-doc (pdfrender’s \pdfcolorstack) leaked “olorstackpop” text when only literal was known.
