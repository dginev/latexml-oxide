K11 — a raw class’s title-page STORES reroute to the frontmatter API.

A class loaded raw keeps its title page in stores: \newcommand\inst[1] {\gdef\@inst{#1}} (ptptex.cls:616), \long\def\abst#1{\long\gdef\@abst{#1}} (jpsj2.cls:841-847), read only by \@maketitle, which LaTeXML’s locked \maketitle never runs. Perl drops every such store (its ~200 class bindings — and the generic OmniBus.cls.ltxml:62-247 table, bypassed under raw class loading — are its only route); the Rust \lx@deposit@maketitle surpass typeset them as body paragraphs. This module is OmniBus’s table applied after the raw load, keyed on what the class actually defined — a setter a binding defined is the binding’s, even under a raw class that loads it (latexml_core::binding::store_setters): a setter is rerouted only when (a) its NAME is in the surveyed table (~/data/pk_agents/w23/frontmatter_stores/, 655 TL classes; an explicit synonym table, never a name pattern — ead matches \setoddhead, date matches \cref@updatelabeldata) and (b) its macro BODY is a pure store of its argument (#1, or #2 of an [optional]{mandatory} setter) — a check on the tokens, never a guess. Everything else the class defined is left alone, but its contact setters that print their argument as a title-page line (reroute_in_place_contact_setters, after a raw class or package: OXIDIZED_DESIGN_DIVERGENCES #936); the kernel’s own locked \title/\author/\date/\thanks are not in the table. A store is handed to the API as it is set, except one that annotates a creator (an affiliation, address, e-mail, ORCID) or makes one (an editor, a speaker), which is read at \maketitle where the author list exists. The class’s \@maketitle is deposited with the handed stores read as empty (\lx@deposit@maketitle, sect05.rs), so it adds only what the frontmatter does not carry.

The table’s keywords setters reach \lx@add@keywords in two more shapes a class gives them (68n), each found by a check on what the class defined, never a name pattern: a one-argument setter the class defines only for its abstract’s body (abstract_setter_definitions: wiley-article.cls:446-489 inside the \NewEnviron its \abstract becomes, astlb.cls:199-205 inside the {pazhabstract} its \@maketitle typesets the abstract in, mtt.cls:176-181 inside its own {abstract}), which the kernel’s locked {abstract} never runs, so \keywords was undefined (330 of 373 run-353 papers: 1706.00599, 1801.08881, 1202.2889, astro-ph0306137, 1507.06302, 2103.05801, 1310.0585); and an environment whose begin code only typesets a heading carrying the class’s label (label_only_begin_code: paper.cls:621-627 \def\keywords{\small\paragraph*{\keywordname:}}), which became a run-in <paragraph> where OmniBus made keywords (OmniBus.cls.ltxml:126-156). OXIDIZED_DESIGN_DIVERGENCES #634.

Three more shapes of the table’s stores (95d): a table name a raw file made a token register that only printed code prints — in a macro the title page reaches or a page style it selects (toks_store: googlecloud.cls’s \newtoks\correspondingauthor, printed in its \fancypagestyle{firststyle} foot, 2607.06973; OD #939); the table setters a raw PACKAGE defines, rerouted at its end as a raw class’s are, unless a raw class’s read loads it (reroute_raw_package_stores: medima.sty’s dates under elsarticle, 2307.16262; OD #940); and a table setter that prints a mark before its pure store (table_setter_stores: astlb.cls’s \email, 1202.2889; OD #941). A raw package’s setter’s own \@<name> is a store only when code that never runs here reads it (ClassReaders::read_where_nothing_runs: rlj.sty’s \@keywords, read by an uncalled \makeCover, 2605.31044); a date or classification is named only by a label the code its title page reaches prints, in a branch’s \else too (medima.sty’s \finalformhead~\@finalform), or before the test (Received: \ifx…\else\@received\fi), a phrase ending at a ; or , (pazha2.cls’s …; revised \@revised), else by its role’s default only where that word is printed right before the store (wiley2sp.cls’s \receivedname), else unnamed (OD #940).

The unclaimed-text net (98c, OD #953; FIDELITY_CHARTER §4): any other store the class’s title-page code reads that the document set, that the title page prints and no kept run typeset, is a note of the author block, kept only for lines of 3 or more words no frontmatter field holds (net_candidates, hand_net_stores; insert.rs keep_unclaimed_net_notes): copernicus’s \AB@affillist, read only by its own \@author (sect05.rs keep_class_author_reader; 0712.1312), sig-alternate’s \tntoks, read only by its refused {abstract} (1206.6940). Below that floor (105a) a line of addresses alone is the e-mail contacts of the note’s creator (aaskaiid.sty’s \email@toks, 2606.27706, 2607.25721), a code’s or a date’s line is kept, and any other is counted in a Warning naming its store and words (2103.14934).

Displaced text (99b, OD #955): a raw file’s affiliation or address setter that stores its argument for its title page among code of its own, which K11’s pure-store test leaves (rstransa’s \gdef\@address{#1\ifaffbreak…\fi}, iau’s numbered \csname affil\the\affilcount\endcsname), runs under a meaning recorder recording what it stored (reroute_displaced_setters); at \maketitle what the title page prints of it is the creators’ contacts, taken out of the deposit by that record (route_and_hand_displaced). An in-place setter with no line break of its own (iopjournal’s \affil) is the API’s where its call stands as a line (run_in_contact_setter). Each line of either is placed by its leading label (contact_line_call).

Functions§

before_title_page_runs
Before the title-page deposit and replay of a raw class’s title page (\lx@deposit@maketitle, sect05.rs), in the state they meet: what the title page prints is decided by TeX, not read off its code. Each candidate store is given a sentinel value and the title page is digested speculatively (title_page_probe_run: output discarded, assignments undone, diagnostics discarded), once with letters sentinels and once with digits ones (sentinel_runs); a store both of whose sentinels reach the digested text is printed there (a numeric context — \setcounter{page}{\@fp} — consumes the digits, TeX’s recovery typesets the letters). A class’s own booleans (sigplanconf.cls:87-90 \def\@true{TT}, :1118 \if \@copyrightwanted \@copyrightspace \fi: 1603.03011 [preprint,nocopyrightspace]), its \newif switches (aiaa-tc.cls:199-200 under [handcarry]), its \@ifundefined and \ifx…\@empty tests and what it only puts in a box or a running head (\setbox, \markboth: 1704.03582, 1508.03599) are then what they are in pdflatex. Three runs:
copy_title_page_prints
Does a stand-in’s copy print the store store (\@author, \@date, \@title) — on its own title page (the \maketitle/\@maketitle it defined, state::copy_provides_title_pages) or in a page style a raw file defined, and every macro they reach that the copy (its own version of a name the binding owns, copy_provides_overlaid_meaning) or another raw file defined, read as ClassReaders reads a raw class (reads_of: \csname…\endcsname, \@nameuse), under the switches it set (a branch of a \newif/kvoptions flag that is now false is not printed, reads_of_branches)? A title-page name it reaches with neither a copy’s nor a raw file’s meaning is the binding’s, which prints the frontmatter: the copy’s \renewcommand\maketitle{\begingroup\@maketitle\endgroup}. None when no copy defined a title page (the binding’s prints the frontmatter). atlasdoc.cls (2019, 1902.05892) prints \@date only in its \ATLAS@TitleHeader (:567, under \ifADOC@datetop), which its \maketitle (:716) calls only without cernpreprint; \@author under the title.
frontmatter_owned_stores
The stores whose values the frontmatter owns: the kernel’s title fields (and their short forms) and the raw class’s stores K11 hands to the frontmatter — the rerouted table setters’ (reroute_raw_class_stores) and the off-table ones (survey_off_table_stores). A class command run in place after the document body began puts them back as they were (sect05.rs sealed_storing_run, silent-loss #8).
hand_net_begin_code_stores
When the document opens a frontmatter environment after the \maketitle that ran the net (\lx@abstract@class@setters, right after the class’s refused begin code is replayed there): the net’s candidates only that begin code prints (lx_sentinel_net_begin, before_title_page_runs), as notes of the author block, their values as they are now (sig-alternate.cls:736-790’s \the\tntoks under {abstract}: 1206.6940, cs0405006). Once; not after the authors were sealed. A document that never opens the environment, or opens it before \maketitle, prints none of them (review rev98c S1: noabs, absfirst).
harvest_stores
At \maketitle (\lx@store@defaults), or at the frontmatter fallback in a document without one (at_maketitle false; again at insertion, a no-op once read): hand the captured stores not yet handed on to their frontmatter API, once — every creator-annotating or creator-making store the document set (in the order it set them), every named abstract or keywords store it set (labelled_api: the class’s store, which LaTeX expands at \maketitle), and, only at \maketitle (nothing reads one otherwise), any store left at its class default that the title page prints (lion-msc.cls:196-203 \gdef\@affiliation{Huygens-Kamerlingh Onnes Laboratory, …}, which pdflatex prints; not tlp.cls:697-728’s running-head placeholders, ClassReaders::read_by_the_title_page). A blank store is skipped. The creator-making stores go after the annotating ones when there is an author (their annotations stay the authors’), before them when there is none (an affiliation then annotates the speaker); a creator-annotating store with no creator at all is not handed on and stays the class’s to print.

note_author_seen

note_document_hooks
Around the begin-document hooks (sect02.rs \begin{document}): before them (before), the Document-origin definitions that exist and the token registers’ contents; after them — \AtBeginDocument‘s, and the begindocument/end hook’s, which \begin{document} reads after itself (\lx@net@document@hooks@done) —, each definition they made is recorded as the hooks’ (lx_net_hook_<name>), and each token register they changed has the contents they left as its raw default (lx_net_toks_default_<name>): a class default for the net (net_value_changed), as a class’s \AtBeginDocument{\setjournal{…}} filling \jtoks is (review rev98c S2).
refused_environment_definition
An undefined token that an open environment defines for its body in the class’s own definition, which the kernel’s environment shadows: a \<env> the class (or the document) made, which \begin{<env>} never runs when the kernel’s \begin{<env>} constructor is defined (sect01.rs), or one the kernel’s lock refused (\lx@dropped@<env>, state.rs) — bmcart.cls:712-717 \def\@figure[#1]{…\def\csentence##1{…} (its captions’ lead sentence, 2305.08284, 1611.01327, 1909.07026) and :1505-1510 \def\abstract@fmt[#1]{… \def\parttitle##1{…} (its structured abstract’s headings, 2007.07886, 1907.07303, 2106.01700): the definition is made where the call stands, as the class’s environment would have made it, and the call retried (latexml_core::binding::kernel_autoload::try_refused_environment_definition). Searched: the open environments innermost first (the kernel’s abstract, no environment frame, first inside its body; a frontmatter field’s own setter before them) whose class code never ran (refused, or shadowed by a constructor), each one’s definitions and the commands they hand control to (handed_to), only definitions a raw file or the document made, outside any conditional, at most 64 per environment. An environment whose begin code ran is not searched: \newenvironment{myenv}{\ifshowfoo\def\foo{…}\fi}{} leaves \foo undefined in its body, as in pdflatex. Guard: perfect_kernel_batch68v::an_environment_whose_code_ran_is_not_searched. OXIDIZED_DESIGN_DIVERGENCES #647.
reroute_displaced_setters
After a raw class, or a raw package read outside a raw class’s read, loaded, and K11 and the in-place reroute had their pick (apa6.cls’s \affiliation, a pure store K11 takes at the class’s end, after ftnright.sty its read loads; 1710.02566): each table setter of an affiliation or an address (displaced_api) the file defined that stores its argument for the title page without printing it (displaced_setter) — rstransa.cls:1154 \gdef\@address{#1\ifaffbreak\relax\end{splitaddress}\fi} (2607.20672), alta.cls:58 \gdef\alta@affiliation{#1} (2609.39929), eph.cls:325 \def\epl@institute{\epl@institute@makeup{#1}} (nlin0310001), iau.cls:1515’s numbered \protected@xdef\csname affil\the\affilcount\endcsname{#1} (2510.16758, 2607.25849): a store K11’s pure-store test (pure_stores, a \@name store) does not take, which the kernel’s \maketitle deposit (sect05.rs \lx@deposit@maketitle) printed into the body under the names, every author with no contact. The setter runs as the file’s own (\lx@class@displaced@<name>), under a meaning recorder (\lx@displaced@begin, \lx@displaced@end; state.rs begin_meaning_recorder, which nests, unlike an assignment journal: review rev99b B4) that records, of each macro it changed, the part that holds the call’s argument (sect05.rs assigned_parts_holding): the class’s own record of the value, its provenance. At \maketitle the title page’s speculative run decides which of them it prints (route_and_hand_displaced); those are the creators’ contacts through the API, and the deposit takes them out of the class’s macros (\lx@replay@records), never by their text. OXIDIZED_DESIGN_DIVERGENCES #955.
reroute_in_place_contact_setters
After a raw file is read (a class, \lx@class@loaded@raw; a package, \lx@package@loaded@raw): each Frontmatter API contact setter it defined (IN_PLACE_CONTACT_SETTERS; still its own definition, not a binding’s, nor one K11 rerouted as a store) that sets its argument as a title-page line (in_place_contact_setter) is the API’s, as the kernel’s locked \author stays the kernel’s against the file’s own: the line becomes a contact of the creators, keyed by its printed marks, and the file’s in-place typesetting of it is not kept — in pdflatex it prints under the names its \author printed, which the kernel’s \author made creators. Beyond Perl, which reads no shipped file and gives the paper OmniBus’s setters. OXIDIZED_DESIGN_DIVERGENCES #936.
reroute_raw_class_stores
Reroute every table setter the raw class cls defined as a store; a binding’s own setter (acmart.cls’s \copyrightyear, ported as the class’s store) is not the raw class’s.
reroute_raw_package_stores
After a raw package sty was read outside a raw class’s read (\lx@package@loaded@raw; one a raw class loads is that class’s, rerouted at its end with its title page known): the table setters it defined itself (defined_by_a_raw_file), as a raw class’s are — medima.sty:300-312 redefines elsarticle’s bound \received, \accepted (and \finalform, \availableonline, \communicated) as stores only its own refused \maketitle reads, so the paper’s “Article history” was lost (2307.16262; jcomp, prletters, ycviu, yjvci, cag, jasr ship the same shape under elsarticle). The class’s other K11 passes (its keywords environments, kernel field setters and off-table stores) stay the class’s.
title_page_may_print
May the class’s title page print the store of \<name>, whose entry carries its title-page provenance (OXIDIZED_DESIGN_DIVERGENCES #903)? Unless the speculative run of the whole title page was made and its sentinel did not reach it (before_title_page_runs, lx_sentinel_printed): a store the class prints elsewhere — dmtcs’s \keywords after its abstract, 0905.1102 — is not the title page’s; with no run made, it may be.
