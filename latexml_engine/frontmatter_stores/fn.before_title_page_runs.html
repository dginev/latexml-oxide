Before the title-page deposit and replay of a raw class’s title page (\lx@deposit@maketitle, sect05.rs), in the state they meet: what the title page prints is decided by TeX, not read off its code. Each candidate store is given a sentinel value and the title page is digested speculatively (title_page_probe_run: output discarded, assignments undone, diagnostics discarded), once with letters sentinels and once with digits ones (sentinel_runs); a store both of whose sentinels reach the digested text is printed there (a numeric context — \setcounter{page}{\@fp} — consumes the digits, TeX’s recovery typesets the letters). A class’s own booleans (sigplanconf.cls:87-90 \def\@true{TT}, :1118 \if \@copyrightwanted \@copyrightspace \fi: 1603.03011 [preprint,nocopyrightspace]), its \newif switches (aiaa-tc.cls:199-200 under [handcarry]), its \@ifundefined and \ifx…\@empty tests and what it only puts in a box or a running head (\setbox, \markboth: 1704.03582, 1508.03599) are then what they are in pdflatex. Three runs:

  • the class’s whole title page with the document’s values (title_page_print_tokens), the off-table stores the document set (offtable_candidates) and the rerouted stores handed to the frontmatter as candidates (lx_sentinel_printed): an off-table store is printed there (hand_untypeset_stores); a handed one was placed by this \maketitle (#6b, \lx@store@hand);
  • the deposit and the replay, each as it will run (title_page_deposit_tokens, title_page_replay_tokens), the off-table candidates given sentinels (lx_sentinel_deposit, lx_sentinel_replay): a store either typesets, when it is kept, is not handed on a second time.

Before them, the value of each rerouted store the document never set that is still undefined (decide_unset_nulls). When no run can be made (a journal is open, or it is over the read budget, TP3), or the deposit’s or the replay’s ended in a Fatal of its own (sentinel_runs), lx_sentinel_ran stays false and the stores’ readers are walked instead (live_read_order, evaluated_switch). The unclaimed-text net’s candidates (net_candidates) join the same runs, after K11’s stores (lx_sentinel_net_printed, _deposit, _replay; with the refused begin codes’ run, net_begin_code_tokens); a run their sentinels make fail is made again without them, and the net then decides nothing.
