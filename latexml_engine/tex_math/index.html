Constants§

REREAD_COPY
The state value naming a digestion that re-reads a source the document also typesets where it stands, set locally by \lx@reread@copy: the toc copy of a heading or caption that has no [short] (sect04.rs, \lx@toc@copy@text), the reference forms of a tag (\lx@make@tags: an \item[…] label’s typerefnum, a \tag{…}’s refnum), and natbib’s label copies (\NAT@@wrout, which TeX writes to the .aux and reads only at a citation). A diagnostic that stands for one source occurrence (OXIDIZED_DESIGN_DIVERGENCES #721’s Warning) is given at the typeset reading and not again here. A [short] title or caption is no re-read: it is its own source, digested once, into the list.
WRITTEN_COPY
The state value naming a copy that TeX only writes to an auxiliary file or a list (natbib’s \bibitem label, natbib.sty:822 \NAT@wrout to the .aux; a caption’s or heading’s list entry, latex.ltx:17403-17404 and \@sect to the .lof/.toc): set locally while such a copy is digested (\lx@written@copy, natbib’s \NAT@@wrout). TeX never typesets the copy where it is made, so a _ or ^ in its text is that character, with no Error — pdflatex gives none (OXIDIZED_DESIGN #550). Witnesses 1904.06560, 2205.04819 (natbib labels), 1303.1693, 1206.2108 (\caption[short_x]).

scan_delimiter
tex.web §1160 scan_delimiter (Perl’s TeXDelimiter, TeX_Math.pool.ltxml:712-724): get_x_token past blanks and \relax, then a delimiter by meaning — a character with a \delcode (or a \let copy of one), \delimiter or \Udelimiter with their codes, or one of LaTeXML’s math symbols (DefMath, and the parameterless primitives and constructors that stand in for TeX’s \delimiter macros: \langle is \delimiter"426830A in TeX). Anything else is TeX’s “Missing delimiter (. inserted)”: the token is put back and the null delimiter . returned. Perl invokes whatever token it reads and unwraps a brace group once; a {/} takes TeX’s path (§1160-1166: “Missing delimiter”, the brace read again). In text mode (a \left TeX would have refused, reached where a beamer frame stripped the $) every token is taken, as Perl takes it. OXIDIZED_DESIGN #530.
stretch_delimiter
Perl augmentDelimiterProperties’ stretchy (TeX_Math.pool.ltxml:810-811) for a delimiter outside DELIMITER_MAP (stmaryrd’s \llbracket, a \delimiter glyph): the element the digested delimiter became is marked stretchy. Until 65d such a delimiter warned “Missing delimiter; ‘.’ inserted” and stayed unstretched (RED math-parse/left_delimiter_outside_the_map); it was accepted by meaning when it was scanned (scan_delimiter).
