The state value naming a copy that TeX only writes to an auxiliary file or a list (natbib’s \bibitem label, natbib.sty:822 \NAT@wrout to the .aux; a caption’s or heading’s list entry, latex.ltx:17403-17404 and \@sect to the .lof/.toc): set locally while such a copy is digested (\lx@written@copy, natbib’s \NAT@@wrout). TeX never typesets the copy where it is made, so a _ or ^ in its text is that character, with no Error — pdflatex gives none (OXIDIZED_DESIGN #550). Witnesses 1904.06560, 2205.04819 (natbib labels), 1303.1693, 1206.2108 (\caption[short_x]).
