The alignment whose rows a rule marker (\hline’s \@@alignment@hline, \cline, an \hrule) borders: the current one, except inside a misplaced \noalign’s body, where TeX’s \hrule errors in the cell and draws nothing (tex.web §1126/§1129; see \noalign). A stray \cline/\hline there used to stack border="bbbb…" (2306.10087). Guard: perfect_kernel_batch65::misplaced_hline_in_a_cell_draws_no_rule.
