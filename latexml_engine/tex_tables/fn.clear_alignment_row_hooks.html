pub fn clear_alignment_row_hooks()
Expand description

A new alignment’s rows run no row hook of an enclosing one: an \halign, {array} or tikzcd in an {eqnarray} or align row inherited \eqnarray@row@before and stepped the equation once per inner row (1601.02132; Perl alike, KNOWN_PERL_ERRORS #518). Every alignment’s bindings call this after assign_alignment; the numbered displays (eqnarray, amsmath, cases) set their hooks afterwards. The hooks are local to the enclosing cell, so the outer alignment’s later rows still run its own.
