The note kind of a contact line led by a footnote-symbol mark (operand, is_symbol_mark: $^*$, $^\dagger$; or one whose printed glyph, line_mark’s, is a footnote symbol: \textsuperscript{\textasteriskcentered}) whose text is a legend — correspondence, a contribution, an author deceased, an address change (classify_thanks) —: a note of the names carrying the symbol, not their affiliation, as the frontmatter observer writes it (show_legend_mark), so a labelled line keeps the kind it had when the observer re-parted the names (2602.03759, 2604.08878, 2607.12158; review rev99b B1’s legend, 2609.15125; $^\dagger$Deceased, an annotation on the author of the same kind as “Corresponding author”, FIDELITY_CHARTER §4, review rev99b2 q4e). None for any other line (frontmatter_stores.rs contact_line_call).
