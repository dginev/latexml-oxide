pub fn glued_line_marks_as_marks(tokens: Tokens, first_line: bool) -> Tokens
Expand description

tokens with a mark that leads a line of labelled entries written without the symbols glued to it ($^{*1}$Kyoto University, $^{1*}$Univ X, 2606.23258): the mark labels the line, the symbol with it, and a line prints no label in its text — it read “* Univ X”, or matched no name once the names’ *1 asks for 1 and * apart (glued_marks). From the first line if first_line (an affiliation list), else from after the first line break (an author block, whose first line is names, its marks after them).
