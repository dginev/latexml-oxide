Expand description

One event of an author block.

Fields§

§kind: EventKind§span: Option<(u16, u16)>

the positions of the author field it covers, start..end

§text: String

its ink: a name’s text, a mark’s printed text, a contact’s or a note’s shown text

§label: Option<String>

a mark’s label, a note’s \label, a contact’s optional label; an enumerate item’s (ITEM_STEP) counter value as digested

§symbol: bool

a mark printed as a footnote symbol

§line_first: bool

a mark that is its line’s first ink

§role: Option<String>

a contact’s role, a mark’s or a layout’s source (sup, math, inst, text; the container’s command); a Name’s, the role of the creator call that printed it (PoS’s \speaker, role=speaker: creator_roles)

§target: Option<String>

a link’s target

§inner: Vec<Event>

a note’s inner contacts and Marks (the one its text opens with line_first, the others not)

§nest: u8

how many layout containers enclose it

§glued: bool

a mark’s run of footnote symbols that a line of its block leads with and a name shows, written together (§†): one label, as †† is (the resolver’s glue_shown_runs; main-session decision 2 on FM S2a.2 r7, 0907.1243)

§space_before: bool

a mark set off by a printed space from the ink or separator before it, and from the name after it: which of the two TeX’s output sets it next to (the resolver’s nearer_next; Han,${}^1$ Thibault prints “Han,¹ Thibault”)

§space_after: bool§meaning: EmailMeaning

an e-mail contact’s: whose meaning made the call (EmailMeaning)

§inkless: bool

a note’s: nothing in it prints (leaves_no_ink on its digested body, the test the XML’s note is dropped by: \thanks{}, \thanks{~}, OXIDIZED_DESIGN_DIVERGENCES #916)

§annotate: Option<String>

an in-block annotation’s (\lx@annotate@frontmatter) annotate= option: the authors today’s API gives it (run, new, a number, all; Perl Base_Utility.pool.ltxml:520-536)

§font: Option<Rc<Font>>

a cut in-block contact entry’s: the font changes in effect where the writer’s cut of it starts, against its call’s (fonts::entry_font; Font::default() for none), which the writer digests it under — None when not read. A Name’s: the font of its first character as digested, for the emitter

§wrap: Option<Rc<Wrap>>

a cut in-block contact entry’s: the containers holding it and another entry, which the writer wraps it in again (fonts::Wrap, emitter::container_wrap)

§formula: Option<MarkFormula>

a mark’s formula or group (MarkFormula), None for one at the block’s top level

§unprinted: Option<String>

a contact’s that prints nothing, what it records (ltx:rdf’s content: AASTeX 7’s \email without [show], 2506.18556, 2507.12222; OXIDIZED_DESIGN #479): its text holds no ink, as the XML holds none. Such a call stands outside the reading’s events (ledger::UnprintedCall)

§held: bool

an error of the block’s rehearsal was held at a position it covers (mark_held): what it reads may be the error’s recovery, not the ink it stands for

§glued_undef: bool

a Name’s: an undefined command its rehearsal held an Error at glues ink onto an address’s local part (mark_held, glues_an_address): the same word has ink before it and ink after it, both before its @ (“Bob|b@”) — it prints nothing, so Bob\email{b@x.org} (\email undefined in article) reads “Bobb@x.org”, an address no word of the source spells, which no reading of addresses may take: Perl’s creator holds it in the personname, Bob<ERROR>\email</ERROR>b@x.org. A Name whose characters the ink table cannot align (a mark glued into it, “Bob Baker1b@x.org”) fails closed on its span: an Error strictly inside it, an @ token of it past the Error. One past the @ (ann@x.org\IEEEmembership{Member}), before the word (Bob \foo b@x.org), in another word (\texttt{ann@x.org}\foo{} Univ X, (ann@x.org\foo)) or with the whole local part before it (ann\foo@x.org) glues no name into an address and is none (OXIDIZED_DESIGN_DIVERGENCES #983)

§break_kind: Option<BreakKind>

a Break’s: what made it, None for a line break (BreakKind)

§braces: u8

a Break’s or a comma’s: the braces printed and not yet closed before it in its column (\{aable, bbaker,\\ ccole\}@x.edu: both inside one group of local parts; ijcai’s \emails list), which a TeX group is none of

§ordinal: bool

a Mark’s: the suffix of the number the Name before it ends in, 5\textsuperscript{th}, $21^{st}$: printed st, nd, rd, th, a space between them or not (2412.10792’s 1\textsuperscript{st} Sertac; iopart’s \address{$^1$Univ A, 5 \textsuperscript{th} floor}; 10$^{a}$ is a mark)

§printed_labels: Vec<PrintedLabel>

a Name’s: the labels its words print by hand (PrintedLabel)

§own_at: Option<u16>

a \textsuperscript Mark’s: the call’s own position, its span being the wrapper’s when it is the first box in one (\textbf{\textsuperscript{2}Univ B}, emitter::Field::own_print). Not in a dump: only the content reads it

§marks: Option<(u16, u16)>

a cut in-block contact entry’s: where its leading marks print, first to last, whole (emitter::span_tokens). A Name’s: its boxes’ own tokens’ positions, first to last, where span is their covers’: the first box in a wrapper takes the cover of the call around it, \\textbf{Ann, Bob}’s Ann the whole group (the emitter’s). Not in a dump: only the content reads it

§footnote: bool

a Note’s: a \footnote, whose meaning in an author’s content is no \thanks’s (digest_frontmatter_item). Not in a dump: only the emitter reads it

§given_number: bool

a footnote Mark’s: it is given its number (\footnotemark[1], a document’s \samethanks[1], 1912.01737, 1811.08622), latex.ltx’s \@xfootnotemark, which sets the counter in a group of its own and steps nothing — it re-references a note written already; a bare \footnotemark steps the counter (\stepcounter\@mpfn). Not in a dump: only the emitter’s dropped-mark check reads it (emitter::emit::mark_dropped)

§creator_call: Option<u16>

a Name’s: the block’s creator call that printed it, its place among the rehearsal’s (creator_roles; ledger::Outcome::Events::creators). Not in a dump: only the emitter reads it

§note_mark: Option<String>

a contact command’s note that prints its text under a mark of its own (its call’s _mark key, jheppub’s \lx@add@contact[role=note,_mark={#1}]): that mark, empty for the footnote counter’s next number (jheppub.sty:84-89 \note[*]{…}, \note{…}); None for any other. Not in a dump: only the reading’s corresponding-author step reads it (Resolver::corresponding)

§body: Vec<Event>

a Note’s lexed text, whole — its names, separators and marks, where inner keeps its contacts and marks alone: what a \thanks of several marked entries is cut by, before each top-level mark (mark_led_pieces). Not in a dump: only the reading’s note step reads it (Resolver::keep_note)

§name: Option<String>

an annotated contact’s (\lx@annotate@frontmatter’s name= key, a nested \lx@add@email[name=…]): the label its class prints with it — authblk’s \affil{Univ A\thanks{Corresponding author e-mail: …}}, the Kind step’s \lx@add@email[name={Corresponding author e-mail:~}]{…} (cond-mat0202268) —, as a call’s own label is its name= attribute (resolver::placed::call_label). Not in a dump: only the content check reads it
