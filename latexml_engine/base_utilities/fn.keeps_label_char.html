pub fn keeps_label_char(c: char, before: Option<char>) -> bool
Expand description

Whether a frontmatter mark’s label reader keeps the character c of printed text, before the last it kept (queue_digest::label_ink, the observer’s events::script_ink): a format character (Unicode Cf: the zero-width space, the joiners, the byte-order mark) prints nothing and is dropped — \up{\!1,2}’s zero-width space was an empty mark on each name, 2209.14855 (review rev92b_r1 B1) —; a combining mark (M) is part of the character before it, kept — \={x} prints “x̄”, an accent with no precomposed form (\=, \~, \v, \u, \H, \b, \d over an x), a label of its own, not x (review rev92b_r2 B1: the mark dropped, x̄ matched an x line) — and dropped only with no base: first, or after white space or a label separator (,). Any other character is kept.
