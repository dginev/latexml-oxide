Do an author’s marks end what it prints (Ann Able$^{1}$, Ann$^{1}$\thanks{…}): after the first of them nothing but further marks, spacing, braces and math shifts (${}^{1}$), and notes with their arguments — \thanks, \footnote, the note commands of is_name_note_command, a document’s note macro, and the binding’s contacts, whose argument goes to the frontmatter (authblk’s \affil inside \author, 2605.03796)? Not when a line or anything visible follows them: Ann Able$^{1}$ \\ Univ X, Ann Able$^{a}$ (ann@x.org), Ann Able$^{1}$ \orcidlink{…} (77n r3 review probes m2, m9, m8). A superscript is a mark only when its operand reads as labels (reads_as_labels): Ann Able$^{1}$\textsuperscript{equal contrib.}, \textsuperscript{(*)}, $^{\rm (a)}$ show text, which the list path would have cut to a label or dropped (77n r4 review probes d1, d3, d4, c4, d6). Public for authblk’s \author (latexml_package), which reads a single marked name as a list only then: the list path shows a mark nothing answers after the name’s last text. (A line break reaches that path by its own, has_author_block_separator, where a mark before it stays, 108a.)
