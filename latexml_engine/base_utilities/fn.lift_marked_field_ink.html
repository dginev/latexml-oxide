pub fn lift_marked_field_ink(document: &mut Document) -> Result<bool>
Expand description

The printed ink of each field the frontmatter displays, removed — the field’s print by construction: the ink digested from the field’s stored tokens (their out-of-band provenance, \lx@field@mark; the title-print study’s rule R3, frontmatter model M3 stage S1, OXIDIZED_DESIGN #715), one run of it (field_ink_runs) at a time, with the title-block wrappers it leaves empty (not a \label target, which is the author’s own). Called once, where the frontmatter is placed (the \maketitle flush \lx@frontmatterhere, the fallback at the first sectional unit or \end{document}), so only what was printed before it is the field’s ink; every mark goes, and later prints are not marked (lx_field_ink_settled, Document::settle_field_ink). A run is lifted only:

  • when it is the whole field: what its own boxes consumed of the current call’s value covers every position of the field’s extent (lx_field_extent_<id>, covers_extent), a macro’s too, so a fragment the document takes of it (\StrLeft{\@title}{5}, also of About \nm; \@car, \@gobble) stays, also beside the rest of the value set in a box never shown, in a formula or in a \phantom (field_ink_runs);
  • where the frontmatter displays the field: a document-level <ltx:title>, or a document-level author <ltx:creator>, with no <ltx:titlepage> beside it (beside one the XSLT shows neither, LaTeXML-structure-xhtml.xsl :374-375 = Perl :358-359 and :687-692, and the print is the displayed copy: 1304.0681, 1503.03277);
  • in the document’s title block: no body text before it in the document’s content order (field_runs_after_body_text: a letter’s closing \noindent\@author stays), and is_field_ink_wrapper for every ancestor of both marks — never inside a {titlepage}, a float, a note, a frontmatter element or a frame;
  • when the fields’ prints fill their lines: the paragraph or table cell around each mark holds nothing but lifted ink, so a mention in prose (Title: \thetitle) keeps its words and a title and author set on one line go together.

Every whole print in the title block is lifted, a title the document prints twice too: it shows once, in the frontmatter element (user ruling 2026-10-17, “lift every whole print”; OXIDIZED_DESIGN #715).

Returns whether a title print was lifted: the text-matching dedup (maybe_dedup_leading_title_ink) then has nothing left to explain. P2 witnesses: 1605.00182, 2402.14614, 1603.09631 (lrec \maketitleabstract), 1503.06457.
