pub fn resolve_dump_text() -> Option<(String, String, u32, bool)>
Expand description

Resolve the ambient latex.YYYY.dump.txt and read it, WITHOUT applying anything to State. Some((content, source_label, dump_year, from_embedded)) or None when $LATEXML_NODUMP is set or no dump is reachable.

Shared by load_definitions (which then replays it) and by crate::latex_kernel, which scans its keys to answer “does the LaTeX kernel define this CS?” without loading anything. Keeping one resolver means the catalogue can never disagree with the dump the pool actually loads — same env overrides, same ambient-year preference, same embedded fallback.
