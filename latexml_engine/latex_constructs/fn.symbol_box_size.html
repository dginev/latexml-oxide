Expand description

A symbol box width × height units of the whatsit’s font, no depth: the size TeX measures for a class’s QED box (a rule, \openbox, \hbox{\rlap{$\sqcap$}$\sqcup$}), given to a size-less constructor so a cell or box holding only it is not empty — alignment emptiness is by measured size (alignment/normalize.rs, Perl Alignment.pm:458-470), and a size-less whatsit alone in a cell was dropped. The constants are TFM ratios of the glyph font’s design size (or the class’s em/ex dimensions), applied as multiples of the current font’s em or ex — equal at 10pt, where cmsy10’s QUAD is 1.000003 of the design size.
