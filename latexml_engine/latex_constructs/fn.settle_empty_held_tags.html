pub fn settle_empty_held_tags(document: &mut Document, root: &Node)
Expand description

Settles the empty held tags left once the document is built (note_empty_held_tag), which no target closing over them tied and removed: a caption’s tags in a minipage that became a figure panel (settle_float_paragraph’s fold; two captioned minipages in a figure), a label type’s tags put in place after their target closed. Each is tied to the labels of its owner only — the element holding its ltx:tags — as tie_held_tags ties one (its held diagnostics raised where a reference prints its role, replay_shown_deferred, so they run before it); an owner with no label is an object no reference can print, so its tag’s diagnostics are dropped with it, as pdflatex never typesets that format (a section’s or an outer figure’s label is not the panel’s). Then it is removed with an ltx:tags it leaves empty. Run on the document and on each streamed segment; the pending count ends at none. Witness 2205.00263 (nine empty panel tags removed). Guards perfect_kernel_batch78j::cleveref_format_errors_in_minipage_panels, …::cleveref_format_of_an_unlabelled_panel_raises_nothing.
