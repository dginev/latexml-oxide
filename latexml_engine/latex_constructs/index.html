note_panel_separator
Record a row separator the source states at the current insertion point, when that is a float’s own panel list (the float, or the capture of a {center}-like environment directly in it) — the panel grid rule (user ruling 2026-10-22, FIDELITY_CHARTER §2 “Float panels”): an explicit break always breaks, and the glue the source states between two panels counts towards their row’s width (plain spaces and \hfill count 0). Our panels are digested in vertical mode, where TeX’s are in a paragraph (subfigure.sty’s \@subfloat, graphicx’s \leavevmode), so a \par or the glue between them leaves nothing in the tree to set the rows by. A \par that leaving horizontal mode inserts is not the source’s (2605.00347: one per inter-panel \hfill broke a 4-panel row into four). Witnesses 1110.0084 Figs 12-16, 27, 29 (a blank line between sub-figures), 0706.4410 Figs 3, 5 (\hspace{1in} between two 0.45\textwidth panels: two rows in the PDF). OXIDIZED_DESIGN_DIVERGENCES #885.
