The global value naming the counter (equation, or subequation when the sub-equation number is set) whose current value the next IEEEeqnarray row prints without stepping it: the number of a retracted EQUATIONROW_HOLDS row. Read and removed by \eqnarray@row@before@ (sect07.rs), cleared where an equation group’s numbering begins (\@equationgroup@numbering), as \@IEEEeqnarray pre-advances afresh (:1985-1987).
