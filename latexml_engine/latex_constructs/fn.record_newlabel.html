pub fn record_newlabel(name: &str, value: &str, url: Option<&str>)
Expand description

One \newlabel{<name>}{<value>}, the record of a label an .aux file holds (latex.ltx \newlabel → \@newl@bel, \global\@namedef{r@<name>}{<value>}): the value’s first group is the text \ref prints, hyperref’s fourth the anchor; a <label>@cref record is cleveref’s type and number (cleveref.sty \cref@label). url is the document the anchors are in, where one is given (xr’s \externaldocument[…]{…}[url]). Records are kept as xr’s are (record_external_label): references to a label this document holds after all print its own.
