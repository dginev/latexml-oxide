pub fn nfss_selected_font(base: &Font, report: bool) -> Result<Font>
Expand description

The font \selectfont puts in force over base: LaTeX’s \f@family, \f@series and \f@shape merged in (Perl latex_constructs.pool.ltxml L5204-5222), without assigning it, so pgf’s \pgfmath@selectfont reads the same font (pgfmath_code_tex.rs pgfmath_font). An unknown family is tried as an encoding (LoadFontMap($family), bbding’s \dingfamily), then as \wrong@fontshape’s encoding defaults; report announces an unrecognized family, series or shape once per document, as \selectfont does.
