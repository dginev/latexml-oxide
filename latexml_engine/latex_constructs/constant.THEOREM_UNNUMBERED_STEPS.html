Set by a package whose unnumbered theorems still step their counter: ntheorem.sty:824-839 \@othm and :870-880 \@thm run \refstepcounter{#2} for every theorem, its \newtheorem* (a nonumber style, :720-727) only printing no number, so \newtheorem*{rmk}[thm]{Remark} takes a number from thm (1606.01585: five references one behind). Read where a theorem is declared (define_new_theorem). Global.
