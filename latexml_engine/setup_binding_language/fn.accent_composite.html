The private inner control sequence of a DefAccent! accent: letters only (\lxaccentdot for \., \lxaccentumlaut for \", \lxaccentu for \u), so it survives every string round trip a document can put an expanded accent through — a \write+\input, \scantokens, titlecaps’ \string-and-re-read of a word’s tokens — under the document’s catcodes (@ OTHER) as well as a package’s (\lx@accent@. split into the undefined \lx@accent@ in titlecaps and \lx in grafcet, sweep 74). T1’s \DeclareTextComposite for this engine: the accent applied to ONE alphabetic letter, which the current font prints as itself, whose NFC with the combiner is a single character is that character (the letter’s catcode kept); otherwise None and the accent takes the \lx@applyaccent primitive. See DefAccent!.
