read_box_operand
The box operand of \setbox and \shipout: tex.web §1084 scan_box reads the next token after expansion whose command is neither a spacer nor \relax (§404: an implicit space such as \@sptoken, a \let alias of \relax such as \scan_stop: and a \noexpand-ed token, §358, are skipped too; guard perfect_kernel_batch58::box_operand_skips_noexpanded_token); None at the end of input. TeX requires a box command (\hbox, \vbox, \vtop, \box, \copy, \lastbox, \vsplit) and otherwise reports “A <box> was supposed to be here”; the caller invokes whatever comes (SYNC_STATUS). \leaders peeks with it (the same §1084 read) and unreads the token, to tell a rule specification from a box filler.
