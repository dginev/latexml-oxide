pub fn begun_environment() -> Option<String>
Expand description

The environment begun with \begin that the open until-body is read in — LaTeX’s \@currenvir, whose end \@checkend checks — or None when the body is a begin code called as a command: a bare begin code (lx@env@bare@end), or one whose innermost recorded environment is {document} (mn2e \keywords{…}, mn2e.cls:993-1003, opens its body in the document’s own environment, which LaTeX never checks against it). The innermost frame that records an environment names it: \begin’s current_environment, or lx@until@begun, which the kernel’s \begin{abstract} (no environment frame of its own) leaves in its body’s frame.
