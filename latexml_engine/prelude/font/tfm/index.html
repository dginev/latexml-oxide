TeX font metric files: the character dimensions of a .tfm, scaled as TeX scales them.

A character of a font loaded with \font (preload.ltx’s \tenln, a document’s \font\x=lcircle10) whose family has no standard metric is measured from its own TFM: the Unicode character a fontmap decodes it to belongs to some other font (line10’s slot 45 is an arrowhead 10pt wide; the arrow it maps to is cmmi’s 5pt \vec). Witness 2605.02221 (diagrams.sty arrows). Guard perfect_kernel_batch58::line_font_char_has_its_tfm_width. The size is the font’s size; TeX scales by the design size when \font has no at (tex.web §568; SYNC_STATUS 58f residual).
