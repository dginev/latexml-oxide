pub fn tex_file_name(name: &[Token]) -> (String, bool)
Expand description

The file a TeXFileName argument names, and whether it was braced. TeX Live’s scan_file_name reads a braced name’s group as the name — \input{name}, \openin\r{name} — without the braces; the reader keeps them on the argument because \input loads LaTeX.pool for a braced (LaTeX-style) name (TeX_FileIO.pool.ltxml:164-169). A " quotes spaces and is not part of the name (tex.ch more_name). One reading for \input, \openin, \openout and \font: an \openin of a braced name kept the braces and found no file (pgfmanual’s \openin\examplesource\expandafter{\codeexamplesource}, pgf-pie-manual).
