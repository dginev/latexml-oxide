The option keys each definer accepts — Perl Package.pm’s $*_options tables — and check_options, Perl’s CheckOptions (Package.pm:1062-1067). The runtime (Rhai) front-end checks every option bag against these; the compile-time macros check theirs at expansion.

check_options
Perl CheckOptions($operation, $allowed, %options): one Error:misdefined naming every key allowed lacks. Returns whether all keys were allowed (Err only when the error cap escalates); the definition proceeds either way, as in Perl, with the rejected keys ignored.
unsupported_option
A key Perl accepts whose effect the core cannot carry yet: said, never silently dropped.
