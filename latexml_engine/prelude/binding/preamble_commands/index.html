latex.ltx:9521-9522 \gdef\do#1{\global\let#1\@notprerr}\@preamblecmds: after \begin{document} each listed command IS \@notprerr, which raw code tests with \ifx (ltnews23.tex:42-43). LaTeXML also reads a package, class or sub-file preamble in the body (Perl’s recovery for a body \usepackage, a binding’s load, standalone and subfiles), which pdflatex never does: there the walk’s commands are reopened, and disabled again after it. The walk keeps each meaning under \lx@onlypreamble@<name>; the State holds the list (OXIDIZED_DESIGN_DIVERGENCES #226). A binding’s lock goes aside with its meaning: \@notprerr is no binding’s, and the body’s \renewcommand of it stands as in TeX (imsart.sty:1223 \@onlypreamble\doi over OmniBus’s locked \doi, 2606.22730).

reopen_preamble_commands
Give the disabled commands back their meanings and locks (a body load, a sub-file’s preamble); false when there is nothing to reopen (still in the preamble, or reopened by an enclosing load). One the body has redefined since is the body’s: the walk no longer holds it, and neither this nor the next walk touches it.
