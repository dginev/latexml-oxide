Does a compiled binding answer an existence test (\IfFileExists, \InputIfFileExists) for file, as the file itself? Perl’s \IfFileExists asks FindFile (latex_constructs.pool.ltxml:5692-5697), which takes a .ltxml binding for the file (Package.pm:2125-2128): pgf’s \IfFileExists{pgfsys-latexml.def} (LaTeXML’s own driver) and babel’s \InputIfFileExists{italian.ldf} on a tree without it find their bindings. A binding standing in for an author’s file is not that file (crate::binding::author_files): TeX finds arxiv.sty only where the paper ships it, and so do we, by the disk search the caller makes first (2606.27281; Perl answers true for its own such bindings, neurips.sty, KNOWN_PERL_ERRORS #770).
