Module author_files 

Source
Expand description

The bindings that stand in for an author’s file: a journal’s, a conference’s or a person’s class or style that TeX Live has never distributed and LaTeXML does not provide, so a paper that uses it ships its copy (arxiv.sty, neurips_2024.sty, JHEP.cls, svjour3.cls, aa.cls, …). The binding is a stand-in for that copy, not the file: \IfFileExists and \InputIfFileExists find the file only when the paper ships it, as TeX does (crate::binding::content::binding_counts_as_file); witness 2606.27281 (\IfFileExists{arxiv.sty} without the file). The copy the paper ships is read after the binding, every definition of a name the binding owns holding only inside the copy’s own code, so that its extra commands are defined (“a stand-in’s copy provides”, crate::binding::content read_stand_in_copy, OXIDIZED_DESIGN_DIVERGENCES #731; 1309.5950’s aas_macros.sty \kms). Every other compiled binding is the file it is named for — TeX Live’s (found where the host’s tree lacks it: babel’s italian.ldf on a trimmed tree), a file TeX Live once distributed (FORMER_TEX_LIVE: TeX in the paper’s era found it, so 1710.04900’s harvard.sty \IfFileExists{html.sty} loads the html binding), or LaTeXML’s own (LATEXML_OWN; the pools, font maps and drivers such as pgfsys-latexml.def need no list).

Every registered .cls/.sty/.tex binding TL 2025’s kpathsea does not find is on exactly one of the three lists, by name and case (TeX on a case-sensitive file system finds neither JHEP.cls for TL 2007’s jhep.cls nor ieeeconf.cls for IEEEconf.cls; TL 2025’s mn2e.cls is a documentation file of mnras, which kpathsea does not search). TeX Live’s history is read from its file lists: the TL 2007 image’s texmf/lists, the TL 2008 tlpdb, the TL 2009 texmf listing and the tlpdb of every year 2010-2024. Guards: perfect_kernel_batch68d::author_file_stand_ins_are_bindings_outside_tex_live (each entry against the registry and kpathsea, the lists disjoint) and ::every_binding_outside_tex_live_is_listed (the reverse, on a full tree).

Constants§

AUTHOR_FILE_STAND_INS
The stand-ins (module docs), by the binding’s file name.
FORMER_TEX_LIVE
Bindings for files TeX Live distributed once and no longer does, with the years their file lists show them (TL 2007-2024 checked; “before 2007” for the ones the 2026-10-15 ruling names that no list from 2007 on has). Each answers \IfFileExists as a TeX Live file does.
LATEXML_OWN
LaTeXML’s own .cls/.sty/.tex bindings that TeX Live does not distribute: they are the files they are named for — LaTeXML’s styles (latexml.sty, lxRDFa.sty, ar5iv.sty, latexmlman.sty, xylatexml.tex), its fallback class OmniBus.cls, the shared cores the class bindings load (ams_core.cls, the _support styles) and the test fixtures (keysetopt.sty, lxtesttemplate.sty).
