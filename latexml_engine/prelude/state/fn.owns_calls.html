Whether the locked binding of cs owns its calls, so that the document’s own definition of cs takes its other uses (install_definition): its signature reads a braced argument — its first mandatory parameter is one of BRACED_ARGUMENT_TYPES, after optional ones only (\text{}, \title[]{}, \cite OptionalMatch:* [][] Semiverbatim) — or it is itself such an override (a loop redefining it on every iteration). Derived from the binding’s own parameter list; a binding that reads its argument downstream (\section’s \@startsection, \footnote, \url) or none (\maketitle) stays absolutely locked. So does the machinery (user ruling 2026-10-11: the machinery stays absolutely locked): LaTeX’s internal namespace, a name with @, which LaTeX’s convention keeps out of a document’s reach until \makeatletter (clsguide.tex:187, latex.ltx:1797). Its locks keep LaTeXML’s engine model against code that re-implements it (\alloc@{}{}{}{}{}, called \alloc@0\count\countdef\insc@unt; \@startsection, \@caption, \@lbibitem).
