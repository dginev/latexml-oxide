ClassLoadFrame
RAII frame of one class load (binding::content::input_definitions, a .cls with its options handled: the \documentclass, a \LoadClass, a binding’s LoadClass!). While it is open, the macros assigned outside LaTeXML’s kernel layers — the class binding’s own (article.cls’s names, article_cls.rs), the raw file’s, a package’s it loads — and the names a lock kept from a definition it made are recorded as the class’s (State::class_loads), as its real file defines them; a repeat load records nothing new. DocumentState
A binding’s document-wide state, one value of the Value table: bound globally, as the \global macros and registers of the package it stands for are, so a rollback (begin_assignment_journal: a rehearsal, a title-page check) puts it back, where a thread-local would keep what the discarded run did (FRONTMATTER_SINGLE_ENGINE_PLAN.md “What a rollback leaves”). It changes in place, unless an open journal holds it: the first change under a journal works on a copy, so a list a binding grows costs no more than a thread-local’s outside one.
