Module private_files 

Source
Expand description

files trusted only when this user wrote them (format dump caches) Files trusted only when this user wrote them. A format dump is loaded as the format, and the caches holding dumps live in shared places ($TMPDIR), where another local user could put a file, or a directory, there first.
