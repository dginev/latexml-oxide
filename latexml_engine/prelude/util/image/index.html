image file helpers — port of LaTeXML::Util::Image Image helpers — port of LaTeXML::Util::Image.

Perl counterpart: lib/LaTeXML/Util/Image.pm.

Provides filesystem search for image candidates, minimal header-based image size detection (PNG / JPEG / EPS) and the graphicx sizer that converts keyval option strings into box dimensions. The Rust port is intentionally narrower than the Perl original — Image::Magick is not used at all; LaTeXML::Post::Graphics carries out any heavy-duty image operations in a post-processing pass.

The page count of a PDF, as pdfTeX’s \pdflastximagepages reports it after \pdfximage: the root /Type /Pages node’s /Count. read_postscript_size_bp
A PostScript file’s size in bp, as TeX reads it: the %%BoundingBox, graphics.sty’s \Gread@eps reading (\Gread@BBox, graphics.sty:52, read at :365-399; the hiresbb option, :56-57, aside) and epstopdf’s, which pdflatex then reads as the page; a %%HiResBoundingBox only when there is no %%BoundingBox (where TeX finds no size at all), as post reads the file (latexml_post graphics.rs read_postscript_bounding_box_full). None for an empty box. Until 78z the high-resolution box came first, rounded: a file with %%BoundingBox: 0 0 200 100 and %%HiResBoundingBox: 0.4 0.3 199.3 99.4 was 199bp x 99bp where latex and pdflatex make it 200.75pt x 100.375pt; hep-ex0703011’s eeggmet.eps carries a stale full-page %%HiResBoundingBox (612x792) beside its 540x522 %%BoundingBox.
