std::fs::canonicalize as a path the rest of the system can read: on Windows std returns the verbatim form (\\?\C:\dir\f.tex), which is dropped back to C:\dir\f.tex when that names the same file (a drive path; a \\?\UNC\… share or an over-long path keeps it). Kept verbatim, the prefix reached the source directory and every path built from it — \graphicspath entries \\?\C:\…\tmp/figs/ that matched no file, EPS candidates listed twice, locators printed as //?/C:/….
