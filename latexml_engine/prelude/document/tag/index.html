Structs§

AutoOpen
How readily an element is auto-opened to hold a child it can contain — Perl’s Tag($tag, autoOpen => $x), where any true value counts as 1 and a fraction (ltx:picture’s 0.5, latex_constructs.pool.ltxml:4943) makes the element’s paths lose to those through a full auto-opener (Document.pm:196-199, 220). Kept as a percentage (100 = 1, 50 = 0.5) for the indirect model’s integer arithmetic (compute_indirect_model).
EntryMut
One entry of a TagList edited in place (TagList::get_mut): when it is dropped, an entry whose kind (pending stub, parent, block creator) the edit changed moves to the index of its new kind — an O(1) check when unchanged. The re-filing runs in Drop, so a guard passed to std::mem::forget would leave the index stale (no caller does; debug builds check the index against a scan at every read: review revI7).
TagData
One frontmatter entry: Perl’s [$tag, {%attr}, @content] (Base_Utility.pool.ltxml, PR #2767 frontmatter refactor).
TagList
One tag’s frontmatter entries, Perl’s @{$frontmatter{$tag}} (Base_Utility.pool.ltxml), with the indices of the entries an annotation may attach to kept as the list changes — Perl’s grep { ($$_[1]{role} || '') ne 'pending' } (Base_Utility.pool.ltxml:492), read per annotation instead of rescanned over every entry. The entries are a slice to read; they change only through the list’s own methods, which keep the index exact: push, remove, retain, and TagList::get_mut/TagList::last_mut, whose EntryMut re-files its entry when an edit changed its kind (debug builds also check the index against the scan at every read).
