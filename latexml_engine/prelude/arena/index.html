An arena for interning strings (global, mutable, single thread only)

Note: works under the assumption of a single threaded, short-lived process, where memory starvation will not be an issue. It would need a hard reset if the same process does multiple conversions, and a different implementation if one needs a thread-local arena.

§Borrow safety

A lend (with and its siblings) holds a shared RefCell borrow of the arena for the closure’s duration, so the buffer it lends from cannot move under it. A string interned while a lend is live cannot grow that buffer: it goes to the overflow page, its own Rc<str> under a symbol at or above OVERFLOW_BASE. One string has one symbol across both tiers until a reset: every intern probes the buffer first, then the page, and only a string neither holds is added (to the buffer outside a lend, to the page under one).
