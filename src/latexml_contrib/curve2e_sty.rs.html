1//! curve2e.sty — extensions of the `picture` env (Bezier curves,
2//! arrows, vector drawings) by Claudio Beccari.
3//!
4//! curve2e raw-loads into pictex-style territory: `\Dir@line`,
5//! `\strokepath`, `\d@mX`, `\d@mY`, `\originalmoveto`,
6//! `\pIIe@lineto` and a `\the\edef` pattern that our engine
7//! rejects with "You can't use \edef after \the". Witness paper
8//! arXiv:1408.2108 — amsart + curve2e (LOADED BUT UNUSED in the
9//! body!) → 100+ errors + fatal. Perl converts the same input
10//! with 26 warnings.
11//!
12//! Match Perl: stub the package as a no-op shell so the raw
13//! .sty is never loaded. We provide the `picture` extensions as
14//! pass-throughs (no fancy curves, but no crashes either). If a
15//! paper uses `\Curve` / `\Arc` heavily the visual fidelity
16//! suffers, but for the common case (loaded-but-unused) the
17//! document converts cleanly.
18use latexml_package::prelude::*;
19
20LoadDefinitions!({
21  // curve2e.sty:16-17 hard dependencies (graphicx, color, pict2e), then the
22  // REAL package raw-loaded: with pict2e's driver-level path builders
23  // (`\pIIe@moveto`… in pict2e_sty.rs) and cap/join declarations present,
24  // curve2e's vector algebra (xfp `\fpeval`), `\Arc`/`\VectorArc`/`\VectorARC`,
25  // `\polyline`/`\Vector`/`\segment`, `\Zbox`/`\Pbox`, `\xmultiput` and the
26  // grid commands all run verbatim and render through `\lx@pic@polyline`
27  // (curve2e-manual: the 9-stub binding left 32 undefined-command errors;
28  // Perl's raw load of the same file, lacking the `\pIIe@*` builders, fails
29  // with 102 errors + Fatal). Its `\@picture` redefinition (curve2e.sty:273)
30  // is dead code here — the picture environment is a constructor that records
31  // `\pict@dimen`/`\pict@offset` itself (sect13.rs, pict2e_sty.rs).
32  RequirePackage!("graphicx");
33  RequirePackage!("color");
34  RequirePackage!("pict2e");
35  InputDefinitions!("curve2e", noltxml => true, extension => Some(Cow::Borrowed("sty")));
36  // curve2e.sty:92-96 snapshots pict2e's `\moveto`/`\lineto`/`\curveto` under
37  // `\original*` before wrapping them for the macro-pair `(\P)` form; pin the
38  // snapshots to the stable aliases so the wrappers can never resolve to
39  // themselves (a `\moveto`→`\originalmoveto`→`\moveto` recursion was seen
40  // with the body absorbed verbatim; the user-level primitives accept `(\P)`
41  // directly anyway).
42  RawTeX!(
43    r"\let\originalmoveto\lx@pictii@moveto \let\originallineto\lx@pictii@lineto
44\let\originalcurveto\lx@pictii@curveto"
45  );
46});
