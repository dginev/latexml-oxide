1//! versonotes.sty — notes set on the verso page facing the text.
2//!
3//! `\versonote{text}` writes its note to the `.aux` (versonotes.sty:42-45,
4//! `\verso@note{page}{ypos}{text}`), and the NEXT run sets it on the facing
5//! verso page from the shipout hook (:217-254). A single pass never reads it
6//! back, so every note was lost, in Perl too (no binding; versonotes/sample
7//! recall 61.5 %, sweep #121). Here the note is a margin note where it is
8//! written, as `\marginpar` is (OXIDIZED_DESIGN_DIVERGENCES #290). Guard:
9//! `class_census::versonote_is_a_margin_note`.
10use latexml_package::prelude::*;
11
12#[rustfmt::skip]
13LoadDefinitions!({
14  InputDefinitions!("versonotes", noltxml => true, extension => Some(Cow::Borrowed("sty")));
15  DefMacro!("\\versonote{}", "\\marginpar{#1}");
16});
