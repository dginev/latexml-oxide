165  // Author-block — attach author names, affiliations and emails to structured
166  // `<ltx:creator>`/`<ltx:contact>` frontmatter, NOT loose top-level notes.
167  // Mirrors jheppub_sty.rs (the Perl PR #2767 labeled-affiliation pattern).
168  //
169  // sn-jnl.cls (the witness cls) defines `\author*[N]{name}` (`\@ifstar` →
170  // corresponding vs regular; the optional `[N]` is the affiliation-id list) and
171  // `\affil*[N]{text}`. We collapse the corresponding-vs-regular star (both
172  // become role=author) — we don't distinguish it in the output.
173  //
174  // `OptionalMatch:*` (not a literal `\author*`): our DefMacro prototype parser
175  // treats a `*` immediately after `\author` as a literal Token parameter, not a
176  // CS suffix, so `\author*[]{}` would force a mandatory star and (via a naive
177  // self-forwarding body) recurse forever on a plain `\author{X}` — the
178  // root-cause for 2306.11901. `OptionalMatch:*` makes the star optional, and the
179  // body forwards to `\lx@add@creator` (never re-enters `\author`). The optional
180  // `[N]` becomes the creator's `annotations` (the affiliation ids it references).
181  // (a name list in one `\author` is several people, read as the per-author classes read theirs: Perl, with no sn-jnl
182  // binding, splits it with the kernel's `\author`; 2312.04825, 2501.00473, 2504.09158)
183  DefMacro!(
184    "\\author OptionalMatch:* []{}",
185    "\\lx@add@authors@append[annotations={#2}]{#3}"
