1//! silence.sty — "Selective filtering of warnings and error messages"
2//! (Paul Isambert, v1.5b 2012/07/02; TeX Live
3//! `texmf-dist/tex/latex/silence/silence.sty`).
4//!
5//! No Perl LaTeXML binding exists — neither upstream
6//! (`LaTeXML/lib/LaTeXML/Package/silence.sty.ltxml` is absent) nor in the
7//! installed 0.8.8 tree — so same-host Perl reports the same
8//! `Error:undefined:\WarningFilter` on the witnesses below. Perl only
9//! survives when `--includestyles` raw-loads the real .sty; with the raw
10//! load unavailable (bare mode, or a class whose `\RequirePackage{silence}`
11//! never runs) every silence command is undefined.
12//!
13//! The package exists solely to filter LaTeX's *console* warnings and
14//! errors. It contributes **no document content**, so every public command
15//! is a no-op here. What matters is the ARITY: an undefined `\WarningFilter`
16//! is recovered as a zero-argument `<ltx:ERROR/>`, which leaks its two
17//! braced arguments into the document as visible text (witness 2605.05327
18//! renders "Extended allocation already in use" in the body). Consuming the
19//! arguments is the whole point of the binding.
20//!
21//! Signatures follow silence.sty verbatim:
22//!   * `\SafeMode`, `\BoldMode`                         L71-72
23//!   * `\WarningsOn[list]`, `\WarningsOff*[list]`       L90-114
24//!   * `\WarningFilter*[family]{package}{message}`      L152-164
25//!   * `\ActivateWarningFilters[list]`,
26//!     `\DeactivateWarningFilters[list]`                L199-209
27//!   * `\ActivateFilters[list]`, `\DeactivateFilters[list]` L231-247
28//!   * `\ErrorsOn[list]`, `\ErrorsOff*[list]`           L495-519
29//!   * `\ErrorFilter*[family]{package}{message}`        L521-530
30//!   * `\ActivateErrorFilters[list]`,
31//!     `\DeactivateErrorFilters[list]`                  L567-577
32//!
33//! The message argument is read `Semiverbatim`: silence itself reads it
34//! under `\catcode`\\12` (L186, L554) precisely because filter patterns
35//! quote LaTeX messages containing control sequences and `#`.
36//!
37//! silence also wraps `\PackageWarning` / `\ClassWarning` / `\PackageError`
38//! / `\ClassError` / `\@latex@error` / `\GenericError` (L386-431, L433,
39//! L581-599) to route them through its filter bank. Those are deliberately
40//! NOT touched: LaTeXML's own definitions are what turn them into
41//! `Error:`/`Warning:` diagnostics, and re-pointing them at a filter
42//! silently downgrades real ones. That is not hypothetical — it is why this
43//! binding is registered UNCONDITIONALLY, where the paper-bundled
44//! `arxiv_sty.rs` sibling defers to the raw file under `INCLUDE_STYLES`.
45//! Measured: `\usepackage{silence}\ErrorsOff` followed by a package that
46//! raises `\PackageError` converts at **0 errors** under same-host Perl
47//! 0.8.8 `--includestyles` (which raw-loads silence.sty) and at **1** with
48//! this binding in front of it. Guard:
49//! `107_silence_keeps_diagnostics::silence_errorsoff_does_not_swallow_a_package_error`.
50//! The trade is that silence's own filter *state* is not modelled, which
51//! costs nothing: LaTeXML has no message bank to filter.
52//!
53//! Witnesses: 2605.05327 (`\RequirePackage{silence}` before
54//! `\documentclass`, aa.cls), 2605.06624 (`\usepackage{silence}` +
55//! `\WarningFilter[captions]{caption}{...}` + `\ActivateWarningFilters`),
56//! 2504.08779 / 2509.17283 / 2512.12232 (ascelike-new.cls, whose
57//! `\RequirePackage{silence}` never runs).
58use latexml_package::prelude::*;
59
60LoadDefinitions!({
61  // Options: debrief, immediate, safe, save, saveall, showwarnings,
62  // showerrors (L38-48). All select filter *reporting* behaviour, which
63  // has no analogue here.
64  DeclareOption!(None, {});
65  ProcessOptions!();
66
67  // L71-72
68  def_macro_noop("\\SafeMode")?;
69  def_macro_noop("\\BoldMode")?;
70
71  // L90-114. `\WarningsOff` takes an optional star OR an optional list;
72  // `\WarningsOn` only the list.
73  def_macro_noop("\\WarningsOn []")?;
74  def_macro_noop("\\WarningsOff OptionalMatch:* []")?;
75
76  // L152-164 / L521-530. `*` selects "safe" (`\makeatletter`) reading of
77  // the message; both modes gobble it here.
78  def_macro_noop("\\WarningFilter OptionalMatch:* [] {} Semiverbatim")?;
79  def_macro_noop("\\ErrorFilter OptionalMatch:* [] {} Semiverbatim")?;
80
81  // L199-209 / L231-247 / L567-577
82  def_macro_noop("\\ActivateWarningFilters []")?;
83  def_macro_noop("\\DeactivateWarningFilters []")?;
84  def_macro_noop("\\ActivateErrorFilters []")?;
85  def_macro_noop("\\DeactivateErrorFilters []")?;
86  def_macro_noop("\\ActivateFilters []")?;
87  def_macro_noop("\\DeactivateFilters []")?;
88
89  // L495-519
90  def_macro_noop("\\ErrorsOn []")?;
91  def_macro_noop("\\ErrorsOff OptionalMatch:* []")?;
92});
