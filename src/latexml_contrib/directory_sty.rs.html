1//! directory.sty — address-book style directories (the bibliography end).
2//!
3//! `directory.sty:235` defines `\directory[ext]{bibs}` to write `\bibdata` to
4//! the `.aux` and `\@input@{\jobname.ext}` — a `.bbl` only a bibtex run with
5//! the package's `.bst` produces, which LaTeXML never has; the `.bib` list is
6//! stringified into that `\write` and never re-read, so the directory
7//! vanished at 0 errors (Perl raw-loads the same package and loses it too, at
8//! 4 errors). A directory is by definition the complete address list — the
9//! manual itself calls `\nodir{*}` (directory.sty:321, the package's
10//! `\nocite`) — so the command is the kernel's `\lx@bibliography` over all
11//! entries (`latex_constructs.pool.ltxml:3942`, `:4214` for `\nocite`), the
12//! same interception Perl makes for bibunits (OXIDIZED_DESIGN_DIVERGENCES
13//! #87). The extension argument selects the `.bbl` and has no LaTeXML role.
14use latexml_package::prelude::*;
15
16#[rustfmt::skip]
17LoadDefinitions!({
18  InputDefinitions!("directory", noltxml => true, extension => Some(Cow::Borrowed("sty")),
19    handleoptions => true);
20  DefMacro!("\\directory [Default:bbl] {}", "\\nocite{*}\\lx@bibliography{#2}");
21});
