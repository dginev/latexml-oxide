1//! textpos: the raw package, with an absolute block placed where it is written.
2//!
3//! In absolute mode (`[absolute]`, `\textblockorigin`) textpos collects each block in `\TP@holdbox`
4//! (textpos.sty:372-376) and draws the hold box only from a shipout hook (`shipout/background` or
5//! `/foreground`, :389-397; `\EveryShipout` on old kernels). LaTeXML ships no pages, so the hook never fires and
6//! every absolute block was lost, without a diagnostic (Perl has no textpos binding and loses them too). A block is
7//! content the author placed on the page; with one page and no coordinates, it is placed where it is written —
8//! in a margin note it stays in the note (OXIDIZED_DESIGN_DIVERGENCES #416). What is placed is the block's text box
9//! at its natural size (`\TP@textbox`, :257): the hold box holds it inside textpos's zero-size positioning boxes
10//! (:326-371), which a renderer draws over the text around it. The hold box is emptied as the block is placed, so
11//! the end-of-document flush (:92) finds nothing; `discardcontent` (no `\ifTP@displayholdbox`) and `noshowtext`
12//! (no `\ifTP@showtext`; pdflatex draws an empty labelled frame) place nothing, nor does a block that shows nothing
13//! (`typesets_content`, as eso-pic's one-shot overlay): autonum.sty:159-173 captures each display environment's
14//! `\\` and `\label` in an absolute block at (0,0) holding an empty `equation`, which became an empty numbered
15//! equation after the abstract (2605.31413). A block of rules alone is placed decoration and is dropped too, as
16//! eso-pic's rule-only overlay is. Firing the shipout hooks at the end
17//! instead would move every block out of reading order and run every package's page furniture (eso-pic,
18//! draftwatermark, background). Witnesses: pdfcomment example ×3, stubs_ex, niepraschk-eso-pic, ftc-notebook.
19use latexml_package::prelude::*;
20
21LoadDefinitions!({
22  InputDefinitions!("textpos", noltxml => true, extension => Some(Cow::Borrowed("sty")));
23  // `\box`, unless the box shows nothing.
24  DefPrimitive!("\\lx@TP@placebox Number", sub[(number)] {
25    match remove_value(&s!("box{}", number.value_of())) {
26      Some(Stored::Digested(block)) if typesets_content(&block) => Ok(vec![block]),
27      _ => Ok(Vec::new()),
28    }
29  });
30  RawTeX!(
31    r"\newbox\lx@TP@textbox
32\let\lx@TP@endtextblock\TP@endtextblock
33\def\TP@endtextblock#1#2#3#4{\ifTP@abspos\setbox\lx@TP@textbox\copy\TP@textbox\fi
34  \lx@TP@endtextblock{#1}{#2}{#3}{#4}%
35  \ifTP@abspos\global\setbox\TP@holdbox\box\voidb@x
36    \ifTP@displayholdbox\ifTP@showtext\lx@TP@placebox\lx@TP@textbox\fi\fi
37  \fi}"
38  );
39});
