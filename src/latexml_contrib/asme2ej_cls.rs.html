14  // amsthm — only ifthen/times/mathptm/ifpdf — and defines its OWN trivlist
15  // `\proof`/`\endproof` at L1242-1245). Eager-loading amsthm here is the
16  // eager-preload anti-pattern: a paper that does `\let\proof\relax` (to clear
17  // the class's conflicting proof) and THEN `\usepackage{amsthm}` to install
18  // amsthm's proof env — exactly the documented asme2ej idiom — finds amsthm
19  // "already loaded" (so its `\usepackage` is a no-op), leaving `\proof`
20  // relaxed → `{proof}` undefined where Perl (which raw-loads the class, never
21  // pre-loading amsthm) is clean. Let the document's own `\usepackage{amsthm}`
22  // be the first/real load. Witness 2102.03856 (`\let\proof\relax` +
23  // `\usepackage{...,amsthm}` + `\begin{proof}`).
24  // Eager xcolor preload removed for Perl parity: it makes a later document
