1//! Binding for `derivative.sty` — Simon Jensen's expl3 package of derivative and
2//! differential operators (`\odv`, `\pdv`, `\mdv`, `\fdv`, `\adv`, `\jdv` and the
3//! matching differentials `\odif`, `\pdif`, `\mdif`, `\fdif`, `\adif`, `\jdif`,
4//! plus user-declared ones via `\DeclareDerivative`/`\DeclareDifferential`).
5//!
6//! There is no Perl binding, and physics.sty only covers the overlap
7//! (`\dv`/`\pdv`/`\fdv`/`\dd`), so a paper's derivative-only commands — most
8//! commonly `\mdif` (material differential) — leaked as undefined control
9//! sequences without raw TeX loading. The package is ~1800 lines of expl3 that
10//! our engine already executes correctly (verified: raw-loading it under
11//! `--includestyles` converts cleanly), so — exactly like `commath_sty` — the
12//! faithful binding just force-raw-loads the real `.sty` rather than
13//! reimplementing it. `noltxml` bypasses the default "raw loading is off" gate;
14//! the `\usepackage` options (e.g. `[italic=true]`) are forwarded by
15//! `InputDefinitions`. Reading a host texmf `.sty` via kpathsea is in scope
16//! (CLAUDE.md Guiding Principles). Witness html_feedback#6876 (arXiv:2311.15365v3,
17//! `[italic=true]`, 36 uses of `\mdif`).
18use latexml_package::prelude::*;
19
20LoadDefinitions!({
21  InputDefinitions!("derivative", noltxml => true, extension => Some(Cow::Borrowed("sty")));
22});
