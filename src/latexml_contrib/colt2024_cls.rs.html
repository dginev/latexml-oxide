1//! Stub for colt2024.cls (COLT 2024 — Conference on Learning Theory); also
2//! serves the sibling PMLR proceedings classes via the registry — colt2025,
3//! colt2026, l4dc2026 (Learning for Dynamics & Control), neus2025 (NeuS) — all
4//! identical in the load-shape (`\LoadClass[pmlr]{jmlr}` +
5//! `\coltauthor`→`\author`). This is the concrete instance of the general
6//! "unknown author-bundled PMLR class" pattern (PLANS 13(f): raw-loader native
7//! fallbacks); until that generalization lands, new PMLR proceedings classes are
8//! routed here by name.
9//!
10//! colt2024.cls does `\LoadClass[pmlr]{jmlr}` and defines `\coltauthor` in its
11//! body: the review form `\newcommand{\coltauthor}[1]{}` (anonymizes), the final
12//! form `\newcommand{\coltauthor}[1]{\author{#1}}`. As an unbound class Rust uses
13//! the OmniBus fallback, which dep-scans the cls (so jmlr loads) but does NOT
14//! execute the cls body — so `\coltauthor` was undefined where Perl raw-executes
15//! the cls and defines it. Route to jmlr (Rust's jmlr binding handles `\editor`/
16//! `\jmlrworkshop`/`\acks`, the rest of the cls body) and define `\coltauthor` as
17//! the final-submission form `\author{#1}` — content-preserving (real author
18//! names, correct for published arXiv versions). Witness 2308.08218.
19use latexml_package::prelude::*;
20
21LoadDefinitions!({
22  LoadClass!("jmlr");
23  DefMacro!("\\coltauthor{}", "\\author{#1}");
24});
