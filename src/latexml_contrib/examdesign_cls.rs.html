1//! examdesign.cls — exams with question banks, answer keys and randomised
2//! versions. Loaded RAW, with one seam opened first.
3//!
4//! examdesign.cls:323-344 repurposes `\section`: `\def\section{\stepcounter
5//! {section}\setcounter{question}{1}}` / `\def\endsection{\make@qlist}`, and
6//! its question environments are `\begin{section}…\end{section}` wrappers
7//! (examdesign.cls:802-812 `matching`, `fillin`, `truefalse`, `shortanswer`,
8//! `multiplechoice`). The kernel `\section` is `locked` (latex_constructs.rs
9//! `DefMacro!("\\section", …, locked=>true)`, Perl latex_constructs.pool:559),
10//! so both engines refused the class's definition and ran `\@startsection`
11//! on an environment body — `Expected opening '{'`, `\lx@tag Attempt to end
12//! mode restricted_horizontal`, then `\endgroup` errors at every `\end` (Perl
13//! 67 errors, Rust 100+ → Fatal on examplea/exampleb/examplec). pdflatex is
14//! clean because the class owns `\section`. Same precedent as the `\chapter`
15//! unlock for source3body (latex_constructs.rs, KNOWN_PERL_ERRORS #141).
16//! Guard: `perfect_kernel_batch54::examdesign_owns_section_as_an_environment`.
17
18use latexml_package::prelude::*;
19
20LoadDefinitions!({
21  assign_value("\\section:locked", false, Some(Scope::Global));
22  InputDefinitions!("examdesign", noltxml => true, extension => Some(Cow::Borrowed("cls")));
23});
