1//! caption2.sty — the obsolete caption package (v2.2, a caption3 front end; TL
2//! `tex/latex/caption/caption2.sty`), still loaded directly and by journal classes
3//! (w-art.cls, SCGE/scpma, POWFI, rmf-d).
4//!
5//! Without a binding of its own the name falls back to the caption binding by its
6//! glued version suffix (Perl Package.pm:2180, `find_file_fallback`), which lacks
7//! caption2's interface: `\captionstyle{center}` was undefined (843 papers in arXiv
8//! run 336, Perl the same). Registered by its exact name, this binding outranks that
9//! fallback, requires the caption binding (which renders the captions) and defines
10//! caption2's commands, so a document's settings are taken. The label delimiter and
11//! separator are printed text and close the caption's tag; the other settings are layout
12//! — the caption style, margins, one-line centering, label font — so the commands store
13//! what they set and the styles they name never run. A document's `\captionlabeldelim` reaches
14//! the tag's `close` as Perl's `toAttribute` renders it (a skip is its spaces), so a `\kern`
15//! delimiter shows as `\kern…` text there (Perl 0.8.8 the same); `\captionlabelfalse`
16//! (caption2.sty:144-149) is not honoured — the label is kept.
17//! Witnesses math0601389, 1307.4815, 1911.03646, 2507.04618.
