1//! refstyle.sty — flexible cross-reference styling (`\newref{type}{...}`,
2//! `\figref`, `\vref`, `\Vref`, `\Ref`, ...).
3//!
4//! The real package is loaded raw, with its options: refstyle.sty and its
5//! refstyle.cfg are pure TeX that the engine runs clean — the `\newref`
6//! templates define `\figref`/`\secref`/`\eqref`/…, and `\RS@removedef`
7//! (`\let\eqref\@undefined`) is seen as undefined by `\@ifundefined`
8//! (latex.ltx:1729-1735), so the amsmath `\eqref` redefinition does not fire
9//! refstyle's "already defined" error. The former stub (`\newref` a no-op,
10//! `\vref` → `\ref`) rested on a mis-probed `\@ifundefined` gap; it left every
11//! `\newref`-built command undefined and lacked the internals documents call
12//! directly — LyX preambles emit `\RS@ifundefined{subref}{…}` (refstyle.sty:51-57;
13//! uspatent/PatentApplicationGuide: an `<ERROR>` in the preamble stranded the
14//! title, 3 schema errors). Perl has no refstyle binding (raw only under
15//! `--includestyles`, 0 errors on that witness).
16//!
17//! Witnesses: arXiv:2009.10518, arXiv:1804.06350 (refstyle + amsmath +
18//! cleveref), uspatent/PatentApplicationGuide.
19//! Guard: `perfect_kernel_batch56::refstyle_loads_raw_with_its_internals`.
20use latexml_package::prelude::*;
21
22LoadDefinitions!({
23  InputDefinitions!("refstyle", noltxml => true, extension => Some(Cow::Borrowed("sty")),
24    handleoptions => true);
25});
