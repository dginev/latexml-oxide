188  // {tocentry} environment — the journal's table-of-contents graphic, which
189  // does not belong in the body.
190  //
191  // It must NOT be suppressed with `\iffalse`…`\fi`. Conditional skipping
192  // matches `\fi` by MEANING and expands nothing on the way (TeX's rule, and
193  // ours — `skip_conditional_body` in `conditional.rs`), so an
194  // `\end{tocentry}` whose macro *body* is `\fi` is invisible to it: the skip
195  // ran to end of file and swallowed the rest of the paper, `\bibliography`
196  // included. That one line cost 42 of the 342 residual papers in the
197  // 2605+2606 bibliography-absence cohort their entire bibliography, and
198  // showed up as `Error:expected:\fi \iffalse` pointing at EOF — which reads
199  // like a source defect and is not one. Witnesses 2606.14933, 2605.00451,
200  // 2606.00264; audit family F6.
201  //
202  // Perl never reaches this: it has no achemso binding at all and falls back
203  // to OmniBus (`Warning:missing_file:achemso`), leaving `{tocentry}`
204  // undefined. pdflatex of course renders these papers fine.
205  //
206  // Nor may the body simply be DIGESTED and dropped (`DefEnvironment!
207  // ("{tocentry}", "")`): these graphics are TikZ/`\includegraphics` blocks
208  // that error heavily out of context. Measured on the same cohort, that
209  // turned three papers from "no bibliography" into no OUTPUT AT ALL —
210  // 2606.08929, 2606.12056 and 2606.15422 went from 1 error to 513 and a
211  // fatal (`\lxSVG@endscope`, `undefined:\@startsection`).
212  //
213  // So skip the body as RAW LINES, the way comment.sty's excluded
214  // environments do (`comment_sty.rs`) — no digestion, no conditionals. The
215  // `\end{tocentry}` is consumed as text, so it is deliberately left
216  // undefined.
217  DefConstructor!(T_CS!("\\begin{tocentry}"), None, None,
218  after_digest => {
219    // The rest of the `\begin{tocentry}` line — which may already carry the
220    // matching `\end{tocentry}`, as the one-line form does.
221    if let Some(first) = read_raw_line()
222      && first.contains("\\end{tocentry}")
223    {
224      return Ok(Vec::new());
225    }
226    let mut nlines = 0;
227    while let Some(line) = read_raw_line() {
228      if line.contains("\\end{tocentry}") {
229        break;
230      }
231      nlines += 1;
232    }
233    note_progress(&s!("[Skipped tocentry ({nlines} lines)]"));
234    Ok(Vec::new())
235  });
