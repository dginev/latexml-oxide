1//! nlctuserguide.sty — Nicola Talbot's user-guide package (the glossaries,
2//! glossaries-extra, datatool, mfirstuc, bib2gls … manuals).
3//!
4//! A manual documents every command, option and term in one
5//! `\nlctuserguidegls{…}` block (nlctuserguide.sty:2928-3016): its writer
6//! macros (`\gcmd`, `\gopt`, `\gidx`, `\gterm`, `\gabbr`, …) serialize each item
7//! as a bib2gls record into `\jobname-gls.bib` through `\glsbibwriteentry` /
8//! `\glsbibwritefield` (:2883-2892), and `\nlctuserguideloadgls` (:3062-3160)
9//! asks the external bib2gls for the `.glstex` that defines the entries. No
10//! `.glstex` ships in TeX Live, and neither engine runs bib2gls, so every entry
11//! stayed undefined: the command summaries, term lists and `\gls` references of
12//! the Talbot manuals were lost (glossaries-extra-manual recall 50.9 %,
13//! datatool-user 67.4 %, glossaries-user 68.0 %, sweep #121; Perl has no binding).
14//!
15//! Here the two writers define the entries in the run instead, as bib2gls's
16//! output would (its `\bibglsnew…` commands are `\newglossaryentry` /
17//! `\newabbreviation` calls): the record type becomes the entry's category and
18//! its glossary follows the resource's `entry-type-aliases` (`type=index`,
19//! terms `dual-type=main`, icons `type=symbols`). Parents are defined before
20//! their children, as bib2gls orders them. Their glossary definitions are
21//! emitted at `\begin{document}`, once every entry exists (glossaries_sty.rs
22//! `\iflx@glossaries@defer`), as the `.glstex` defines all entries before any
23//! is typeset: a description may reference an entry defined after it. The icon
24//! entries (`\symboldefinitions`, :792-817, written as raw `@icon` records) are
25//! defined from the same macros. A real bib2gls run with the `.glstex` took
26//! mfirstuc-manual from 76.6 % to 92.8 % recall
27//! (OXIDIZED_DESIGN_DIVERGENCES #292). Guard: `class_census::nlctuserguide_entries_defined_in_run`.
