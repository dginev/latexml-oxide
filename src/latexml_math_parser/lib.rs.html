1//! The math parser of latexml-oxide: it turns the token lists of each formula (`ltx:XMath`) into a parse tree,
2//! the work of Perl LaTeXML's `LaTeXML::MathParser`.
3//!
4//! Where Perl uses a Parse::RecDescent grammar, this crate uses a highly ambiguous Marpa grammar and prunes the
5//! parses in its semantic rules. [`MathGrammar`] is the grammar, built once and shared; [`MathParser`] parses the
6//! formulas of a document with it (`parse_math`).
7//!
8//! Read next: [MATH_PARSER_AND_ASF.md](https://github.com/dginev/latexml-oxide/blob/main/docs/math/MATH_PARSER_AND_ASF.md) and
9//! [OXIDIZED_DESIGN_MATH.md](https://github.com/dginev/latexml-oxide/blob/main/docs/math/OXIDIZED_DESIGN_MATH.md).

45/// Print and reset the thread-local Marpa ASF instrumentation
46/// counters (codex's `MARPA_ASF_STATS=1` plan from
47/// `marpa/docs/ASF_PERFORMANCE_FINDINGS.md`). No-op when the env
48/// var is unset.
49///
50/// Intended to be called once per document conversion from the
51/// `latexml_oxide` converter so each `.tex → .html` run emits at
52/// most one stats line; aggregation across a corpus is done
53/// offline by piping stderr through `grep MARPA_ASF_STATS`.
54pub fn report_and_reset_asf_stats() {
55  if marpa::asf::asf_stats_enabled()
56    && let Some(snapshot) = marpa::asf::snapshot()
57  {
58    eprintln!("{}", snapshot.as_log_line());
59    marpa::asf::reset();
60  }
61}
