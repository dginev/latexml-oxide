113/// Derive the cooperative soft-RSS budget (bytes) from the hard `--max-memory`
114/// ceiling (MiB). The soft fuse sits at 75% of the ceiling, leaving ~25%
115/// headroom for the post-processing phase (libxml DOM + XSLT) that runs above
116/// digestion and which this cooperative guard cannot see. `0` in → `0` out
117/// (disabled), so `--max-memory=0` disables the whole memory limit. This keeps
118/// `--max-memory` the single knob: the hard Watchdog rides the ceiling, this
119/// fuse rides a fixed fraction below it — no independent second number.
120///
121/// The 75% factor reproduces the historical ~4.5 GB-under-6 GiB relationship at
122/// the 6144 MiB default (→ 4608 MiB) while scaling with any user-chosen ceiling
123/// (so a tight `--max-memory` also gets the graceful cooperative failure first,
124/// and a generous one raises both guards together).
125pub fn soft_cap_from_ceiling(max_memory_mib: u64) -> u64 {
126  (max_memory_mib.saturating_mul(3) / 4).saturating_mul(1024 * 1024)
127}

129/// Minimum boxes that must accumulate before the **soft-RSS** yield branch may
130/// fire (the box-budget branch is unaffected and still yields on its own).
131///
132/// The soft-RSS test is a LEVEL test with no hysteresis: `rss > watermark`. A
133/// document whose irreducible resident floor sits above the watermark therefore
134/// latches it on permanently and yields at every legal seam, accumulating
135/// almost nothing between yields. Measured on the 131 MB witness at
136/// `--max-memory 48000` (watermark 12 GB, pass-1 RSS 13.3-14.9 GB — above it
137/// for the entire run): **24,051,712 yields** producing **459,579 segments
138/// averaging 5.5 KB**, against a box budget of ~2.0 M boxes that would on its
139/// own have yielded ~12 times. The same binary on a witness that never crosses
140/// its watermark yields **8** times.
141///
142/// A floor restores the trigger's intent — "respond to memory pressure sooner
143/// than the box budget would" — without the degenerate per-seam case. 1024
144/// boxes is ~2.5 MB of box memory at the measured 2416 B/box, i.e. negligible
145/// against any watermark large enough to matter, so the pressure response stays
146/// effectively immediate while the yield count drops by ~3 orders of magnitude.
147///
148/// **The floor is waived under real pressure** — see `soft_yield_is_urgent`.
149/// The soft-RSS branch exists because "the box budget alone assumes a per-box
150/// footprint; on content whose real cost per box is higher (math-dense trees),
151/// RSS crosses the ceiling long before the box count does". A floor that
152/// applied unconditionally would blunt that valve for exactly the pathological
153/// input it was added for: 1024 boxes of ordinary content is ~2.5 MB, but 1024
154/// boxes of something pathological is unbounded, and the fuse could fire inside
155/// one un-yielded window. So above a higher RSS mark the floor is ignored.
156///
157/// Env-overridable for calibration only (`LATEXML_SOFT_YIELD_MIN_BOXES`),
158/// deliberately not a CLI flag — same reasoning as `LATEXML_SPILL_AT_MIB`.
159/// Override the soft-RSS floor directly, bypassing the env lookup. For tests
160/// that need to drive the degenerate (floor = 1) and fixed (floor = N) regimes
161/// in one process — see `115_soft_yield_floor`.
162pub fn set_soft_yield_min_boxes(boxes: usize) { SOFT_YIELD_MIN_BOXES.set(Some(boxes)); }

164/// Is memory pressure URGENT enough to waive the soft-yield floor?
165///
166/// Halfway from the spill watermark to the cooperative fuse. Below this the
167/// floor applies and yields stay coarse; above it every legal seam yields, as
168/// before this floor existed — so a document whose per-box footprint is wildly
169/// larger than the 2416 B the box budget assumes still gets the immediate
170/// response the soft-RSS branch was introduced to provide, instead of Fatal-ing
171/// inside a 1024-box window.
172fn soft_yield_is_urgent(rss_kb: u64) -> bool {
173  soft_yield_urgency(
174    rss_kb,
175    spill_mark_kb().map(|kb| kb * 1024),
176    resolve_rss_cap(),
177  )
178}

180/// The pure predicate behind [`soft_yield_is_urgent`], split out so the
181/// arithmetic is unit-testable (an integration test would need a real RSS cap
182/// near the test process's actual footprint — flaky by construction on the
183/// 16 GB CI runner). `watermark`/`fuse` in bytes, `rss_kb` in KiB.
184fn soft_yield_urgency(rss_kb: u64, watermark: Option<u64>, fuse: Option<u64>) -> bool {
185  match (watermark, fuse) {
186    (Some(watermark), Some(fuse)) if fuse > watermark => {
187      rss_kb.saturating_mul(1024) >= watermark + (fuse - watermark) / 2
188    },
189    // No fuse to divide (`--max-memory=0`): the floor always applies, matching
190    // the watermark fallback's own "no ceiling to race" reasoning.
191    _ => false,
192  }
193}

200/// Digests `f`'s token as a delimiter: tex.web §1160 `scan_delimiter` takes a letter or other character by its
201/// `\delcode`, never its `\mathcode`, so a math-active character (`\mathcode`(="8000`, the active `(` a `\left(`) is
202/// that character, not its active meaning — which, `\left(` itself, recursed without end (2609.40266).
203pub fn digest_as_delimiter<T>(f: impl FnOnce() -> T) -> T {
204  // Restored on unwind too: a sweep catches a paper's panic and converts the next on this thread.
205  struct Restore(bool);
206  impl Drop for Restore {
207    fn drop(&mut self) { DIGESTING_DELIMITER.set(self.0); }
208  }
209  let _restore = Restore(DIGESTING_DELIMITER.replace(true));
210  f()
211}

276/// The RAM watermark, in bytes above the conversion's starting RSS ([`spill_mark_kb`]), at which streaming pass 1
277/// begins spilling closed subtrees to disk — the second derived quantity of the single
278/// `--max-memory` knob, and deliberately NOT a flag of its own (a watermark a
279/// user could raise above the fuse would Fatal before it ever spilled).
280///
281/// **A third of the cooperative fuse.** Not a half: the yields fire only at
282/// legal seams (a large alignment digests straight through any threshold), the
283/// RSS sample lags by up to 1024 guard ticks, and per-run bookkeeping creeps
284/// monotonically — measured on the 131 MB witness, a half-of-fuse watermark
285/// steadied pass 1 around 33 GB and the creep then walked it into the 37.7 GB
286/// fuse and died, where a third completed at 28.1 GB peak.
287///
288/// **With `--max-memory=0` there is no fuse to divide, and the watermark must
289/// still exist**: disabling the death ceiling says "do not kill me", not "let
290/// the machine run out". Fall back to an eighth of physical RAM, which lands
291/// the same 12 GiB on a 96 GB host that the validated 48 GiB ceiling derives.
292pub fn spill_watermark_bytes() -> Option<u64> {
293  if let Some(bytes) = SPILL_WATERMARK_OVERRIDE.with(|c| c.get()) {
294    return Some(bytes);
295  }
296  // Calibration override (`LATEXML_SPILL_AT_MIB`), deliberately env-only and
297  // NOT a CLI flag: a user-settable watermark could be raised above the fuse,
298  // producing a run that Fatals before it ever spills. It exists so the
299  // fuse-fraction below can be re-derived by measurement rather than argued.
300  if let Some(mib) = std::env::var("LATEXML_SPILL_AT_MIB")
301    .ok()
302    .and_then(|v| v.parse::<u64>().ok())
303  {
304    return Some(mib.saturating_mul(1024 * 1024));
305  }
306  match resolve_rss_cap() {
307    Some(fuse) => Some(fuse / 3),
308    None => crate::watchdog::total_memory_bytes().map(|ram| ram / 8),
309  }
310}

323/// The resident set (KB) at which this conversion spills: [`spill_watermark_bytes`] above its starting RSS, never
324/// closer to the fuse (process RSS, it guards the machine) than two watermarks — the headroom the fuse fraction was
325/// calibrated for (a half-of-fuse mark crept into the fuse, [`spill_watermark_bytes`]). With the default third-of-fuse
326/// watermark that cap is the watermark itself, so under a fuse the mark is absolute, as before the conversion's
327/// baseline (revSTRM: a worker near its recycle threshold must not spill later than the calibration allows); the
328/// baseline moves the mark only without a fuse or under a smaller calibration watermark. Order independence rests on a
329/// switched conversion writing the eager XML, not on the mark. A zero watermark (a test's or a calibration's
330/// `LATEXML_SPILL_AT_MIB=0`) puts every seam over it.
331pub fn spill_mark_kb() -> Option<u64> {
332  let watermark_kb = spill_watermark_bytes()? / 1024;
333  Some(spill_mark(
334    CONVERSION_RSS_BASELINE_KB.get(),
335    watermark_kb,
336    resolve_rss_cap(),
337  ))
338}

340/// The arithmetic of [`spill_mark_kb`] (KB; `fuse` in bytes).
341fn spill_mark(baseline_kb: u64, watermark_kb: u64, fuse: Option<u64>) -> u64 {
342  if watermark_kb == 0 {
343    return 0;
344  }
345  let mark = baseline_kb.saturating_add(watermark_kb);
346  match fuse {
347    Some(fuse) => mark.min(
348      (fuse / 1024)
349        .saturating_sub(2 * watermark_kb)
350        .max(watermark_kb),
351    ),
352    None => mark,
353  }
354}

375/// Resolve the effective soft-RSS budget: `None` = disabled (no ceiling),
376/// `Some(n)` = abort above `n` bytes. Precedence: the explicit
377/// [`set_memory_cap`] override, else `LATEXML_RSS_CAP_BYTES`, else the 4.5 GB
378/// default. A cap of `0` from EITHER source resolves to `None`, so
379/// `--max-memory=0` / `LATEXML_RSS_CAP_BYTES=0` mean "no limit" — not "abort
380/// immediately" (a literal `0` compared as `rss_bytes > 0` is always true).
381///
382/// Note the env is consulted only when nothing set the override — i.e. only for
383/// embedders that never call [`apply_memory_ceiling`]. Every path in the
384/// `latexml_oxide` binary calls it, so there `--max-memory` always wins.
385pub fn resolve_rss_cap() -> Option<u64> {
386  let cap = RSS_CAP_OVERRIDE.with(|c| c.get()).unwrap_or_else(|| {
387    std::env::var("LATEXML_RSS_CAP_BYTES")
388      .ok()
389      .and_then(|v| v.parse::<u64>().ok())
390      .unwrap_or(4_500_000_000)
391  });
392  (cap > 0).then_some(cap)
393}

395/// Check if conversion has timed out. Returns Err if deadline exceeded.
396///
397/// Also samples RSS via /proc/self/status every ~1024 calls and raises
398/// `Fatal:oom:memory_budget` if the process is approaching the worker
399/// memory cap. R35.A witnesses (plain-TeX `$$\displaylines{ … \picture
400/// … }$$`, 7 sandbox papers from 1999–2006) trigger a runaway where
401/// `set_alloc_error_hook` fires AFTER the process has already allocated
402/// ~5+ GB; that hook can't easily walk back the call site under
403/// `panic="unwind"`. Sampling RSS here at well below the OS ulimit
404/// gives us a clean diagnostic and a unwound stack via `fatal!`.
405pub fn check_timeout() -> Result<()> {
406  // Box-list cycle guard fired in `push_box_list` (which cannot unwind) —
407  // surface it here, the regular Result-returning digestion checkpoint.
408  // (The `stomach_mut!` macro is defined textually below; use STOMACH
409  // directly, with a try-borrow so a transient borrow just defers to the
410  // next tick.)
411  let pending = STOMACH
412    .try_borrow_mut()
413    .ok()
414    .and_then(|mut s| s.pending_cycle_fatal.take());
415  if let Some((category, msg)) = pending {
416    use crate::common::error::{Error as LatexmlError, ErrorTarget};
417    return Err(LatexmlError::from(ErrorData {
418      target: ErrorTarget::Stomach,
419      category,
420      message: msg,
421    }));
422  }
423  CONVERSION_DEADLINE.with(|d| {
424    if let Some(deadline) = d.get()
425      && Instant::now() > deadline
426    {
427      fatal!(Timeout, Convert, "Conversion timed out!");
428    }
429    Ok(())
430  })?;
431  // Soft memory budget: every ~1024 calls, peek at our own RSS.
432  // 1024-call cadence keeps overhead negligible on the hot path
433  // (each call reads /proc/self/statm — a single syscall).
434  std::thread_local! {
435    static MEM_TICK: Cell<usize> = const { Cell::new(0) };
436  }
437  let tick = MEM_TICK.with(|t| {
438    let v = t.get().wrapping_add(1);
439    t.set(v);
440    v
441  });
442  if tick & 0x3FF == 0 {
443    // Single RSS-reading seam: `watchdog::process_rss_kb` (this was a second
444    // hand-rolled /proc parser; PR #249 review P3-12). When the watchdog
445    // grows macOS/Windows backends, this cap follows for free.
446    {
447      {
448        if let Some(rss_kb) = crate::watchdog::process_rss_kb() {
449          LAST_SAMPLED_RSS_KB.set(rss_kb);
450          let rss_bytes = rss_kb * 1024;
451          // R35.A safety cap: 4.5 GB RSS. Real documents in the wp5 /
452          // canvas3 corpus stay below 1 GB peak RSS, so this is well
453          // into pathological territory while leaving headroom for
454          // post-processing (XSLT, MathML chain).
455          // Override via LATEXML_RSS_CAP_BYTES env or `set_memory_cap`; a
456          // value of 0 (or `--max-memory=0`) disables it — see
457          // `resolve_rss_cap`.
458          //
459          // This is a *per-process* fuse, deliberately kept LOW. It must
460          // bound ONE conversion: in production the binary is
461          // single-conversion (one paper per process), and a massively
462          // parallel fleet runs many such processes at once — so the
463          // aggregate host RSS is `N_processes × this_cap`. Raising the
464          // default would let a busy fleet OOM the machine. The
465          // `cortex_worker` fleet OVERRIDES this env to its own per-child
466          // ceiling (`--child-mem-limit-mb`).
467          //
468          // The ONE multi-conversion-in-one-process case is the test
469          // harness: libtest spawns a thread per test, so at `cargo
470          // test`'s default parallelism on a many-core box (e.g. -j128)
471          // the process-wide RSS is the *sum* over all in-flight
472          // conversions and trips this single-conversion cap on
473          // otherwise-fine documents. That is handled NOT by raising this
474          // default but by the harness setting LATEXML_RSS_CAP_BYTES at
475          // test setup (latexml_oxide `util::test::init_test_rss_cap`).
476          // Any other single-process-many-conversion driver should do the
477          // same.
478          if let Some(watermark) = STREAMING_RESTART_WATERMARK.get()
479            && rss_bytes > watermark
480          {
481            // One stop per arming: the rerun is streaming and never armed.
482            STREAMING_RESTART_WATERMARK.set(None);
483            note_streaming_restart_signal(RestartSignal::Watermark);
484            use crate::common::error::{Error as LatexmlError, ErrorCategory, ErrorTarget};
485            return Err(LatexmlError::from(ErrorData {
486              target:   ErrorTarget::Timeout,
487              category: ErrorCategory::StreamingRestart,
488              message:  format!(
489                "eager digestion reached the streaming-restart watermark: RSS {} MB > {} MB; \
490                 rerunning under --streaming",
491                rss_bytes / 1_000_000,
492                watermark / 1_000_000
493              ),
494            }));
495          }
496          if let Some(cap) = resolve_rss_cap()
497            && rss_bytes > cap
498          {
499            // R35.A debug: when LATEXML_DEBUG_MEMBUDGET=1 is set, dump
500            // a stack backtrace before exiting so we can identify the
501            // expansion loop responsible. Backtrace allocation is
502            // fine here — we haven't hit the OS ulimit yet (we're
503            // 1.5 GB below it by default).
504            if std::env::var_os("LATEXML_DEBUG_MEMBUDGET").is_some() {
505              eprintln!(
506                "[membudget] RSS {} MB > cap {} MB — dumping backtrace",
507                rss_bytes / 1_000_000,
508                cap / 1_000_000
509              );
510              // Permanent LATEXML_DEBUG_MEMBUDGET diagnostic: which
511              // accumulating list is growing? (MEMORY.md's OOM-diagnosis
512              // recipe depends on this dump — do not remove as "temp".)
513              if let Ok(st) = STOMACH.try_borrow() {
514                eprintln!(
515                  "[membudget] box_list={} (~{} MB est) token_stack={} boxing={} localized_box_list_total={}",
516                  st.box_list.len(),
517                  estimate_box_list_bytes(&st.box_list) / 1_000_000,
518                  st.token_stack.len(),
519                  st.boxing.len(),
520                  st.localized_box_list
521                    .iter()
522                    .map(|(v, _)| v.len())
523                    .sum::<usize>(),
524                );
525              }
526              if let Ok(g) = gullet::GULLET.try_borrow() {
527                let pb = g.runtime.as_ref().map(|r| r.pushback.len()).unwrap_or(0);
528                eprintln!("[membudget] gullet pushback={pb} progress={}", g.progress);
529              }
530              let bt = std::backtrace::Backtrace::force_capture();
531              eprintln!("{bt}");
532            }
533            // The actionable half of the message is a KNOWN NEED, not an
534            // anomaly: a document's peak scales with macro expansion and math
535            // density (the 131 MB witness needs ~23 GB resident just to
536            // stream through core), so the honest advice is "raise the
537            // ceiling", plus the derived flag value so the user knows which
538            // number they are raising — the cap here is the 75% fuse, not
539            // the `--max-memory` figure they typed. The latch lets the
540            // binary's end-of-run report add the kernel-tracked peak
541            // (`watchdog::peak_memory_report`, emitted only when this fired).
542            crate::watchdog::note_memory_fatal();
543            note_streaming_restart_signal(RestartSignal::Fuse);
544            fatal!(
545              Timeout,
546              MemoryBudget,
547              format!(
548                "Memory budget exceeded: RSS {} MB > cap {} MB (the cooperative fuse at 75% of \
549                 --max-memory={}). This document needs a larger ceiling: rerun with a higher \
550                 --max-memory on a machine with enough free RAM.",
551                rss_bytes / 1_000_000,
552                cap / 1_000_000,
553                (cap * 4).div_ceil(3 * 1024 * 1024),
554              )
555            );
556          }
557        }
558      }
559    }
560  }
561  Ok(())
562}

702/// Ask digestion to yield at legal fragment seams once `budget` boxes have
703/// accumulated at the current level (`None` restores eager digestion). Set by
704/// the streaming pass-1 driver; the budget is a box COUNT — the driver derives
705/// it from the byte ceiling via the measured per-box footprint, the same basis

707pub fn set_fragment_yield_budget(budget: Option<usize>) {

716  // yielding, and preserved when it disables at end-of-digestion (the driver
717  // clears the budget before the tail phases, and telemetry/tests read the
718  // count after the conversion returns).
719  if enabling {
720    FRAGMENT_YIELD_COUNT.set(0);
721  }
722}

846/// Digests a frame's `beforeAfterGroup` tokens into the current box list ([`execute_before_after_group`]).
847fn digest_before_after_group(beforeafter: VecDeque<Stored>) -> Result<()> {
848  if !beforeafter.is_empty() {
849    let mut result = Vec::with_capacity(beforeafter.len());
850    for beforeafter_frame in beforeafter.into_iter() {
851      match beforeafter_frame {
852        Stored::Tokens(frametoks) => result.push(frametoks.be_digested()?),
853        Stored::Token(frametok) => result.push(frametok.be_digested()?),
854        _ => {
855          // Unexpected value type in beforeAfterGroup — skip silently
856          // rather than panic (could occur with non-standard TeX constructs)
857        },
858      }
859    }
860    // Perl Stomach.pm:182-183 — every digested item must be Box-like
861    // (TBox / List / Whatsit / Alignment); anything else is a binding
862    // bug. Emit Error per offender; the Box-like items still flow
863    // through to box_list so partial output is preserved.
864    // Perl additionally calls `@result = (makeMisdefinedError(@result))`
865    // collapsing everything to a single error sentinel — we keep
866    // the partial-output behaviour (Rust-side divergence; surfacing
867    // *the* offending item via Error! is what the harness needs to
868    // report, while the rest of the box stream is still useful).
869    //
870    // Implementation note: walk the result list with an index loop
871    // rather than `retain(|d| {…})`. The Error! macro can `return
872    // Err(…)` on the max-errors / runaway-loop guards, and a closure
873    // returning `bool` can't propagate that out — only an explicit
874    // for-loop in the surrounding `Result<()>` body can.
875    let mut filtered = Vec::with_capacity(result.len());
876    for d in result {
877      let is_box = matches!(
878        d.data(),
879        DigestedData::TBox(_)
880          | DigestedData::List(_)
881          | DigestedData::Whatsit(_)
882          | DigestedData::Alignment(_)
883      );
884      if is_box {
885        filtered.push(d);
886      } else {
887        let kind_label = match d.data() {
888          DigestedData::Postponed(_) => "Postponed",
889          DigestedData::KeyVals(_) => "KeyVals",
890          DigestedData::RegisterValue(_) => "RegisterValue",
891          DigestedData::Comment(_) => "Comment",
892          _ => "non-Box",
893        };
894        Error!(
895          "misdefined",
896          "<beforeAfterGroup>",
897          format!(
898            "Expected a Box|List|Whatsit, but got '{}' — dropping",
899            kind_label
900          )
901        );
902      }
903    }
904    // Route the group's digested boxes through the GUARDED appender (not a
905    // raw `box_list.extend`) so the stomach's cycle / count / byte-budget
906    // runaway guards see them. This is the path a grouped drawing loop
907    // (`\@whiledim{…\hbox{…}…}`) flushes through, so bypassing it let a
908    // heavy-box runaway accumulate unguarded until only the Linux RSS cap
909    // caught it. Witness math0102053.
910    extend_box_list(filtered);
911  }
912  Ok(())
913}

915/// Removes the last/current stack frame, ending a TeX group
916pub fn pop_stack_frame(nobox: bool) -> Result<()> { pop_stack_frame_with(nobox, true) }
917
918fn pop_stack_frame_with(nobox: bool, run_after_group: bool) -> Result<()> {
919  if *TRACE_FRAMES {
920    let current_token = get_current_token().unwrap_or_else(|| T_CS!("\\relax"));
921    eprintln!(
922      "[frames] pop  nobox={nobox} id={} depth {} -> {} at {current_token} (bound_mode={})",
923      current_frame_id(),
924      get_frame_depth(),
925      get_frame_depth().saturating_sub(1),
926      lookup_string_from_sym(crate::pin!("BOUND_MODE"))
927    );
928  }
929  let mut after = remove_value("afterGroup");
930  let depth_before = get_frame_depth();
931  execute_before_after_group()?;
932  if *TRACE_FRAMES && get_frame_depth() != depth_before {
933    eprintln!(
934      "[frames] beforeAfterGroup changed the depth {depth_before} -> {} (top id {} now)",
935      get_frame_depth(),
936      current_frame_id()
937    );
938  }
939  // Guard: `perfect_kernel_batch64zf::setspace_switch_in_a_plain_group_rearms_on_the_enclosing_group`.
940  // Perl Stomach.pm:308-314 takes the frame's afterGroup list by REFERENCE before
941  // the beforeAfterGroup hooks run, and pushValue (State.pm:218-223) appends to that
942  // same array, so an `\aftergroup` a hook performs is honoured after the pop. Here
943  // the list was taken by value, and a hook's push re-created the frame's slot,
944  // which the pop then discarded: append what the hooks queued on this frame.
945  if get_frame_depth() == depth_before
946    && let Some(Stored::VecDequeStored(queued)) = remove_value("afterGroup")
947    && !queued.is_empty()
948  {
949    match after {
950      Some(Stored::VecDequeStored(ref mut entries)) => entries.extend(queued),
951      _ => after = Some(Stored::VecDequeStored(queued)),
952    }
953  }
954  // The closers this frame still owes move to the frame now innermost ([`OWED_BRACES`]).
955  let owed = [OWED_BRACES, OWED_ENDGROUPS].map(owed_closers);
956  pop_frame()?;
957  for (key, debt) in [OWED_BRACES, OWED_ENDGROUPS].into_iter().zip(owed) {
958    if debt > 0 {
959      assign_frame_value(key, Stored::Int(owed_closers(key) + debt));
960    }
961  }
962  if !nobox {
963    {
964      stomach_mut!().boxing.pop(); // For begingroup/endgroup
965    }
966  }
967  if !run_after_group {
968    after = None;
969  }
970  if let Some(Stored::VecDequeStored(after_entries)) = after {
971    for entry in after_entries.into_iter().rev() {
972      match entry {
973        Stored::Tokens(t) => gullet::unread(t),
974        Stored::Token(t) => gullet::unread_one(t),
975        other => panic!(r"\aftergroup should be used with tokens, got instead: {other:?}"),
976      };
977    }
978  }
979  Ok(())
980}

1048/// A group closer `closer` (`}`/`\egroup`, or `\endgroup` when `semi_simple`)
1049/// meeting the frame of an environment: end the environment first, as its own
1050/// closer would. Returns true when it acted.
1051///
1052/// LaTeX's `\begin` is `\begingroup` + `\X` (latex.ltx:15346-15355) and its
1053/// `\end` is `\endX` + `\endgroup` (latex.ltx:15386-15393); the environment's
1054/// local state goes with whichever closer ends that group. LaTeXML keeps a
1055/// mode frame for the environment's body (Perl Package.pm:1919-1925 `bgroup`
1056/// then `beginMode`, :1972 `beginMode` for the bare `\X`), which a plain
1057/// closer cannot pop (Perl Stomach.pm:343-375 errors and keeps the frame), so
1058/// the body swallowed the rest of the document. The recovery is tex.web
1059/// §1064-1065 `off_save`'s shape — back-input the closer, insert what the
1060/// innermost group expects:
1061/// * a bare `\X` frame (`{\thm …}`, `{\quote …}`, `\begingroup\rem …\endgroup`):
1062///   insert `\endX` and re-read the closer, which then ends the enclosing group
1063///   (or meets that group's own mismatch, reported there);
1064/// * a `\begin{X}` frame met by `\endgroup` (the ALICE author block): that
1065///   `\endgroup` closes `\begin`'s group (tex.web §1063 `end_group` against a
1066///   `semi_simple_group`: `unsave`), so the environment's own `\end{X}` takes
1067///   its place and pops the frame — the group is closed once.
1068///
1069/// What TeX itself reports decides the diagnostic, by the kind of group the
1070/// environment's begin code leaves open (`lx@env@tex@group`, a [`TexGroup`]
1071/// name; tex.web §269 group codes):
1072/// * none (`\trivlist`, `\list`): TeX has no mismatch at all (a bare `\X` opens
1073///   no group; `\begin`'s group is any `\endgroup`'s) — an Info;
1074/// * a `semi_simple_group` (`\begingroup` or a nested `\begin`: setspace,
1075///   lscape, multicols, beamer's blocks): `}` is §1068-1069 `extra_right_brace`
1076///   — an Error; `\endgroup` just unsaves it (§1063), which is clean for a bare
1077///   `\X` (`\begingroup\multicols{2} …\endgroup` — an Info: `\endX` takes the
1078///   `\endgroup`'s place and the enclosing group stays open, as in TeX) but
1079///   leaves `\begin`'s own group open for a `\begin{X}`, reported at the next
1080///   `\end` — an Error;
1081/// * a box or colour group (a float's `\@xfloat`, a minipage's `\vbox\bgroup`):
1082///   §1064 `off_save` "Missing } inserted" for `\endgroup`, the box ended early
1083///   for `}` (§1068 `handle_right_brace`) — an Error.
1084///
1085/// The kind is a frame value that follows TeX's group state: raw end code that
1086/// closes the box group without the binding's own closer (floatrow's
1087/// `\float@end` calling latex.ltx's `\@endfloatbox` against the bound `\@float`)
1088/// sets it to none (sect09.rs `\lx@endfloatbox@close`), so a closer that meets
1089/// the frame afterwards is clean in TeX and logs the Info. A `}` against a
1090/// `\begin{X}` frame (§1068-1069 `extra_right_brace`, "Extra }, or forgotten
1091/// \endgroup", the brace deleted) and any closer against an environment in math
1092/// mode (its `$` or `$$` opened a `math_shift_group`, §1064/§1069) are not
1093/// recovered here: both stay with the caller's Error. One attempt per frame:
1094/// the marker is taken, so a redefined `\endX` that does not close the frame
1095/// falls back to the Error. The frame is flagged (`environment_ended_by_group`) so that end
1096/// code TeX would not run — `\end`'s hooks, a theorem's end mark — is skipped.
1097/// Witnesses: 1210.5866 1111.2539 2405.03639 1703.03321 2202.11643 0812.1147
1098/// 1009.2722 1312.6689 1905.06220 2207.12734 2308.09714 2503.00772 1403.7312
1099/// 2104.03038 (`{\thm …}`), 2412.14057 (`{\quote …}`), 1702.01612 1909.03158
1100/// (`\begin{flushleft} … \endgroup`). A REVTeX 3 `\figure{N}` caption line
1101/// opens no group without the `floats` option (aps.sty:614-630, revtex3_support
1102/// overrides the flag): cond-mat9607130 is pdflatex-clean and gets the Info.
1103fn close_environment_frame(closer: Token, semi_simple: bool) -> Result<bool> {
1104  // Only the closer itself is re-read: a binding that calls `egroup()` /
1105  // `endgroup()` from its own code (a cell, a box argument) keeps the Error.
1106  let is_closer = if semi_simple {
1107    x_equals(&closer, &T_CS!("\\endgroup"))
1108  } else {
1109    gullet::is_right_brace(&closer)
1110  };
1111  if !is_closer {
1112    return Ok(false);
1113  }
1114  if matches!(
1115    lookup_string_from_sym(crate::pin!("MODE")).as_str(),
1116    "math" | "display_math"
1117  ) {
1118    return Ok(false);
1119  }
1120  let (end, bare) = if is_value_bound("lx@env@bare@end", Some(0)) {
1121    (remove_value("lx@env@bare@end"), true)
1122  } else if semi_simple && is_value_bound("lx@env@begin@end", Some(0)) {
1123    (remove_value("lx@env@begin@end"), false)
1124  } else {
1125    return Ok(false);
1126  };
1127  let Some(Stored::Token(end)) = end else {
1128    return Ok(false);
1129  };
1130  let environment = lookup_token_sym(crate::pin!("groupInitiator"))
1131    .map(|t| t.to_string())
1132    .unwrap_or_default();
1133  assign_frame_value_sym(crate::pin!("lx@env@ended@by@group"), true);
1134  let kind = if is_value_bound("lx@env@tex@group", Some(0)) {
1135    TexGroup::from_name(&lookup_string("lx@env@tex@group")).unwrap_or(TexGroup::None)
1136  } else {
1137    TexGroup::None
1138  };
1139  let tex_error = match kind {
1140    TexGroup::None => None,
1141    TexGroup::SemiSimple if !semi_simple => Some(
1142      "TeX: Extra }, or forgotten \\endgroup (the } meets the \\begingroup the begin code opened)",
1143    ),
1144    TexGroup::SemiSimple if !bare => Some(
1145      "TeX: the \\endgroup closes the \\begingroup the begin code opened; \\begin's own group stays open \
1146       and TeX reports the mismatch at the next \\end",
1147    ),
1148    TexGroup::SemiSimple => None,
1149    TexGroup::Box if semi_simple => Some(
1150      "TeX: the \\endgroup meets the box group the begin code opened, and TeX reports a group mismatch \
1151       (Missing } inserted, or a later error once the group is gone)",
1152    ),
1153    TexGroup::Box => Some(
1154      "TeX: the } ends the box group the begin code opened, not the enclosing one, and TeX reports a mismatch later",
1155    ),
1156  };
1157  if let Some(tex) = tex_error {
1158    Error!(
1159      "unexpected",
1160      closer,
1161      s!("Environment {environment} opened a TeX group of its own: ending it with {end}"),
1162      tex
1163    );
1164  } else {
1165    Info!(
1166      "unexpected",
1167      closer,
1168      s!("ends the group around environment {environment}: inserting {end}")
1169    );
1170  }
1171  // A bare `\X` frame normally re-reads the closer for the enclosing group;
1172  // but an `\endgroup` against the `\begingroup` a bare `\X` opened only unsaves
1173  // that group (§1063), so `\endX` takes its place and the enclosing group
1174  // stays open, as in TeX (`{\multicols{2} …\endgroup}`).
1175  let reread = bare && !(semi_simple && kind == TexGroup::SemiSimple);
1176  if reread {
1177    gullet::unread(Tokens::new(vec![end, closer]));
1178  } else {
1179    gullet::unread_one(end);
1180  }
1181  Ok(true)
1182}

1190/// `\end{X}` met while plain `\begingroup` groups opened inside X stand above X's own frame — raa.cls:322-349
1191/// `\institutename`: `\begin{flushleft}\begingroup … \end{flushleft}\endgroup`. That is TeX's scoping, not an error:
1192/// groups are untyped between `\begingroup` and `\endgroup` (tex.web §1063-1069), so `\end{X}`'s `\endgroup`
1193/// (latex.ltx:15384-15393 `\end` = `\endX` + `\@checkend` + `\endgroup`; `\@checkend` reads `\@currenvir`, still X)
1194/// closes the innermost one, and the class's own `\endgroup` closes the group `\begin{X}` opened. Here, as there:
1195/// * the innermost plain group is popped, its local values undone (`\end`'s `\endgroup`);
1196/// * X ends: its open paragraph, its mode and its boxing level end here, so its element ends where `\end{X}` stands
1197///   and its own `beforeAfterGroup` work (an alignment, `\@add@centering`) acts on its body;
1198/// * X's frame stays open as a plain `\begingroup` group, keeping X's other local values (its `\@currenvir`, `\\`, a
1199///   value set before the class's `\begingroup`) until the `\endgroup` that closes it.
1200///
1201/// Perl ends the mode against the plain group instead and errors (Stomach.pm:544-550 "Attempt to end mode"); with
1202/// the error a raw class's title-page deposit was dropped — title, authors, abstract and keywords (KNOWN_PERL_ERRORS
1203/// #1207, OXIDIZED_DESIGN_DIVERGENCES #965). Only that shape acts: every frame above X a plain `\begingroup` group
1204/// (no mode, no box, no environment marker, and no environment recorded but X's own — not a raw `\newenvironment`'s
1205/// `\begin{Y}`; an X this branch ended earlier, its group still open, records X), the environment open X itself
1206/// (`\@checkend`), X's frame the `\begin{X}` of this very `\end{X}`, and X neither a math environment nor one whose
1207/// begin code opened a box group — where TeX itself errs (`\@badend`, or the box's own group). Otherwise false, and
1208/// the caller's `end_mode` raises today's Error. Witnesses 1404.3644, 1304.5354, 1508.02561, 1509.00139, 2004.06992,
1209/// 2110.11117, 2306.16795, 1604.05586, 2003.13998, 2102.01352, 2511.10805 (raa, raa_twocolumn). Guards
1210/// `perfect_kernel_batch98d::*`.
1211pub fn end_environment_over_plain_groups(name: &str, end: Token) -> Result<bool> {
1212  // The `\@checkend` the caller's `unexpected_end_closure` just ran: the environment open is X, and no group above
1213  // X's frame records another (a raw `\newenvironment`'s `\begin{Y}`) — else LaTeX's `\@badend`. A group recording X
1214  // is an X this branch ended earlier (`\begin{X}\begin{X}\begingroup … \end{X}…\end{X}`), as TeX's `\@currenvir`.
1215  if lookup_string("current_environment") != name {
1216    return Ok(false);
1217  }
1218  let depth = get_frame_depth();
1219  let records_only_x = |frame: usize| {
1220    !is_value_bound("current_environment", Some(frame))
1221      || matches!(value_in_frame("current_environment", frame),
1222        Some(Stored::String(open)) if arena::with(open, |open| open == name))
1223  };
1224  let plain_group = |frame: usize| {
1225    matches!(
1226      value_in_frame("groupNonBoxing", frame),
1227      Some(Stored::Bool(true))
1228    ) && is_value_bound("groupNonBoxing", Some(frame))
1229      && records_only_x(frame)
1230      && [
1231        "BOUND_MODE",
1232        "lx@env@begin@end",
1233        "lx@env@bare@end",
1234        "lx@env@ended@by@group",
1235      ]
1236      .iter()
1237      .all(|key| !is_value_bound(key, Some(frame)))
1238  };
1239  let mut frame = 0;
1240  while frame < depth && plain_group(frame) {
1241    frame += 1;
1242  }
1243  if frame == 0 || frame >= depth {
1244    return Ok(false);
1245  }
1246  let own_frame = is_value_bound("lx@env@begin@end", Some(frame))
1247    && matches!(value_in_frame("lx@env@begin@end", frame), Some(Stored::Token(t)) if t == end);
1248  let frame_string = |key: &str| match value_in_frame(key, frame) {
1249    Some(Stored::String(value)) if is_value_bound(key, Some(frame)) => {
1250      arena::with(value, str::to_string)
1251    },
1252    _ => String::new(),
1253  };
1254  let bound_mode = frame_string("BOUND_MODE");
1255  let box_group = frame_string("lx@env@tex@group") == TexGroup::Box.as_str();
1256  if !own_frame || bound_mode.is_empty() || bound_mode.ends_with("math") || box_group {
1257    return Ok(false);
1258  }
1259  Info!(
1260    "unexpected",
1261    end,
1262    s!(
1263      "{end} closes the \\begingroup opened inside the environment ({frame} open above it); the environment's own \
1264       group stays open for the next \\endgroup"
1265    )
1266  );
1267  if bound_mode.ends_with("vertical") {
1268    leave_horizontal_internal();
1269  }
1270  // `\end`'s `\endgroup`: the innermost group only.
1271  pop_stack_frame(true)?;
1272  let own = frame - 1;
1273  // X's element-closing work, run in its body as `end_mode`'s pop runs it.
1274  if let Some(Stored::VecDequeStored(work)) = replace_value_in_frame(
1275    "beforeAfterGroup",
1276    own,
1277    Stored::VecDequeStored(VecDeque::new()),
1278  ) {
1279    digest_before_after_group(work)?;
1280  }
1281  // X's mode and environment markers go; the rest of its frame is now a plain group's.
1282  for key in [
1283    "BOUND_MODE",
1284    "MODE",
1285    "IN_MATH",
1286    "lx@env@begin@end",
1287    "lx@env@tex@group",
1288    "lx@until@terminal",
1289    "lx@until@depth",
1290  ] {
1291    unbind_value_in_frame(key, own);
1292  }
1293  replace_value_in_frame("groupNonBoxing", own, Stored::Bool(true));
1294  stomach_mut!().boxing.pop();
1295  Ok(true)
1296}

1303/// End a level of binding by popping the last stack frame,
1304/// undoing whatever bindings appeared there, and also
1305/// decrementing the level of boxing.
1306pub fn egroup() -> Result<()> {
1307  if get_current_token().is_some_and(|t| gullet::is_right_brace(&t)) && close_template_brace() {
1308    return Ok(());
1309  }
1310  if is_value_bound("BOUND_MODE", Some(0)) {
1311    // Diagnostic for cluster investigation (project_explsyntax_midload.md).
1312    if *TRACE_BOUND_MODE {
1313      let mode = lookup_string_from_sym(crate::pin!("MODE"));
1314      let bound = lookup_string_from_sym(crate::pin!("BOUND_MODE"));
1315      let cur_tok = get_current_token()
1316        .map(|t| t.to_string())
1317        .unwrap_or_default();
1318      eprintln!(
1319        "[trace] egroup ERROR: cur_tok={cur_tok} BOUND_MODE={bound} MODE={mode}\n{}",
1320        std::backtrace::Backtrace::force_capture()
1321      );
1322    }
1323    // Last stack frame was a mode switch!?!?!
1324    // A bare `\X` environment inside the closed group ends first.
1325    if let Some(closer) = get_current_token()
1326      && close_environment_frame(closer, false)?
1327    {
1328      return Ok(());
1329    }
1330    // Don't pop if there's an error; maybe we'll recover?
1331    // Perl Stomach.pm:347-349 passes currentFrameMessage as a SEPARATE
1332    // Error detail (its own line), not merged into the primary message.
1333    // After a resource Fatal the recovery pass only drains pending closers:
1334    // that noise is not reported — `error::emit_record` drops every Error
1335    // once `resource_fatal_latched()`.
1336    Error!(
1337      "unexpected",
1338      get_current_token().unwrap_or_else(|| T_CS!("\\?")),
1339      s!(
1340        "Attempt to close a group that switched to mode {}",
1341        lookup_string_from_sym(crate::pin!("MODE"))
1342      ),
1343      current_frame_message()
1344    );
1345  } else if lookup_bool_sym(crate::pin!("groupNonBoxing")) {
1346    // or group was opened with \begingroup
1347    Error!(
1348      "unexpected",
1349      get_current_token().unwrap_or_else(|| T_CS!("\\?")),
1350      "Attempt to close boxing group",
1351      current_frame_message()
1352    );
1353  } else {
1354    // A `}` that closes a `\left` group (its group code, latexml_engine tex_math.rs `\lx@math@left@group`): tex.web
1355    // §1069 `extra_right_brace` reports "Extra }, or forgotten \right." and deletes the brace; here the group closes,
1356    // as Perl closes it, so the formula stays well nested — a Warning (user ruling 2026-10-11 on TeX-only errors).
1357    // Deleting it as TeX does leaves the enclosing `{` group open, which our `$` defers to rather than closing
1358    // (65d round 7, h1/e1: open, SYNC row MS). OXIDIZED_DESIGN #530. Guard
1359    // `perfect_kernel_batch65d::brace_closing_a_left_group_warns`.
1360    if in_left_group() && get_current_token().is_some_and(|t| gullet::is_right_brace(&t)) {
1361      Warn!(
1362        "unexpected",
1363        "}",
1364        "Extra }, or forgotten \\right.",
1365        "A } closed the group of a \\left; the group ends without its \\right."
1366      );
1367    }
1368    // Don't pop if there's an error; maybe we'll recover?
1369    pop_stack_frame(false)?;
1370  }
1371  // Perl's egroup does NOT touch $ALIGN_STATE — tracked at scan level only.
1372  Ok(())
1373}

1385/// undoing whatever bindings appeared there.

1390    let loc = gullet::get_locator();

1396        loc,
1397        std::backtrace::Backtrace::force_capture()
1398      );

1400      eprintln!(
1401        "[trace] endgroup pre-depth={depth} bound_top={bound} tok={} at {}",
1402        tok, loc
1403      );
1404    }
1405  }

1432  // same dumps. A raw file's `\endgroup` against an `\hbox` frame is Perl's

1434  // probe: one Error, where the silent pop cost three later ones).

1439      let bound = lookup_string_from_sym(crate::pin!("BOUND_MODE"));
1440      eprintln!(
1441        "[trace] endgroup ERROR: BOUND_MODE={bound} MODE={mode}\n{}",
1442        std::backtrace::Backtrace::force_capture()
1443      );
1444    }
1445    // Last stack frame was a mode switch!?!?!
1446    // An environment's frame: a bare `\X` ends inside the group, a
1447    // `\begin{X}` ends with it.
1448    if let Some(closer) = get_current_token()
1449      && close_environment_frame(closer, true)?
1450    {
1451      return Ok(());
1452    }
1453    let mode = lookup_string_from_sym(crate::pin!("MODE"));
1454    if mode == "math" || mode == "display_math" {
1455      // tex.web §1063/§1064 `off_save`: `\endgroup` against a math_shift_group
1456      // inserts the missing `$` ("Missing $ inserted"), closes the math and
1457      // re-reads the `\endgroup`. Perl (Stomach.pm:367-369) only reports the
1458      // mismatch and leaves the math frame on the stack, so every later closer
1459      // re-errors and `<ltx:Math>` leaks to the document root — tikz calc's
1460      // bailout `\tikz@cc@end$` (tikzlibrarycalc.code.tex:118-129) eats the
1461      // injected `$` and `\tikz@finish` (tikz.code.tex:2500-2508) re-inserts
1462      // the orphaned one as real math (calc_fraction_partway_bailout_mode_frame:
1463      // pdflatex 3 / Perl 24 / Rust 23; kblocks-doc, ozguide, nathguide,
1464      // chemobabel carry the cascade). `}`/`\egroup` keep TeX's §1069 shape
1465      // (the brace is dropped, math stays open). OXIDIZED_DESIGN_DIVERGENCES
1466      // #195. Guard: `perfect_kernel_batch56::endgroup_against_open_math_inserts_the_missing_dollar`.
1467      let closer = get_current_token().unwrap_or_else(|| T_CS!("\\endgroup"));
1468      Error!(
1469        "expected",
1470        "$",
1471        "Missing $ inserted",
1472        s!("I've inserted an end-math symbol before {closer}.")
1473      );
1474      let mut toks = vec![T_MATH!()];
1475      if mode == "display_math" {
1476        toks.push(T_MATH!());
1477      }
1478      toks.push(closer);
1479      gullet::unread(Tokens::new(toks));
1480      return Ok(());
1481    }
1482    // Don't pop if there's an error; maybe we'll recover?
1483    // Settled dead end (K9): inserting the box's `}` here (tex.web §1064
1484    // `off_save`) reaches whichever nested consumer is reading, not the box
1485    // reader that owns the frame, and only doubled the count (modernposter,
1486    // dsptricks); the `\globaldefs` bookkeeping exemption was the real msc
1487    // root (state.rs `assign_local_unconditional`).
1488    // Perl Stomach.pm:367-369: currentFrameMessage is a SEPARATE detail.
1489    Error!(
1490      "unexpected",
1491      get_current_token()
1492        .map(|t| t.to_string())
1493        .unwrap_or_else(|| String::from("\\?")),
1494      s!("Attempt to close a group that switched to mode {mode}"),
1495      current_frame_message()
1496    );
1497  } else if !lookup_bool_sym(crate::pin!("groupNonBoxing")) {
1498    // A bare environment whose body is read in a boxing frame of its own — a brace-less `\abstract`'s
1499    // capture (`\lx@add@frontmatter@until`, marked by sect05.rs `\lx@abstract@bare@frame`) — ends as any
1500    // bare `\X` does (witness 2305.17823).
1501    if let Some(closer) = get_current_token()
1502      && close_environment_frame(closer, true)?
1503    {
1504      return Ok(());
1505    }
1506    // or group was opened with \bgroup
1507    Error!(
1508      "unexpected",
1509      get_current_token()
1510        .map(|t| t.to_string())
1511        .unwrap_or_else(|| String::from("\\?")),
1512      "Attempt to close non-boxing group",
1513      current_frame_message()
1514    );
1515  } else {
1516    pop_stack_frame(true)?;
1517  }
1518  Ok(())
1519}

1534/// [`set_mode`] with the bound mode that was in force before the caller bound
1535/// the new one: [`begin_mode_opt`] binds `BOUND_MODE` first and reads the
1536/// previous value before it does (Perl `beginMode` reads `$prevbound` before
1537/// its `assignValue`, Stomach.pm:503-507).
1538fn set_mode_from(mode: &str, prevbound: &str) -> Result<()> {
1539  // Perl reads `$wasmath` from MODE (Stomach.pm:504); there MODE differs from
1540  // BOUND_MODE only by the vertical/horizontal toggle, never in math. Rust
1541  // forces MODE to `internal_vertical` inside a math-level `\noalign`
1542  // (tex_tables.rs), so the bound mode is the faithful test: an `\hbox` in
1543  // `$$\eqalignno{…\noalign{\hbox{where}}…}$$` gets the pre-math font back.
1544  let wasmath = prevbound.ends_with("math");
1545  let ismath = mode.ends_with("math");
1546  // Perl: beginMode maps to internal mode names, but set_mode stores as-is
1547  // We also set BOUND_MODE so end_mode can find it
1548  let bound_mode = bindable_mode(mode).unwrap_or(mode);
1549  // Diagnostic
1550  if *TRACE_BOUND_MODE {
1551    eprintln!(
1552      "[trace] set_mode mode={mode} bound_mode={bound_mode}\n{}",
1553      std::backtrace::Backtrace::force_capture()
1554    );
1555  }
1556  assign_frame_value("BOUND_MODE", arena::pin(bound_mode));
1557  assign_frame_value("MODE", arena::pin(bound_mode));
1558  assign_value("IN_MATH", ismath, Some(Scope::Local));
1559  // Perl Stomach.pm:514-535: nothing when the bound mode is unchanged; the
1560  // math font on entering math; and the pre-math text font back ONLY when
1561  // leaving math (`elsif ($wasmath)`). Restoring it on every other change
1562  // undid a text font switch at the next `\hbox` inside a `\vbox` inside
1563  // math: fancyvrb's `BVerbatim[baseline=c]` (`$\vcenter\bgroup`,
1564  // fancyvrb.sty:1103-1105) lost its `\ttfamily` (cascade-french).
1565  if bound_mode == prevbound {
1566  } else if ismath {
1567    let curfont = lookup_font().unwrap();
1568    // When entering math mode, we set the font to the default math font,
1569    // and save the text font for any embedded text.
1570    assign_value("savedfont", curfont.clone(), Some(Scope::Local));
1571    // see get_script_level()
1572    assign_value("script_base_level", stomach!().boxing.len(), None);
1573    let isdisplay = mode.starts_with("display");
1574    assign_value("IN_MATH_DISPLAY", isdisplay, Some(Scope::Local));
1575    let new_font = Rc::new(lookup_mathfont().unwrap().merge(Font {
1576      color: curfont.color,
1577      bg: curfont.bg,
1578      size: curfont.size,
1579      mathstyle: if isdisplay {
1580        Some("display".into())
1581      } else {
1582        Some("text".into())
1583      },
1584      ..Font::default()
1585    }));
1586    assign_value(
1587      "initial_math_font",
1588      Stored::Font(new_font.clone()),
1589      Some(Scope::Local),
1590    );
1591    assign_font(new_font, Some(Scope::Local));
1592    // Perl Stomach.pm:505 — `$STATE->assignValue(fontfamily => -1, 'local');`
1593    // Resets `\fam` (whose getter reads `fontfamily`) on math entry so that
1594    // text-mode `\rm` (which sets `fontfamily=0`) doesn't leak into math.
1595    assign_value("fontfamily", -1_i64, Some(Scope::Local));
1596  } else if wasmath {
1597    let curfont = lookup_font().unwrap();
1598    // When entering text mode, we should set the font to the text font in use before the math
1599    // but inherit color and size
1600    let saved_opt = lookup_value("savedfont");
1601    if let Some(Stored::Font(saved_font)) = saved_opt {
1602      assign_font(
1603        Rc::new(saved_font.merge(Font {
1604          color: curfont.color,
1605          bg: curfont.bg,
1606          size: curfont.size,
1607          ..Font::default()
1608        })),
1609        Some(Scope::Local),
1610      );
1611    }
1612  }
1613  Ok(())
1614}

1648/// Begin processing in `mode`; one of "text", "display-math" or "inline-math".
1649/// This also begins a new level of grouping and switches to a font
1650/// appropriate for the mode.
1651/// If `noframe` is true, skip pushing a stack frame (e.g. for \begin{document}).
1652/// Perl: sub beginMode (Stomach.pm lines 474-517)
1653pub fn begin_mode(mode: &str) -> Result<()> { begin_mode_opt(mode, false) }
1654/// Like `begin_mode`, but with an explicit `noframe` option.
1655/// When `noframe` is true, no stack frame is pushed (the caller already did bgroup).
1656pub fn begin_mode_opt(mode: &str, noframe: bool) -> Result<()> {
1657  if let Some(bound_mode) = bindable_mode(mode) {
1658    // Perl #2798: beginning a vertical or display-math mode ends the current
1659    // paragraph first (leaveHorizontal), UNLESS the *user* mode is an inline
1660    // form (inline_internal_vertical / inline_math) — inline blocks must not
1661    // break the surrounding paragraph. `leave_horizontal` is itself a no-op
1662    // unless mid-paragraph (MODE==horizontal), so this only fires when a
1663    // vertical/display construct is encountered inside a paragraph.
1664    let is_display = bound_mode.starts_with("display");
1665    let is_vertical = is_display || bound_mode.contains("vertical");
1666    let is_inline = mode.contains("inline");
1667    if is_vertical && !is_inline {
1668      leave_horizontal()?;
1669    }
1670    if !noframe {
1671      push_stack_frame(false); // Effectively bgroup
1672    }
1673    // Diagnostic: tracking who binds BOUND_MODE during raw .sty load
1674    // (gated by LXML_TRACE_BOUND_MODE env var to avoid noise in normal runs).
1675    // See project_explsyntax_midload.md memory for the active investigation.
1676    if *TRACE_BOUND_MODE {
1677      eprintln!(
1678        "[trace] begin_mode_opt mode={mode} noframe={noframe} bound_mode={bound_mode}\n{}",
1679        std::backtrace::Backtrace::force_capture()
1680      );
1681    }
1682    let prevbound = lookup_string_from_sym(crate::pin!("BOUND_MODE"));
1683    // Perl: $STATE->assignValue(BOUND_MODE => $mode, 'local');
1684    assign_frame_value("BOUND_MODE", arena::pin(bound_mode));
1685    // tex.web §211's inner sign, kept as a frame-bound flag: a FRAMED mode
1686    // switch is a box or math interior (`\hbox`/`\vbox`/`\parbox`/minipage,
1687    // `$…$`), where `\ifinner` is true; display math is positive `mmode`
1688    // (outer); the document body's frameless `internal_vertical` and plain
1689    // `{…}` groups bind nothing, so the main galley stays outer. The mode
1690    // STRINGS serve both galley and box (`internal_vertical`), so `\ifinner`
1691    // on them said inner at the body top after `\par` — paracol.sty:1996
1692    // `\ifinner\@parmoderr` (tidyres); Perl identical. The binding is
1693    // undone with the frame at `end_mode`. Guard:
1694    // `perfect_kernel_batch54::ifinner_is_the_box_frame_sign`.
1695    if !noframe {
1696      assign_frame_value_sym(crate::pin!("INNER_BOX"), bound_mode != "display_math");
1697    }
1698    set_mode_from(bound_mode, &prevbound)?;
1699    // Perl Stomach.pm lines 527-530: inject \everymath or \everydisplay tokens
1700    // Display math gets \everydisplay, inline math gets \everymath (not both). Perl reads them
1701    // only when they are registers (`$ereg->isRegister`), quietly: a package that redefines
1702    // `\everymath` as a macro does not warn at every formula.
1703    if bound_mode.contains("math") {
1704      let is_display = bound_mode == "display_math";
1705      let reg_name = if is_display {
1706        "\\everydisplay"
1707      } else {
1708        "\\everymath"
1709      };
1710      if let Some(RegisterValue::Tokens(toks)) = lookup_register_quiet(reg_name) {
1711        let toks = toks.unlist();
1712        if !toks.is_empty() {
1713          gullet::unread(Tokens::new(toks));
1714        }
1715      }
1716    }
1717    Ok(())
1718  } else {
1719    Warn!("unexpected", mode, s!("Cannot enter {mode} mode"));
1720    Ok(())
1721  }
1722}
1723/// End processing in `mode`; an error is signalled if `stomach` is not
1724/// currently in `mode`.  This also ends a level of grouping.
1725/// Perl: sub endMode (Stomach.pm lines 522-541)
1726pub fn end_mode(mode: &str) -> Result<()> { end_mode_opt(mode, false) }
1727/// Like `end_mode`, but with an explicit `noframe` option.
1728/// When `noframe` is true, executeBeforeAfterGroup is run but the stack frame is not popped.
1729pub fn end_mode_opt(mode: &str, noframe: bool) -> Result<()> {
1730  if let Some(bound_mode) = bindable_mode(mode) {
1731    // Perl Stomach.pm L527-528:
1732    //   if ((!$STATE->isValueBound('BOUND_MODE', 0))     # Last stack frame was NOT a mode switch
1733    //     || ($STATE->lookupValue('BOUND_MODE') ne $mode))  # OR switch to a different mode
1734    // Strict Perl-faithful: error if BOUND_MODE is not bound on the top
1735    // frame, OR if its value doesn't match the mode being closed. (Earlier
1736    // versions of this file used a lax value-only check as a workaround
1737    // for the 1112.6246 halign frame-balance issue, since fixed in
1738    // d162803d2.)
1739    let current_bound = lookup_string_from_sym(crate::pin!("BOUND_MODE"));
1740    let bound_on_top = is_value_bound("BOUND_MODE", Some(0));
1741    let make_mode_error = || {
1742      // Perl Stomach.pm:550: Error('unexpected', $CURRENT_TOKEN, $self,
1743      //   "Attempt to end mode $mode", currentFrameMessage($self)) — where
1744      // $mode is the BOUND (bindable) mode, and currentFrameMessage is a
1745      // SEPARATE detail (added at the call sites below). The earlier Rust
1746      // wording ("...mode `X` in `Y`") was not Perl-faithful.
1747      let message = s!("Attempt to end mode {}", bound_mode);
1748      let category = match get_current_token() {
1749        Some(ref token) => token.to_string(),
1750        None => String::from("mode"),
1751      };
1752      (category, message)
1753    };
1754    if !bound_on_top || current_bound != bound_mode {
1755      // Last stack frame was NOT a mode switch, or was a switch to a different mode.
1756      // Perl: Don't pop if there's an error; maybe we'll recover?
1757      if *TRACE_BOUND_MODE {
1758        let cur_tok = get_current_token()
1759          .map(|t| t.to_string())
1760          .unwrap_or_default();
1761        eprintln!(
1762          "[trace] end_mode ERROR: mode={mode} cur_tok={cur_tok} bound_on_top={bound_on_top} current_bound={current_bound} depth={}\n  {}\n{}",
1763          get_frame_depth(),
1764          current_frame_message(),
1765          std::backtrace::Backtrace::force_capture()
1766        );
1767      }
1768      let (category, message) = make_mode_error();
1769      Error!("unexpected", category, &message, current_frame_message());
1770    } else {
1771      // Perl: leaveHorizontal_internal($self) if $mode =~ /vertical$/;
1772      if bound_mode.ends_with("vertical") {
1773        leave_horizontal_internal();
1774      }
1775      if noframe {
1776        // No pop, but at least do beforeAfterGroup
1777        execute_before_after_group()?;
1778      } else if current_frame_locked() {
1779        // After `leave_horizontal_internal` the only frame left is the LOCKED
1780        // bottom frame — there is no mode-switch frame to pop, so
1781        // `pop_stack_frame` → `pop_frame` would FATAL ("pop last locked stack
1782        // frame"). This happens on a STRAY mode-ender with no matching begin:
1783        // e.g. `$Proof.$ … \quad \endproof` (no `\begin{proof}`) leaves
1784        // BOUND_MODE bound on the bottom frame, so the value-guard above passes
1785        // but the pop is illegal. Emit a recoverable Error and DON'T pop (Perl's
1786        // "maybe we'll recover" intent — Perl completes such papers; Rust used
1787        // to crash). Note the check is HERE (after `leave_horizontal_internal`,
1788        // which can repack a horizontal frame that legitimately becomes the
1789        // pop target — e.g. a normal document's `\end{document}`), not at the
1790        // value-guard above. Witness 1703.05010 (svjour3 + bare `\endproof`).
1791        let (category, message) = make_mode_error();
1792        Error!("unexpected", category, &message);
1793      } else {
1794        pop_stack_frame(false)?;
1795      }
1796    }
1797  } else {
1798    Warn!("unexpected", mode, s!("Cannot end {mode} mode"));
1799  }
1800  Ok(())
1801}

1805  static EVERYPAR_FIRING: Cell<bool> = const { Cell::new(false) };
1806  // How many isolated argument digestions (`digest(tokens)`) are open, with
1807  // `digest_next_body` resetting the count to 0 for the list it captures.
1808  // tex.web §1091 `new_graf` fires `\everypar` when a *list* — the main
1809  // vertical list or a `\vbox`'s internal one — starts a paragraph; a
1810  // constructor's digested `{}` argument is macro-parameter text that TeX
1811  // never typesets as such, so a paragraph "started" while reverting it is
1812  // not a `new_graf`. An armed `\everypar` (latex.ltx `\@afterheading`'s
1813  // `{\setbox\z@\lastbox}`, left by ltugboat.cls:1214 `\aftergroup
1814  // \@afterheading` in `\@maketitle`) used to fire inside
1815  // `\@@numbered@section`'s *type* argument and revert into it as
1816  // `{}section` — counter `\c@{}section`, tag `ltx:{}section` (lazylist,
1817  // parnotes; guard
1818  // `perfect_kernel_batch54::everypar_does_not_fire_inside_a_constructor_argument`).
1819  static ARG_DIGEST_DEPTH: Cell<u32> = const { Cell::new(0) };
1820}

1846/// Fire `\the\everypar` when a paragraph enters horizontal mode, the way tex.web's
1847/// `new_graf` (background/tex.web L21117) does `begin_token_list(every_par)`.
1848///
1849/// Guarded two ways, because LaTeXML's `\everypar` is not TeX's:
1850/// * `\everypar` is empty for most paragraphs (`\begin{document}` clears it — see
1851///   `latex_constructs/sect02.rs`), so this is a cheap early return except where a document or
1852///   package populates it (algorithm2e line numbering sets `\everypar`→`\algocf@everypar`→`\nl`
1853///   inside a listing; a preamble chain such as arabicore's keeps its own hook there).
1854/// * We fire ONLY in the document body. In the preamble the list holds
1855///   latex.ltx:9137's `\@nodocument` ("Missing \begin{document}"); `\begin{document}`
1856///   lets `\@nodocument`→`\relax`, so "document started" is exactly that test.
1857///
1858/// The digested boxes are pushed to the current box list BEFORE the triggering box
1859/// (the caller `extend_box_list`s that after), so `\nl`'s tag lands at the head of
1860/// the listingline. Errors are swallowed (this rides the infallible mode-switch
1861/// path); a genuine fatal is re-detected at the next digest-loop checkpoint.
1862fn fire_everypar() {
1863  let Some(toks) = pending_everypar() else {
1864    return;
1865  };
1866  EVERYPAR_FIRING.with(|f| f.set(true));
1867  if let Ok(digested) = digest(toks) {
1868    // A List box is unwound (flattened) on absorption, so `\nl`'s tag-whatsit runs
1869    // inline in the current listingline rather than under a wrapper.
1870    push_box_list(digested);
1871  }
1872  EVERYPAR_FIRING.with(|f| f.set(false));
1873}

1875/// The `\everypar` a paragraph started here would fire (see `fire_everypar` for
1876/// the two guards), or `None`.
1877fn pending_everypar() -> Option<Tokens> {
1878  if EVERYPAR_FIRING.with(|f| f.get()) || ARG_DIGEST_DEPTH.with(|d| d.get()) > 0 {
1879    return None;
1880  }
1881  // tex.web §1091: `new_graf` runs the every_par slot, whatever `\everypar` means now. Under
1882  // LaTeX that slot is the para hook, which runs the register latex.ltx:9070 allocated, named by
1883  // number (:9072-9077) — `\lx@para@everypar` (latex_constructs_rust_only.rs) — so a package's
1884  // `\def\everypar` (rlbicig.sty:62-64, witness: montex manual) or `\let\everypar\othertoks`
1885  // leaves it in place. Without LaTeX there is no document body (the `\@nodocument` test below),
1886  // so nothing fires.
1887  let register = lookup_register_definition(&T_CS!("\\lx@para@everypar"))?;
1888  let Some(RegisterValue::Tokens(toks)) = register.value_of(Vec::new()) else {
1889    return None;
1890  };
1891  if toks.is_empty() {
1892    return None; // empty \everypar — the normal body paragraph
1893  }
1894  // Skip the preamble/kernel-load para-hook \everypar (see doc comment).
1895  if !x_equals(&T_CS!("\\@nodocument"), &T_CS!("\\relax")) {
1896    return None;
1897  }
1898  Some(toks)

2008/// Resume vertical mode by executing \par, in TeX-like fashion.
2009/// Perl: sub leaveHorizontal
2010pub fn leave_horizontal() -> Result<()> {
2011  let mode = lookup_string_from_sym(crate::pin!("MODE"));
2012  let bound = lookup_string_from_sym(crate::pin!("BOUND_MODE"));
2013  if mode == "horizontal" && bound.ends_with("vertical") {
2014    // This needs to be an invisible, and slightly gentler, \par
2015    assign_value("INTERNAL_PAR", true, Some(Scope::Local));
2016    let par = T_CS!("\\par");
2017    if matches!(lookup_meaning(&par), Some(Stored::Expandable(_))) {
2018      // tex.web §1094 `head_for_vmode`: TeX backs the vertical command up and
2019      // inserts `\par` in front of it, so a redefined `\par` runs its WHOLE
2020      // body before the command reads its arguments. `invoke_token` stops at
2021      // the macro's first primitive and leaves the rest in the gullet, where
2022      // `\vskip`'s glue scan read it: syntax.sty:264-273's grammar `\par`
2023      // (`\parshape…\@@par \catcode`\<12 \everypar{…}`) lost `\@@par` to the
2024      // scan ("Missing number"), and the glue's stray digit then started a
2025      // paragraph that fired the re-armed `\everypar`, whose `\gr@implitem`
2026      // never found its catcode-12 `<` (2605.07451: `\grammarShrink` =
2027      // `\vspace` between productions). The body is read from a mouth of its
2028      // own, in no group (its assignments stand), and invoked against the
2029      // CURRENT box list, so `\@@par`'s repack still sees the paragraph and
2030      // the vertical-mode `\par` whatsit stays a bare paragraph boundary. The
2031      // one departure from §1094: a body that reads past its own end finds
2032      // end of input here, not the vertical command behind it.
2033      gullet::reading_from_mouth(Mouth::default(), || {
2034        gullet::unread(Tokens!(par));
2035        while let Some(token) = gullet::read_x_token(Some(true), false, None)? {
2036          check_timeout()?;
2037          let invoked = invoke_token(&token)?;
2038          extend_box_list(invoked);
2039        }
2040        Ok(())
2041      })?;
2042    } else {
2043      let par_result = invoke_token(&par)?;
2044      push_box_list_vec(par_result);
2045    }
2046    assign_value("INTERNAL_PAR", false, Some(Scope::Local));
2047  }
2048  Ok(())
2049}

2254/// innermost level IS the pathology — a 50k-box repeating window. Salvaging it

2271  }

2389/// Stomach-level cycle guard: only once `box_list` has grown far past any
2390/// flushed-document size (a normal `box_list` is drained as paragraphs/boxes
2391/// complete and stays small) do we record the digest-push stream and look for
2392/// a short repeating window — a box-accumulation infinite loop. Cuts it off
2393/// with a clean Fatal long before the RSS soft cap. Caller must already hold
2394/// the stomach borrow and have appended past the activation size.
2395#[inline]
2396fn cycle_guard_record(st: &mut Stomach, d: &Digested, progress: usize) {
2397  // Once a fatal is pending, further detection work is pointless — the raise
2398  // happens at the NEXT `check_timeout` tick, which (since PR #249 review
2399  // P2-6) every digestion loop runs per iteration (`digest_next_body`,
2400  // `digest`, `raw_tex`), so the window between detection and raise is at
2401  // most one `invoke_token`. (Before that fix, a runaway confined to
2402  // `digest()` set the flag and the guards then self-disabled while the list
2403  // grew unbounded — the flag was never raised on that path.)
2404  if st.pending_cycle_fatal.is_none() {
2405    // Hard size backstop — platform-INDEPENDENT (the RSS soft cap in
2406    // `check_timeout` reads `/proc/self/statm` and is therefore Linux-only;
2407    // on macOS/Windows it is inactive). This bounds `box_list` everywhere and
2408    // also catches APERIODIC runaways the windowed cycle detector cannot
2409    // (boxes that vary per iteration, e.g. a `\@whilenum` loop with a
2410    // counter, or period > MAX_WINDOW). 40× the validated cycle-activation
2411    // size, far past any flushed-document list. Analogous to the gullet's
2412    // platform-independent `token_limit`.
2413    if let Some(cap) = box_count_cap()
2414      && st.box_list.len() > cap
2415    {
2416      st.pending_cycle_fatal = Some((
2417        ErrorCategory::MemoryBudget,
2418        s!(
2419          "Box-list runaway: {} accumulated boxes exceeded the hard cap of {} \
2420           (unbounded digestion with no detectable cycle); raise --max-memory, \
2421           or --max-memory=0 to lift the ceiling",
2422          st.box_list.len(),
2423          cap
2424        ),
2425      ));
2426      return;
2427    }
2428    // Portable, BYTE-based memory guard. The count caps above are a proxy for
2429    // memory, but per-box weight varies several-fold (a bare text box vs a
2430    // deeply nested `\hbox{\raise…\hbox{…}}`), so a count calibrated for light
2431    // boxes lets a HEAVY-box runaway sail past it — only the Linux-only RSS cap
2432    // in `check_timeout` (4.5 GB) then catches it, late and non-portably.
2433    // Here we estimate the box list's actual heap footprint (by sampling, so
2434    // it stays O(1) amortised) and `Fatal` once it crosses a budget set BELOW
2435    // the RSS cap. This fires EARLIER than the external RSS guard AND works on
2436    // macOS/Windows where `/proc/self/statm` is unavailable. Driver:
2437    // math0102053 (plain-TeX `\@whiledim` line-drawing loop — Perl OOMs too;
2438    // ~1.87 M heavy line-segment boxes reached 4.5 GB RSS before the 2 M count
2439    // cap could fire).
2440    let len = st.box_list.len();
2441    if let Some(budget) = box_bytes_budget()
2442      && len >= BYTE_CHECK_ACTIVATE
2443      && len.is_multiple_of(BYTE_CHECK_EVERY)
2444    {
2445      let est = estimate_box_list_bytes(&st.box_list);
2446      if est > budget {
2447        st.pending_cycle_fatal = Some((
2448          ErrorCategory::MemoryBudget,
2449          s!(
2450            "Box-list memory runaway: ~{} MB estimated across {} boxes exceeded \
2451             the {} MB budget (unbounded accumulation); raise --max-memory, or \
2452             --max-memory=0 to lift the ceiling. NOTE: the estimate is a LOWER \
2453             BOUND (each box is walked at most {} nodes deep), so true RSS at \
2454             this point is typically several times larger",
2455            est / 1_000_000,
2456            len,
2457            budget / 1_000_000,
2458            crate::digested::EB_BUDGET
2459          ),
2460        ));
2461        return;
2462      }
2463    }
2464    // A repeating box window is a loop only when the input behind it repeats
2465    // too: every point of a pgf `plot[smooth]` digests the same content-free
2466    // boxes (empty `\pgf@process` groups, a stray space;
2467    // pgflibraryplothandlers.code.tex:37-77) from coordinates of varying
2468    // length, so an 11,000-point plot is no cycle (tkz-grapheur-doc-en/-fr,
2469    // sweep #126), where ` {}\x` reads the same tokens each time. The box
2470    // window keeps its uniform-run exemption (a finite `\loop` printing one
2471    // letter). Excluding content-free boxes instead blinded the guard to that
2472    // runaway and to 2508.07407's cloud loop; mixing the span into the box
2473    // fingerprint defeated the uniform-run exemption. DIVERGENCES #326.
2474    st.cycle_spans
2475      .push(progress.saturating_sub(st.cycle_progress));
2476    st.cycle_progress = progress;
2477    let fp = d.cycle_fingerprint();
2478    if let Some(period) = st.cycle_guard.push(fp, 0)
2479      && let Some(input_period) = st.cycle_spans.input_period(period)
2480    {
2481      st.pending_cycle_fatal = Some((
2482        ErrorCategory::Recursion,
2483        s!(
2484          "Infinite digestion loop: a window of {} box(es) repeated {}+ times from \
2485           input that repeats every {} box(es), while the box list grew past {}",
2486          period,
2487          crate::cycle_guard::REPEAT,
2488          input_period,
2489          STOMACH_CYCLE_ACTIVATE
2490        ),
2491      ));
2492    }
2493  }
2494}

2496/// Hard, platform-independent ceiling on `box_list` length — `None` when the
2497/// memory limit is disabled. A normal list is flushed continuously and stays
2498/// tiny; reaching this is an unbounded accumulation. The backstop for
2499/// very-LIGHT-box runaways, which the byte budget below can under-weigh.
2500///
2501/// **Rides `--max-memory`**, like every other memory ceiling: the resolved soft
2502/// cap divided by [`BYTES_PER_LIGHT_BOX`], which reproduces the historical fixed
2503/// 2 M at the stock `--max-memory=6144` (soft cap 4608 MiB), scales linearly
2504/// with the flag, and is `None` at `--max-memory=0`.
2505///
2506/// It used to be a hardcoded `const`, which made `--max-memory=0` a documented
2507/// lie: the binary prints "memory limiting disabled entirely" and then Fatal'd
2508/// on a memory ceiling anyway, with no flag able to raise it. Witness: a
2509/// ~10 000-page notes document (Nasser Abbasi, rc4 report 2026-07-28) died on
2510/// the byte budget below after 8 h at ~58 GB RSS having explicitly passed
2511/// `--max-memory=0`. Guard: `box_ceilings_follow_the_memory_knob`.
2512fn box_count_cap() -> Option<usize> {
2513  resolve_rss_cap().map(|cap| (cap / BYTES_PER_LIGHT_BOX) as usize)
2514}
2515
2516/// Calibration for [`box_count_cap`]: the per-box footprint of a *light* box,
2517/// chosen so the stock ceiling yields the validated 2 M-box cap.
2518const BYTES_PER_LIGHT_BOX: u64 = 2_416;
2519
2520/// Portable byte-budget for the accumulated `box_list` — `None` when the memory
2521/// limit is disabled. `estimate_bytes` counts each box's OWNED heavy data (the
2522/// `properties` HashMap, the `Tbox` `tokens` source-TeX vector, args/children
2523/// vectors + nested children). Works on macOS/Windows, where the `/proc` RSS
2524/// check is inactive and this is the ONLY memory guard for a heavy-box runaway.
2525///
2526/// **Rides `--max-memory`** (see [`box_count_cap`]): two thirds of the resolved
2527/// soft cap, i.e. 3.22 GB at the stock `--max-memory=6144` — the historical
2528/// fixed 3.2 GB — so on Linux it still `Fatal`s well before the RSS fuse, and
2529/// `None` at `--max-memory=0`.
2530///
2531/// **The estimate is a LOWER BOUND, not an RSS prediction.**
2532/// [`Digested::estimate_bytes`] walks at most `EB_BUDGET` (256) nodes per box,
2533/// so a deep document tree is undercounted by however much hangs below that
2534/// horizon — and the shortfall is content-dependent, not a constant. Measured:
2535/// a flat 600 k-paragraph synthetic crosses the 3.2 GB budget at 5.8 GB true RSS
2536/// (est ≈ 58 % of RSS), while Nasser's deeply-nested notes crossed the *same*
2537/// budget at ~58 GB (est ≈ 6 %). A ~10× spread — so do not read the budget as a
2538/// megabyte ceiling on the process. (The "tracks true RSS within ~10 %" claim
2539/// this doc used to carry held only for its calibration paper, math0102053: a
2540/// plain-TeX `\@whiledim` line-drawing loop whose ~1.87 M boxes are shallow.)
2541fn box_bytes_budget() -> Option<usize> { resolve_rss_cap().map(|cap| (cap / 3 * 2) as usize) }
2542/// Don't bother byte-sampling until the list is already well past the cycle
2543/// activation size (a normal list never gets here).
2544const BYTE_CHECK_ACTIVATE: usize = 200_000;
2545/// Re-estimate the box-list footprint every this-many boxes (amortises the
2546/// sampling cost to O(1) per push).
2547const BYTE_CHECK_EVERY: usize = 50_000;
2548/// Boxes sampled per byte estimate. Box weights are bimodal (light text
2549/// segments vs heavy nested structures), so a *dense* sample is needed to keep
2550/// the extrapolation from aliasing against the heavy-box stride.
2551const BYTE_SAMPLE_N: usize = 8192;
2552
2553/// Cost-bounded estimate of the heap bytes held by `list`, via even sampling +
2554/// extrapolation (each sampled box is itself depth-bounded — see
2555/// [`crate::digested::Digested::estimate_bytes`]). O(`BYTE_SAMPLE_N`) regardless
2556/// of list length. The sample is taken as contiguous *blocks* spread across the
2557/// list rather than a single large stride, which is far more robust to clustered
2558/// heavy boxes than evenly-strided point sampling.
2559fn estimate_box_list_bytes(list: &[Digested]) -> usize {
2560  let len = list.len();
2561  if len == 0 {
2562    return 0;
2563  }
2564  if len <= BYTE_SAMPLE_N {
2565    return list.iter().map(Digested::estimate_bytes).sum();
2566  }
2567  // 32 blocks of (BYTE_SAMPLE_N/32) contiguous boxes, evenly spaced — captures
2568  // local clustering of heavy boxes that point sampling misses.
2569  const BLOCKS: usize = 32;
2570  let block = (BYTE_SAMPLE_N / BLOCKS).max(1);
2571  let gap = len / BLOCKS;
2572  let mut sum = 0usize;
2573  let mut n = 0usize;
2574  for b in 0..BLOCKS {
2575    let start = b * gap;
2576    let end = (start + block).min(len);
2577    for d in &list[start..end] {
2578      sum += d.estimate_bytes();
2579      n += 1;
2580    }
2581  }
2582  // average-per-box × len; usize (64-bit) cannot overflow at realistic sizes.
2583  (sum / n.max(1)) * len
2584}

2824/// Print the list `list`: digest every entry deferred for it, in document order, and mark it printed. With `None`, digest
2825/// every deferred entry of every list without marking any printed — the streaming yield's fallback (an anchor is built
2826/// and spilled with the fragment it is in, before a later `\printindex` could fill it), where the entries are typeset
2827/// as Perl typesets them, at once.
2828pub fn resolve_deferred_prints(list: Option<&str>) -> Result<()> {
2829  if let Some(list) = list {
2830    assign_value(
2831      &s!("lx@deferred@print@printed@{list}"),
2832      Stored::Bool(true),
2833      Some(Scope::Global),
2834    );
2835  }
2836  if lookup_int("lx@deferred@print@unresolved") <= 0 {
2837    return Ok(());
2838  }
2839  // A list with nothing pending has nothing to scan for: a `\cite` of a key whose `\bibitem` comes later (70c's
2840  // `b@<key>` lists), with a document's unprinted `\index` entries pending, would otherwise rescan them all, once per
2841  // cite (40k entries and 5k cites, release build: 20.9 s → 0.99 s).
2842  if let Some(list) = list
2843    && lookup_int(&s!("lx@deferred@print@pending@{list}")) <= 0
2844  {
2845    return Ok(());
2846  }
2847  // The entries below the low-water mark are all resolved: a scan starts at the first one still pending, so the
2848  // streaming yields, which resolve every list, scan each entry once; one list's scan stops at its last entry.
2849  let count = lookup_int("lx@deferred@print@count");
2850  let low = lookup_int("lx@deferred@print@low").max(1);
2851  let mut first_pending: Option<i64> = None;
2852  let mut scanned_to = count;
2853  for id in low..=count {
2854    let key = s!("lx@deferred@print@tokens@{id}");
2855    let Some(Stored::Tokens(tokens)) = lookup_value(&key) else {
2856      continue;
2857    };
2858    let entry_list = lookup_string(&s!("lx@deferred@print@list@{id}"));
2859    if let Some(list) = list
2860      && entry_list != list
2861    {
2862      first_pending.get_or_insert(id);
2863      continue;
2864    }
2865    assign_value(&key, Stored::None, Some(Scope::Global));
2866    let unresolved = lookup_int("lx@deferred@print@unresolved") - 1;
2867    assign_value(
2868      "lx@deferred@print@unresolved",
2869      Stored::Int(unresolved),
2870      Some(Scope::Global),
2871    );
2872    let pending_key = s!("lx@deferred@print@pending@{entry_list}");
2873    let pending = lookup_int(&pending_key) - 1;
2874    assign_value(&pending_key, Stored::Int(pending), Some(Scope::Global));
2875    let content = digest(tokens)?;
2876    assign_value(
2877      &s!("lx@deferred@print@content@{id}"),
2878      Stored::Digested(content),
2879      Some(Scope::Global),
2880    );
2881    if list.is_some() && pending <= 0 {
2882      scanned_to = id;
2883      break;
2884    }
2885  }
2886  assign_value(
2887    "lx@deferred@print@low",

2892}

2898/// Digest a list of tokens independent from any current Gullet.
2899/// Typically used to digest arguments to primitives or constructors.
2900/// Returns a List containing the digested material.
2901pub fn digest<T: Into<Tokens>>(tokens: T) -> Result<Digested> {
2902  let tokens: Tokens = tokens.into();
2903  if tokens.is_empty() {
2904    return Ok(Digested::default());
2905  }
2906  // Digestion is no part of an enclosing number scan (calc's `\widthof`
2907  // inside `\makebox[…]`'s width; see `gullet::NumberScan::suspend`).
2908  let _outside_scan = gullet::NumberScan::suspend();
2909  gullet::reading_from_mouth(Mouth::default(), || {
2910    gullet::unread(tokens);
2911    clear_prefixes(); // prefixes shouldn't apply here.
2912    let _arg_scope = ArgDigestScope::enter_argument();
2913    let mode = if lookup_bool_sym(crate::pin!("IN_MATH")) {
2914      TexMode::Math
2915    } else {
2916      TexMode::Text
2917    };
2918    let initdepth = stomach!().boxing.len();
2919    let depth = initdepth;
2920    new_local_box_list();
2921    while let Some(token) = match gullet::get_pending_comment() {
2922      Some(comment) => Some(comment),
2923      None => gullet::read_x_token(Some(true), false, None)?,
2924    } {
2925      // Raise any pending stomach-guard fatal + deadline/RSS checks. This
2926      // loop is a digestion path of its own — without a tick here, a runaway
2927      // confined to constructor-argument digestion set `pending_cycle_fatal`
2928      // at detection but nothing ever RAISED it (check_timeout's only call
2929      // site was digest_next_body), and the RSS soft cap / wall-clock
2930      // deadline were equally dead on this path. PR #249 review P2-6.
2931      check_timeout()?;
2932      if delete_extra_brace(&token)? {
2933        continue;
2934      }
2935      // Done if we run out of tokens
2936      let invoked = invoke_token(&token)?;
2937      extend_box_list(invoked);
2938
2939      if initdepth > stomach!().boxing.len() {
2940        // if we've closed the initial mode.
2941        break;
2942      }
2943      if initdepth < depth {
2944        // TODO
2945        fatal!(Internal, EoF, "We've fallen off the end, somehow !?!?!?");
2946        //     Fatal('internal', '<EOF>', self,
2947        //       "We've fallen off the end, somehow!?!?!",
2948        //       "Last token " . ToString($LaTeXML::CURRENT_TOKEN)
2949        //         . " (Boxing depth was $initdepth, now $depth: Boxing generated by "
2950        //         . join(', ', map { ToString($_) } @{ $self{boxing} }))
2951        //       if $initdepth < $depth;
2952      }
2953    }
2954
2955    let mut digested_list = List::new(expire_local_box_list());
2956    digested_list.mode = Some(mode);
2957    digested_list.into()
2958  })
2959}

3043/// Abandons the current group, tex.web §1335 `final_cleanup` style: the stack frame (and its
3044/// `boxing` entry, unless the group is non-boxing) is popped and its `\aftergroup` list is
3045/// discarded, never run. Used where open groups are unwound wholesale — `\end{document}`
3046/// (`\lx@finalize@document`, Perl latex_constructs.pool.ltxml:353-386) and a bounded body's
3047/// terminal met inside a group ([`until_terminal_inside_group`]).
3048///
3049/// Every body digesting inside an abandoned group then ends the way Perl's does: Perl pops only
3050/// the undo frame (`$STATE->popFrame`, latex_constructs.pool.ltxml:373) and flushes the gullet
3051/// (:386), so each enclosing `digestUntil` reads END OF INPUT (Stomach.pm:111) and pushes a dummy
3052/// trailer (Stomach.pm:130) — every body keeps its boxes. Here the `boxing` entry goes too (an
3053/// unbalanced `\abstract{…` otherwise leaves a bounded primitive closing the document frame,
3054/// screenplay-pkg.tex:67), so the bodies stop on the depth check instead; `digest_next_body`
3055/// counts that exit as running out, not as a close whose last box is the closer. Without it the
3056/// trailer split took each enclosing body's LAST REAL BOX: two nested environments open at
3057/// `\end{document}` lost the inner one whole (`\begin{quote}Q1. \begin{quote}Q2. After.`), and a
3058/// list or math left open by an upstream defect lost the rest of the document. Witnesses: the
3059/// powerdotDE manual (recall 26% → 98%), arXiv 1902.00853 (27,484 words), 2110.01778.
3060///
3061/// The frame's beforeAfterGroup hooks still run, and what they queue on `\aftergroup` is
3062/// discarded with the rest (setspace's `\lx@setspace@rearm`). This is a LaTeXML recovery
3063/// modelled on §1335 (groups left open, `\aftergroup` never run); TeX itself recovers a closer
3064/// met inside a group by `off_save`, whose inserted closer runs `unsave` and so does run
3065/// `\aftergroup`. Guard: `perfect_kernel_batch64zf::abandoned_group_discards_hook_queued_aftergroup`.

3070  Ok(())
3071}

3418enum LookaheadCommand {

3433/// What the control sequence or active character `token` tells the look-ahead past a `\par`, by its current meaning
3434/// ([`LookaheadCommand`]), nothing expanded. A definition's parameters are read from its parameter list: any verbatim,
3435/// semi-verbatim or delimited one gives up. A macro whose body is tokens is followed into the control sequences of
3436/// that body, `depth` levels deep, for what it stops at or cannot follow (`\lstinline` = `\leavevmode\lx@lstinline`,
3437/// whose code reads a verbatim argument; `\medskip` = `\vskip…`); `budget` bounds the body tokens examined.
3438fn lookahead_command(token: &Token, depth: usize, budget: &mut usize) -> LookaheadCommand {
3439  use LookaheadCommand::*;
3440  if token.with_str(|name| PAR_LOOKAHEAD_STOPS.contains(&name)) {
3441    return GiveUp;
3442  }
3443  let defn: Rc<dyn Definition> = match lookup_meaning(token) {
3444    None => return Neutral,
3445    Some(Stored::Token(t)) => {
3446      return match t.get_catcode() {
3447        Catcode::SUPER | Catcode::SUB => MathOnly,
3448        Catcode::MATH | Catcode::ALIGN => GiveUp,
3449        _ => Neutral,
3450      };
3451    },
3452    Some(Stored::MathPrimitive(_)) => return MathOnly,
3453    Some(Stored::Constructor(d)) => d,
3454    Some(Stored::Primitive(d)) => d,
3455    Some(Stored::Expandable(d)) => d,
3456    Some(Stored::Conditional(d)) => d,
3457    Some(_) => return Neutral,
3458  };
3459  if defn
3460    .get_cs()
3461    .with_str(|name| PAR_LOOKAHEAD_STOPS.contains(&name))
3462  {
3463    return GiveUp;
3464  }
3465  let mode = defn.declared_mode();
3466  if mode.as_ref().is_some_and(|mode| mode.leave_horizontal) {
3467    return GiveUp;
3468  }
3469  if defn.get_parameters().is_some_and(|params| {
3470    params.get_parameters().iter().any(|param| {
3471      param.semiverbatim.is_some()
3472        || arena::with(param.name, |name| {
3473          name.contains("erbatim") || name.contains("Until") || name == "Match"
3474        })
3475    })
3476  }) {
3477    return GiveUp;
3478  }
3479  if mode.is_some_and(|mode| mode.require_math)
3480    || defn
3481      .get_cs()
3482      .with_str(|name| MATH_ONLY_PRIMITIVES.contains(&name))
3483  {
3484    return MathOnly;
3485  }
3486  match defn.get_expansion() {
3487    Some(ExpansionBody::Closure(_)) => GiveUp,
3488    Some(ExpansionBody::Tokens(body)) => {
3489      if depth >= PAR_LOOKAHEAD_DEPTH {
3490        return GiveUp;
3491      }
3492      for inner in body.unlist_ref() {
3493        if *budget == 0 {
3494          return GiveUp;
3495        }
3496        *budget -= 1;
3497        match inner.get_catcode() {
3498          Catcode::MATH | Catcode::ALIGN => return GiveUp,
3499          code if code.is_active_or_cs() && inner != token => {
3500            if lookahead_command(inner, depth + 1, budget) == GiveUp {
3501              return GiveUp;
3502            }
3503          },
3504          _ => {},
3505        }
3506      }
3507      Neutral
3508    },

3510  }

3548/// Where the look-ahead past a `\par` is relative to a command's arguments.
3549#[derive(Clone, Copy, PartialEq, Eq)]
3550enum ArgumentPosition {
3551  /// Not after a command.
3552  None,
3553  /// Right after a control sequence that is not math-only: a `*`, a `[…]` or a `{…}` is its argument.
3554  Command,
3555  /// Right after such an argument: a `[…]` or a `{…}` is its next one.

3559/// [`formula_continues_past_par`]'s decision over the `upcoming` tokens: `Some(math_only_seen)` at the closer,
3560/// `None` when undecided.
3561fn par_lookahead_verdict(upcoming: impl Iterator<Item = Token>) -> Option<bool> {
3562  let mut tokens = upcoming.peekable();
3563  let mut math_only = false;
3564  let mut depth = 0usize;
3565  // The brace depth below which every group is an argument, not looked into (`None`: none open).
3566  let mut opaque_from: Option<usize> = None;
3567  // The brace depth of an open bracketed argument `[…]`, not looked into.
3568  let mut bracket_at: Option<usize> = None;
3569  let mut position = ArgumentPosition::None;
3570  let mut leading = true;
3571  let mut budget = PAR_LOOKAHEAD_BODY_TOKENS;
3572  // The commands already classified, so a repeated macro costs its body once.
3573  let mut seen: Vec<(Token, LookaheadCommand)> = Vec::new();
3574  while let Some(token) = tokens.next() {
3575    let code = token.get_catcode();
3576    // The `\par`s and spaces of the blank lines themselves (an active `^^M` let to `\par` under `\obeylines`).
3577    if leading && (code == Catcode::SPACE || means_par(&token)) {
3578      continue;
3579    }
3580    leading = false;
3581    let opaque = opaque_from.is_some() || bracket_at.is_some();
3582    let after_command = position != ArgumentPosition::None;
3583    match code {
3584      Catcode::SPACE | Catcode::COMMENT | Catcode::MARKER => continue,
3585      // TeX's alphabetic constant: a `_` or `^` after a `` ` `` is a character code (`\char`_`, `\lccode`^`),
3586      // inert. Only those two are stepped over: a quoted `` `$x_1$' `` or `` `\ref{a_b}' `` keeps its `$` or its
3587      // command, which decide as they would anywhere else.
3588      Catcode::OTHER if token == T_OTHER!("`") => {
3589        if tokens
3590          .peek()
3591          .is_some_and(|next| matches!(next.get_catcode(), Catcode::SUB | Catcode::SUPER))
3592        {
3593          tokens.next();
3594        }
3595        position = ArgumentPosition::None;
3596        continue;
3597      },
3598      Catcode::MATH => {
3599        let display = tokens
3600          .peek()
3601          .is_some_and(|next| next.get_catcode() == Catcode::MATH);
3602        return (depth == 0 && !opaque && !display).then_some(math_only);
3603      },
3604      Catcode::ALIGN => return None,
3605      Catcode::BEGIN => {
3606        if after_command && !opaque {
3607          opaque_from = Some(depth);
3608        }
3609        depth += 1;
3610        position = ArgumentPosition::None;
3611        continue;
3612      },
3613      Catcode::END => {
3614        depth = depth.checked_sub(1)?;
3615        if bracket_at.is_some_and(|at| at > depth) {
3616          return None;
3617        }
3618        position = ArgumentPosition::None;
3619        if opaque_from == Some(depth) {
3620          opaque_from = None;
3621          position = ArgumentPosition::Argument;
3622        }
3623        continue;
3624      },
3625      Catcode::OTHER if !opaque && after_command => {
3626        if position == ArgumentPosition::Command && token == T_OTHER!("*") {
3627          continue;
3628        }
3629        if token == T_OTHER!("[") {
3630          bracket_at = Some(depth);
3631          position = ArgumentPosition::None;
3632          continue;
3633        }
3634      },
3635      Catcode::OTHER if bracket_at == Some(depth) && token == T_OTHER!("]") => {
3636        bracket_at = None;
3637        position = ArgumentPosition::Argument;
3638        continue;
3639      },
3640      _ => {},
3641    }
3642    position = ArgumentPosition::None;
3643    if code.is_active_or_cs() {
3644      if token == T_CS!("\\)") {
3645        return (depth == 0 && !opaque).then_some(math_only);
3646      }
3647      let command = match seen.iter().find(|(known, _)| *known == token) {
3648        Some((_, command)) => *command,
3649        None => {
3650          let command = lookahead_command(&token, 0, &mut budget);
3651          seen.push((token, command));
3652          command
3653        },
3654      };
3655      match command {
3656        LookaheadCommand::GiveUp => return None,
3657        LookaheadCommand::MathOnly => math_only |= !opaque,
3658        // A math-only command's groups and brackets are math, looked into (`\left[0,1\right)`, `\in [0,1)`).
3659        LookaheadCommand::Neutral if code == Catcode::CS => position = ArgumentPosition::Command,
3660        LookaheadCommand::Neutral => {},
3661      }
3662    } else if !opaque && matches!(code, Catcode::SUPER | Catcode::SUB) {
3663      math_only = true;
3664    }
3665  }
3666  None
3667}

3719///   recovery for our own insertion);
3720/// * the `}` a delimiter scan put back ([`PUT_BACK_BRACE`]: `$\left\{ x \right}$`, `\mbox{$\left\{ x \right}$}`)
3721///   meeting the formula's own math shift — "Extra }, or forgotten $", an Error, as TeX and Perl err there.
3722///
3723/// Any other `}` at the formula's frame is `digest_next_body`'s (the general §1069 deletion of an inline formula's stray
3724/// brace, OXIDIZED_DESIGN #553). Checked before the digestion loops could take the brace for a group end (65d reviews
3725/// r1/r3/r5). OXIDIZED_DESIGN #530.
3726fn delete_extra_brace(token: &Token) -> Result<bool> {
3727  if !gullet::is_right_brace(token) {
3728    return Ok(false);
3729  }
3730  let put_back = take_put_back_mark(token);
3731  if owed_closers(OWED_BRACES) > 0
3732    && let Some(forgotten) = brace_cannot_close()
3733  {
3734    assign_frame_value(OWED_BRACES, Stored::Int(owed_closers(OWED_BRACES) - 1));
3735    Warn!(
3736      "unexpected",
3737      "}",
3738      s!("Extra }}, or forgotten {forgotten}"),
3739      "The } of a group closed earlier by an inserted } is deleted."
3740    );
3741    return Ok(true);
3742  }
3743  if put_back {
3744    return delete_put_back_brace();
3745  }
3746  Ok(false)
3747}

4136  if let Some(ref terminal) = terminal_opt
4137    && !found_terminal
4138  {
4139    let message = s!(
4140      "body should have ended with {:?}. current body started at {:?}",
4141      terminal,
4142      start_location
4143    );
4144    Warn!("expected", terminal, message);
4145  }
4146  // and add a Dummy `trailer' if none explicit — Perl `Stomach.pm` L130,
4147  // `push(@LaTeXML::LIST, Box()) unless $token;`.
4148  //
4149  // This was mistranslated as "if we never read ANY token", which is a strictly
4150  // narrower condition: it agrees with Perl only on a body that was empty from
4151  // the start. The case it missed is a body that read content and THEN hit EOF —
4152  // and that is the case the trailer exists for. `readDigested`
4153  // (`Base_ParameterTypes.pool.ltxml` L374, ported in `base_parameter_types.rs`)
4154  // does `push(@list, digestNextBody()); pop(@list);` to strip the closing `}`

4157  // its own argument, and the `pop` then removed the boxes carrying every
4158  // following entry — an empty bibliography where Perl renders all of them.
4159  if ran_out {
4160    push_box_list(Digested::from(Tbox::default()));
4161  }
4162  Ok(expire_local_box_list())
4163}

4195/// The token that takes the place of an expansion made here, in the stomach (Perl Stomach.pm:204-209 `invokeToken`
4196/// re-reads with `readXToken` and invokes what it finds), unless that token ends the alignment cell being read.
4197///
4198/// A tab or `\cr` that an expansion yields at `align_state` 0 ends the cell (tex.web §789 `insert_v_part`): the gullet
4199/// takes it as the column's end, raises the count to 1000000, and puts it back behind the column's v-part
4200/// (`handle_template`). The cell's own reader then meets the v-part and, after it, the end. When the column has no
4201/// v-part (`\omit`, so every `\multicolumn` cell), the end itself is the next token, and it comes back to this
4202/// re-read instead: it goes back to the cell's reader, which ends the column on it, rather than being digested as a
4203/// stray `&`. A cell reader hands a protected macro to the stomach unexpanded (it reads as Perl's `readXToken(0)`
4204/// does), so `\protected\def\cellx#1{& #1}` after a `\multicolumn` (sgamex.sty:56-58) reaches this path; pdflatex
4205/// gives three cells (witness 2410.16600), and Perl too only because its `\multicolumn` keeps a v-part
4206/// (OXIDIZED_DESIGN_DIVERGENCES #474). Guard:
4207/// `perfect_kernel_batch63::protected_tab_after_multicolumn_ends_the_cell`.
4208fn read_x_token_after_expansion() -> Result<Option<Token>> {

4210  if let Some(token) = next
4211    && align_group_count() == 1_000_000
4212    && has_reading_alignment()
4213    && gullet::is_column_end(&token).is_some()
4214  {
4215    gullet::unread_one(token);
4216    return Ok(None);
4217  }
4218  Ok(next)
4219}

4221/// tex.web §1127 `align_error`: a tab, `\cr` or `\span` that reaches the stomach while the alignment count is not 0
4222/// — the cell left a brace unbalanced, so the gullet did not take it for the cell's end (§342) — gets the brace TeX
4223/// supposes was omitted: count −1 or −2 (the cell's `}` closed one more group than it opened, `a} &=& b`) inserts a
4224/// `{` ("Missing { inserted"), count +1 or +2 (`{a & b}`, `\textbf{a & b}`) a `}` ("Missing } inserted"), and the
4225/// column end is read again behind it, now at count 0, so the v-part runs and the cell ends as the template says
4226/// (§789). The ledger moves as TeX's does: `align_error` steps the count towards 0 and `ins_error`'s `back_input`
4227/// (§325) retracts the inserted brace, which counts again when it is read. A larger count (`abs(align_state)>2`,
4228/// "Misplaced &") is left to the cell's reader, as is a count past the v-part's 1000000 (the column's own end).
4229/// Before, the column end was taken for the cell's end with no v-part: an eqnarray/amsmath cell left its template's
4230/// math open (pdflatex 1 error, ours 17: "Attempt to close a group that switched to mode math"), and a tabular cell's
4231/// `{a & b}` lost `a` without a word. Perl has no `align_error` (KNOWN_PERL_ERRORS #923). Whether it fired. Guards
4232/// `perfect_kernel_batch70b::{eqnarray_stray_close_brace_inserts_a_left_brace,
4233/// tabular_open_brace_at_a_cell_end_inserts_a_right_brace}`.
4234pub fn align_error(token: &Token) -> Result<bool> {
4235  let count = align_group_count();
4236  if count == 0
4237    || count.abs() > 2
4238    || !has_reading_alignment()
4239    || gullet::is_column_end(token).is_none()
4240    || !is_tab_mark_command(token)
4241  {
4242    return Ok(false);
4243  }
4244  if count < 0 {
4245    Error!(
4246      "expected",
4247      "{",
4248      "Missing { inserted",
4249      "I've put in what seems to be necessary to fix the current column of the current alignment."
4250    );
4251    set_align_group_count(count + 1);
4252    gullet::unread_one(*token);
4253    gullet::unread_one(T_BEGIN!());
4254  } else {
4255    Error!(
4256      "expected",
4257      "}",
4258      "Missing } inserted",
4259      "I've put in what seems to be necessary to fix the current column of the current alignment."
4260    );
4261    set_align_group_count(count - 1);
4262    gullet::unread_one(*token);
4263    gullet::unread_one(T_END!());
4264  }
4265  Ok(true)
4266}

4330/// Invoke a token
4331///
4332/// If it is a primitive or constructor, the definition will be invoked,
4333/// possibly arguments will be parsed from the Gullet.
4334/// Otherwise, the token is simply digested: turned into an appropriate box.
4335/// Returns a list of boxes/whatsits.
4336pub fn invoke_token(input_token: &Token) -> Result<Vec<Digested>> {
4337  // The choke point: a cell's `}` and any `}` inside a `\noalign` body pass it, clearing the live put-back mark, and a
4338  // put-back `}` is deleted here at the formula's own math shift ([`PUT_BACK_BRACE`]). A loop's own closing `}` (the
4339  // `\noalign` loop, tex_tables.rs:1291; the box-body loop, base_utilities.rs:7083) does not pass it and leaves the
4340  // live serial set, which is harmless: the frame holding the mark closes with that `}` (probe B1).
4341  if take_put_back_mark(input_token) && delete_put_back_brace()? {
4342    return Ok(Vec::new());
4343  }
4344  // Perf: Token is Copy (SymStr + Catcode, ~5 bytes), so we pass by value
4345  // directly instead of wrapping in Cow<Token>.
4346  let mut maybe_token: Option<Token> = Some(*input_token);
4347  let mut result: Vec<Digested> = Vec::new();
4348  // INVOKE:
4349  while let Some(token) = maybe_token.take() {
4350    if align_error(&token)? {
4351      return Ok(Vec::new());
4352    }
4353    // RAII guard: auto-pops current_token on scope exit (even on early return/panic)
4354    let _token_guard = local_current_token_guard(token);
4355    {
4356      stomach_mut!().token_stack.push(token);
4357    }
4358    if { stomach!().token_stack.len() } > MAXSTACK {
4359      fatal!(
4360        Stomach,
4361        Recursion,
4362        s!(
4363          "Excessive recursion(?): Tokens on stack: {:?}",
4364          stomach!().token_stack
4365        )
4366      );
4367    }
4368    result.clear();
4369
4370    // Rust notes: It would be ideal if we could unify the cases for (Primtive, Constructor,
4371    // MathPrimitive), as well as (Expandable, Conditional) since the
4372    // API is identical. However, as the types are different, Rust
4373    // constrains us here, we need separate match arms for each
4374    // distinctly typed enum case.
4375    let digestable_def = lookup_digestable_definition(&token);
4376    match digestable_def {
4377      None | Some(Stored::None) => {
4378        result = invoke_token_undefined(&token)?;
4379      },
4380      Some(Stored::Token(meaning)) => {
4381        // Common case
4382        let cc = meaning.get_catcode();
4383        if cc == Catcode::CS {
4384          result = invoke_token_undefined(&token)?;
4385        } else if cc.is_absorbable() {
4386          let starts_paragraph = matches!(cc, Catcode::LETTER | Catcode::OTHER)
4387            && !lookup_bool_sym(crate::pin!("IN_MATH"));
4388          if starts_paragraph && back_input_for_new_graf(token) {
4389            // `\everypar`, then this token again, in horizontal mode.
4390          } else if let Some(digested) = invoke_token_simple(meaning)? {
4391            result.push(digested);
4392          }
4393        } else {
4394          // Perl L187-189: deactivate T_ALIGN to prevent error flood in tables
4395          if token.get_catcode() == Catcode::ALIGN
4396            && let Some(relax_meaning) = lookup_meaning(&T_CS!("\\relax"))
4397          {
4398            assign_meaning(&token, relax_meaning, Some(Scope::Local));
4399          }
4400          let message = s!(
4401            "The token {:?} (catcode {:?}) should never reach Stomach!",
4402            token,
4403            cc
4404          );
4405          Error!("misdefined", token, &message);
4406          if let Some(digested) = invoke_token_simple(meaning)? {
4407            result.push(digested);
4408          }
4409        }
4410      },
4411      Some(Stored::Expandable(meaning)) => {
4412        // A math-active character will (typically) be a macro,
4413        // but it isn't expanded in the gullet, but later when digesting, in math mode
4414        // (? I think)
4415        let mut invoked_meaning = meaning.invoke(false)?;
4416        crate::token::inherit_field_prov(token.prov, &mut invoked_meaning);
4417        if !invoked_meaning.is_empty() {
4418          {
4419            gullet::unread(invoked_meaning);
4420          }
4421        }
4422        // replace the token by it's expansion!!!
4423        maybe_token = read_x_token_after_expansion()?;
4424        {
4425          stomach_mut!().token_stack.pop();
4426        }
4427        drop(_token_guard); // expire current token via RAII
4428        continue;
4429      },
4430      Some(Stored::Conditional(meaning)) => {
4431        // Conditionals are "expandable", use the regular invoke.
4432        let invoked_meaning = meaning.invoke(false)?;
4433        gullet::unread(invoked_meaning);
4434        maybe_token = read_x_token_after_expansion()?;
4435        {
4436          stomach_mut!().token_stack.pop();
4437        }
4438        drop(_token_guard); // expire current token via RAII
4439        continue;
4440      },
4441      Some(Stored::Constructor(meaning))
4442        if starts_new_graf(&meaning.get_cs()) && back_input_for_new_graf(token) =>
4443      {
4444        // `\hskip`, `\vrule`, `\valign`: `\everypar`, then this token again, in horizontal mode (tex.web §1090).
4445      },
4446      Some(Stored::Constructor(meaning)) => {
4447        // Perl Stomach.pm L187-189: deactivate T_ALIGN to `\relax` LOCAL
4448        // on first non-table encounter, to prevent error flood. The
4449        // existing guard at the Stored::Token branch (above) only fires
4450        // when `&` has been Let'd to another token, but the `&`
4451        // CC_ALIGN char-token is bound to a Constructor (TeX_Tables.pool
4452        // L49: `DefConstructorI('&', undef, sub { Error('unexpected', '&',
4453        // $_[0], "Stray alignment \"&\"") })`), so it falls into THIS
4454        // branch instead. Without this guard, papers with multiple stray
4455        // `&` (e.g. astro-ph0107583's bibitem with unescaped `Hirose &
4456        // Osaki`) emit one Error per occurrence; Perl emits ONE total
4457        // because of the LOCAL `\relax` rebinding. Self-deactivate here
4458        // too so subsequent `&` invocations no-op.
4459        if token.get_catcode() == Catcode::ALIGN
4460          && let Some(relax_meaning) = lookup_meaning(&T_CS!("\\relax"))
4461        {
4462          assign_meaning(&token, relax_meaning, Some(Scope::Local));
4463        }
4464        // `meaning` IS the state table's `Rc<Constructor>`, so hand it to the
4465        // Whatsit rather than letting `invoke_primitive` deep-clone the
4466        // definition once per invocation (see `Constructor::invoke_primitive_shared`).
4467        result = Constructor::invoke_primitive_shared(&meaning)?;
4468        if !meaning.is_prefix() {
4469          clear_prefixes(); // Clear prefixes unless we just set one.
4470        }
4471      },
4472      Some(Stored::Primitive(meaning))
4473        if starts_new_graf(&meaning.get_cs()) && back_input_for_new_graf(token) =>
4474      {
4475        // `\everypar`, then this token again, in horizontal mode (tex.web §1090).
4476      },
4477      Some(Stored::Primitive(meaning)) => {
4478        // Otherwise, a normal primitive or constructor
4479        result = meaning.invoke_primitive()?;
4480        // After a prefix TeX reads on to the next non-blank non-relax token
4481        // (tex.web §1211, §404), so a `\relax` there keeps the prefixes:
4482        // catoptions' `\protected\relax\def` (its `\robust@def*`, :375-381)
4483        // defines a protected macro. Perl clears them (Stomach.pm:212), and the
4484        // unprotected `\cpt@newv@riables` ran inside an `\edef`: 70 errors per
4485        // `\usepackage{catoptions}` (keyval2e, concepts, ltxkeys). KPE #223.
4486        if !meaning.is_prefix() && !(has_tex_prefixes() && *meaning.get_cs() == T_CS!("\\relax")) {
4487          clear_prefixes(); // Clear prefixes unless we just set one.
4488        }
4489      },
4490      Some(Stored::MathPrimitive(meaning)) => {
4491        // Copy of regular Primitive
4492        // Otherwise, a normal primitive or constructor
4493        result = meaning.invoke_primitive()?;
4494        if !meaning.is_prefix() {
4495          clear_prefixes(); // Clear prefixes unless we just set one.
4496        }
4497      },
4498      Some(Stored::Register(meaning)) => {
4499        // Registers are special primitives
4500        result = meaning.invoke_primitive()?;
4501        if !meaning.is_prefix() {
4502          clear_prefixes(); // Clear prefixes unless we just set one.
4503        }
4504      },
4505      meaning => {
4506        // Perl: Error + makeMisdefinedError (non-fatal). Don't crash.
4507        Error!(
4508          "misdefined",
4509          token,
4510          s!("Unexpected object in Stomach: {:?}", meaning)
4511        );
4512      },
4513    }
4514    if token.prov != 0 && crate::token::field_ledger_live() {
4515      note_field_token(&token, &result);
4516    }
4517    // _token_guard drops here, auto-expiring current token
4518    break;
4519  }
4520  stomach_mut!().token_stack.pop();
4521  Ok(result)
4522}

4524fn invoke_token_undefined(token: &Token) -> Result<Vec<Digested>> {
4525  // The LaTeX format may not be loaded yet (a document may use a kernel CS
4526  // before `\documentclass` — real LaTeX has no "before the kernel"). If this
4527  // is a kernel CS, pull the format in and re-digest instead of stubbing it as
4528  // `<ltx:ERROR/>`. Fires at most once per session; see
4529  // `binding::kernel_autoload`. Same retry shape as the `\ifsomething` arm below.
4530  if crate::binding::kernel_autoload::try_autoload(token) {
4531    gullet::unread_one(*token); // Retry, now that the kernel is in state.
4532    return Ok(Vec::new());
4533  }
4534  // An environment the class redefined, whose begin defines this command for its body, but whose definition the
4535  // kernel's lock refused (`kernel_autoload::try_refused_environment_definition`).
4536  if crate::binding::kernel_autoload::try_refused_environment_definition(token) {
4537    gullet::unread_one(*token);
4538    return Ok(Vec::new());
4539  }
4540  // a stand-in named for the undefined name (`kernel_autoload::undefined_fallback`, OXIDIZED_DESIGN #734)
4541  if let Some(stand_in) = crate::binding::kernel_autoload::undefined_fallback(token) {
4542    gullet::unread_one(stand_in);
4543    return Ok(Vec::new());
4544  }
4545  let cs = token.with_cs_name(|cs| String::from(cs));
4546  // Gate the undefined-CS summary tally and the Error! emission by
4547  // SUPPRESS_UNDEFINED_ERRORS. During expl3-code.tex raw load we install
4548  // the ERROR stub silently — forward references resolve when subsequent
4549  // post-load fixups rebind the canonical CS (see expl3_sty.rs L161-167
4550  // for \iow_wrap stubs that overwrite ERROR after the raw load). Mirrors
4551  // the existing gate at state.rs::generate_error_stub L1018-L1030.
4552  let suppressed = lookup_bool_sym(crate::pin!("SUPPRESS_UNDEFINED_ERRORS"));
4553  if !suppressed {
4554    note_status(LogStatus::Undefined, Some(&cs));
4555  }
4556
4557  // To minimize chatter, go ahead and define it...
4558  if cs.starts_with("\\if") {
4559    // Apparently an \ifsomething ???
4560    let name = cs.replace("\\if", "");
4561    if !suppressed {
4562      let message = s!("The token {} is not defined.", token.stringify());
4563      Error!(
4564        "undefined",
4565        token,
4566        &message,
4567        "Defining it now as with \\newif"
4568      );
4569    }
4570    // install stub definitions for new conditional
4571    install_definition(
4572      Expandable::new(
4573        T_CS!(s!("\\{}true", name)),
4574        None,
4575        Tokens!(T_CS!("\\let"), T_CS!(&cs), T_CS!("\\iftrue")).into(),
4576        None,
4577      )?,
4578      None,
4579    );
4580    install_definition(
4581      Expandable::new(
4582        T_CS!(s!("\\{}false", name)),
4583        None,
4584        Tokens!(T_CS!("\\let"), T_CS!(cs), T_CS!("\\iffalse")).into(),
4585        None,
4586      )?,
4587      None,
4588    );
4589
4590    let_i(token, &T_CS!("\\iffalse"), None);
4591    gullet::unread_one(*token); // Retry
4592    Ok(Vec::new())
4593  } else {
4594    if !suppressed {
4595      let message = s!("The token {} is not defined.", token.stringify());
4596      Error!(
4597        "undefined",
4598        token,
4599        &message,
4600        "Defining it now as <ltx:ERROR/>"
4601      );
4602    }
4603    install_definition(
4604      Constructor {
4605        cs: *token,
4606        paramlist: None,
4607        replacement: Some(Rc::new(move |document, _args, _props| {
4608          document.make_error("undefined", &cs)
4609        })),
4610        ..Constructor::default()
4611      },
4612      Some(Scope::Global),
4613    );
4614    // Perl: unread the token and return empty, so the outer loop re-reads
4615    // and dispatches through the normal path (with the newly installed stub).
4616    // This ensures gullet-level side effects (filtering, expansion) are applied.
4617    gullet::unread_one(*token);
4618    Ok(Vec::new())
4619  }
4620}

4622fn invoke_token_simple(meaning: Token) -> Result<Option<Digested>> {
4623  let cc = meaning.get_catcode();
4624  let font = lookup_font();
4625  // token-locators: the leaf char box's exact source position comes from the
4626  // token's origin handle — the position that survived expansion to digestion
4627  // (Experiments 1–3 showed it cannot be re-derived from the mouth here, which
4628  // is past the construct). `None` → `Tbox::new` falls back to the gullet's
4629  // current locator (the eating-disorder heuristic). See SOURCE_PROVENANCE §3.1.1.
4630  // Stamp a leaf box only from a *genuine* (read-from-source) origin. An
4631  // inherited origin — a macro's expansion attributed to its call site, e.g.
4632  // `\section`'s structural body literals at the `\section` column — must not
4633  // become a located leaf, or box-level `get_locator()` aggregation would widen
4634  // a construct past its content (the `\section{Intro}` title would start at the
4635  // command, not at "Intro"). The inherited origin still rides the token, so
4636  // `constructor::child_span`'s genuine-first scan can recover it as the
4637  // fallback for the origin-less case (`\today`). See SOURCE_PROVENANCE §3.1.3.
4638  #[cfg(feature = "token-locators")]
4639  let origin_loc: Option<crate::common::locator::Locator> =
4640    crate::token::get_token_origin(meaning.loc)
4641      .filter(|o| !o.inherited)
4642      .map(|o| {
4643        crate::common::arena::with(o.source, |s| {
4644          crate::common::locator::Locator::new(s, o.line, o.col, o.line, o.col)
4645        })
4646      });
4647  #[cfg(not(feature = "token-locators"))]
4648  let origin_loc: Option<crate::common::locator::Locator> = None;
4649  match cc {
4650    Catcode::SPACE => {
4651      // A space after a prefix is skipped, not typeset (tex.web §1211, §404).
4652      if has_tex_prefixes() {
4653        return Ok(None);
4654      }
4655      clear_prefixes(); // Perl Stomach.pm line 234: prefixes shouldn't apply here.
4656      // Perl: if($STATE->lookupValue('MODE') =~ /(?:math|vertical)$/) { return (); }
4657      let mode = lookup_string_from_sym(crate::pin!("MODE"));
4658      if mode.ends_with("math") || mode.ends_with("vertical") {
4659        Ok(None)
4660      } else {
4661        enter_horizontal();
4662        // An interword space is glue (tex.web §1041 `app_space`): `\unskip` removes it, `\lastskip` reads it
4663        // (KNOWN_PERL_ERRORS #436). Perl's space box carries no `isSkip` (Stomach.pm:244-250), so `a \unskip,`
4664        // kept the space before the comma (witness 2605.02925, its `\and` author list).
4665        let mut properties = HashMap::default();
4666        properties.insert("isSkip", Stored::Bool(true));
4667        Ok(Some(Digested::from(Tbox::new(
4668          meaning.get_sym(),
4669          font,
4670          origin_loc,
4671          Tokens!(meaning),
4672          properties,
4673        ))))
4674      }
4675    },
4676    Catcode::COMMENT => {
4677      // Perl Stomach.pm lines 241-244: decode comment via font encoding
4678      let decoded = font::decode_string(meaning.get_sym(), None, true);
4679      let comment = arena::with(decoded, |s| {
4680        // However, spaces normally would have be digested away as positioning...
4681        // Replace NBSP + combining strikethrough (OT1 space position) with actual space
4682        s.replace("\u{00A0}\u{0335}", " ")
4683      });
4684      // Perl: returns LaTeXML::Core::Comment->new($comment)
4685      // which gets absorbed as an XML comment node via Document::insertComment
4686      Ok(Some(Digested::from(Comment(comment))))
4687    },
4688    _ => {
4689      clear_prefixes(); // Perl Stomach.pm line 247: prefixes shouldn't apply here.
4690      // Perl: check mathcode for IN_MATH characters (Stomach.pm lines 248-251)
4691      // In Perl, all math chars go through decodeMathChar which decodes via
4692      // the font encoding. In Rust, Tbox::new already handles IN_MATH:
4693      // it sets mode="math", looks up math_token_attributes for role/meaning/name,
4694      // and specializes the font. This produces the correct LaTeXML-level properties.
4695      // The mathchar parsing handles non-ASCII chars needing font map lookup.
4696      // TODO: Use for chars where font-encoding glyph differs from input.
4697      // Perl L248-257: if IN_MATH && mathcode → decodeMathChar (math box)
4698      // else → enterHorizontal + text box (covers non-math AND math-but-no-mathcode)
4699      // A math-active character ("8000) digested as itself has no math character to decode; it is the plain character:
4700      // a delimiter (`digest_as_delimiter`), or one whose active meaning is undefined and self-inserts
4701      // (`lookup_digestable_definition`, braket's `\Pr{A|B}`, 1602.01342). `decode_math_char` of "8000 is class 8, which
4702      // dropped the character here before, and is Γ in Perl (KNOWN_PERL_ERRORS #495).
4703      if lookup_bool_sym(crate::pin!("IN_MATH"))
4704        && let Some(mathcode) = lookup_mathcode_sym(meaning.get_sym())
4705        && mathcode != 0x8000
4706      {
4707        return crate::common::mathchar::decode_math_char_for_stomach(mathcode, meaning);
4708      }
4709      // Fallthrough: either not in math, or in math but no mathcode
4710      enter_horizontal();
4711      let text = font::decode_string(meaning.get_sym(), None, true);
4712      // A raw `\font`'s slot is measured from its TFM (`Tbox::with_tfm_slot`).
4713      let slot = meaning.with_str(|s| {
4714        let mut chars = s.chars();
4715        match (chars.next(), chars.next()) {
4716          (Some(c), None) => u32::from(c),
4717          _ => u32::MAX,
4718        }
4719      });
4720      Ok(Some(Digested::from(
4721        Tbox::new(
4722          text,
4723          None,
4724          origin_loc,
4725          Tokens!(meaning),   // tokens
4726          HashMap::default(), // properties
4727        )
4728        .with_tfm_slot(slot),
4729      )))
4730    },
4731  }
4732}
