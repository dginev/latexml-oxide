1//! latexml-oxide converts LaTeX documents into HTML5 with MathML, XML and EPUB 3: a Rust port of
2//! [LaTeXML](https://github.com/brucemiller/latexml). This crate, published as `latexml`, holds the command-line
3//! binaries (`latexml_oxide`, `latexmlmath_oxide`, `genschema_oxide`, and `cortex_worker` with the `cortex` feature)
4//! and the library that drives a conversion.
5//!
6//! - [`api`]: the stable entry points, `convert_to_xml`, `convert_to_html` and `convert_to_html_with`.
7//! - [`converter::Converter`]: a full conversion with its own configuration (preloads, search paths, split, …).
8//! - [`post`]: the post-processing to HTML, XHTML or EPUB (Perl's `latexmlpost`).
9//! - [`format_dumps`]: the format dumps embedded in the binary or built once for the host TeX tree.
10//! - [`environment`] and [`intermediate_files`]: every environment variable read, and every file written.
11//!
12//! The engine is in `latexml_core` and `latexml_engine`, the bindings in `latexml_package` and `latexml_contrib`,
13//! the math parser in `latexml_math_parser` and the post-processors in `latexml_post`. Start with the
14//! [README](https://github.com/dginev/latexml-oxide/blob/main/README.md) and [USAGE.md](https://github.com/dginev/latexml-oxide/blob/main/docs/USAGE.md).

50/// Load the embedded LaTeXML schema (compile-time) into the runtime
51/// `MODEL`. Single home for the `load_model!("LaTeXML")` macro
52/// expansion — the macro generates a fresh `_ModelLoader::build_model`
53/// at each call site (~600 KiB of `.text` per copy), so funnelling
54/// all callers through this one function lets LTO keep exactly one
55/// instance in the final binary. Mirrors Perl
56/// `LaTeXML::Common::Model::compileSchema` (Model.pm L121-136).
57// The generated loader builds the whole schema in one frame (opt-level 0); it runs once per process at start-up. Splitting
58// it per element in the `load_model!` proc macro is a post-merge refactor.
59#[allow(clippy::large_unopt_stack_frames)]
60pub fn load_latexml_default_model() {
61  use latexml_codegen::LoadModel;
62  load_model!("LaTeXML");
63}

65/// Load the embedded LaTeXML schema and return its compiled-model
66/// serialisation in the `.model` plain-text format. Used by
67/// `tools/compileschema.sh` stage 2 (and the `--dump-model` flag on
68/// the `latexml_oxide` binary) to regenerate `LaTeXML.model` from the
69/// same source the runtime sees.
70pub fn dump_compiled_latexml_model() -> String {
71  load_latexml_default_model();
72  latexml_core::common::model::MODEL
73    .borrow()
74    .dump_compiled_schema()
75}
