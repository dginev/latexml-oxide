1//! newverbs.sty (M. Scharrer) — `\newverbcommand{\cmd}[\verb]{before}{after}`.
2//!
3//! newverbs.sty:52-69 `\new@@verbcommand`: the created command opens a
4//! `\bgroup`, runs `before`, then the verb macro; `after` and the matching
5//! `\egroup` are appended to `\verb@egroup` (:58,64), which real `\verb`
6//! (latex.ltx:15501) executes when its verbatim scan ends. Our `\verb` closes
7//! its group through `\verb@egroup` too (sect06.rs), so the protocol is ported
8//! as is and the verb is whatever `\verb` (or the optional `[\verbcmd]`) means
9//! at the call: a package that redefines the `\verb`/`\verb@egroup` pair
10//! (accessibility.sty:1566-1577) keeps both halves. The command's group is a
11//! hidden one. It once leaked past every `\end{…}` ("Attempt to end mode
12//! internal_vertical" — homework.cls demos ×4 via
13//! `\newverbcommand{\cverb}{\color{…}}{}`), when `\verb` read its body without
14//! running `\verb@egroup`. `\fverb`/`\qverb` (:100-108) are provided the same
15//! way, and the `\MakeShortVerb`/`\MakeSpecialShortVerb` family (:112-137)
16//! verbatim. Guards: `perfect_kernel_batch54::newverbcommand_wraps_the_verb_body`,
17//! `binding_singletons_56::qverb_keeps_a_redefined_verb_pair`.

20/// newverbs.sty:52-69 `\new@@verbcommand`'s body, `\bgroup`/`\egroup` being
21/// the hidden pair: `\lx@newverbs@setup{after}` is :56-64 (after `\verb`'s own
22/// group closes, `\verb@egroup` runs `after` and closes the command's group),
23/// then `\verbatim@font` is selected BEFORE `before` runs (:65-66), so
24/// `before`, the body and `after` share the verbatim font — `\qverb`'s opening
25/// quote was roman (macros2e's `\MakeSpecialShortVerb\qverb\"`).
26/// `\lx@newverbs@font` keeps the document's encoding across `\verbatim@font`,
27/// whose `\lx@fontencoding{ASCII}` (OXIDIZED_DESIGN #144) is meant for verbatim
28/// text: the body still gets it from the `\verb` constructor's own font
29/// (sect06.rs `\@internal@text@verb`), and the user's code prints as pdflatex
30/// prints it — `\qverb`'s quotes are OT1 typewriter ‘‘ ’’, not ASCII `` ''.
31/// Guard: `binding_singletons_56::qverb_quotes_share_the_verbatim_font`.
32fn define_verb_command(
33  cmd: Token,
34  verb: Option<Tokens>,
35  before: Tokens,
36  after: Tokens,
37) -> Result<()> {
38  let mut body = vec![
39    T_CS!("\\lx@hidden@bgroup"),
40    T_CS!("\\newverbcommand@settings"),
41    T_CS!("\\lx@newverbs@setup"),
42    T_BEGIN!(),
43  ];
44  body.extend(after.unlist());
45  body.push(T_END!());
46  body.push(T_CS!("\\lx@newverbs@font"));
47  body.extend(before.unlist());
48  // :47-50: the verb command, `\verb` unless `[\verbcmd]` names another.
49  match verb {
50    Some(verb) if !verb.is_empty() => body.extend(verb.unlist()),
51    _ => body.push(T_CS!("\\verb")),
52  }
53  def_macro(cmd, None, Tokens::new(body), None)?;
54  Ok(())
55}
