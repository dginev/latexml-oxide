1//! mathscinet.sty — the AMS's transliteration vocabulary for MathSciNet output.
2//!
3//! Real source: `mathscinet.sty` v1.05 (2002/04/17), American Mathematical
4//! Society, LPPL, shipped in TeX Live as part of the **amsrefs** bundle
5//! (`texmf-dist/tex/latex/amsrefs/mathscinet.sty`). Perl LaTeXML has no binding
6//! for it — `\Dbar` and `\cprime` appear in no `.ltxml` file — so this is
7//! Rust-only, not a port of a Perl binding; the `.sty` itself is the ground truth.
8//!
9//! [MathSciNet](https://mathscinet.ams.org) is the AMS reviewing database, and
10//! its BibTeX export assembles a large share of pure-mathematics bibliographies.
11//! The macros here are how those records transliterate Cyrillic and South-Slavic
12//! names: `\cprime` for the soft sign ь, `\Dbar`/`\dbar` for Đ/đ.
13//!
14//! **Loaded the normal way, and only the normal way.** `\usepackage{mathscinet}`
15//! is the trigger, and `amsrefs.sty` L217 does
16//! `\RequirePackage{mathscinet}[2002/01/01]`. All three `\cprime` witnesses name
17//! the package themselves (2508.13753 L7, 2508.20226 L3, 2509.07628 L13) — they
18//! errored only because no binding existed.
19//!
20//! Nothing loads it on a document's behalf, and that is deliberate. The
21//! recursive `.bib` session does exactly that for `url.sty`, on the grounds that
22//! a real `.bst` writes `\providecommand{\url}` into the `.bbl`; the same
23//! argument does NOT hold here. Checked on witness 2605.11579: it never mentions
24//! mathscinet or amsrefs, and it uses `\bibliographystyle{alpha}` — `alpha.bst`
25//! contains no `Dbar` at all. So `\Dbar` is undefined in the author's own build
26//! too, real pdflatex raises the same undefined control sequence, and leaving it
27//! undefined is PARITY. Supplying it would push our error count below what the
28//! author's toolchain produces. Guard:
29//! `06_cluster_bibliography::bib_mathscinet_macro_yields_to_the_authors_own_definition`.
30//!
31//! **`\Provide…` semantics are load-bearing, not incidental.** The upstream file
32//! uses `\ProvideTextCommand`/`\ProvideTextCommandDefault` for the character
33//! commands, so an author who defined the name first keeps their meaning. That
34//! matters concretely: in a 4,000-paper scan of arXiv 2605, six papers define
35//! `\Dbar` themselves (four with `\newcommand`) and twelve define `\dbar` — and
36//! every one of those twelve means the inexact-differential đ of thermodynamics
37//! or a barred derivative, not a Croatian letter. Being a *package* rather than
38//! an always-present kernel definition is what keeps us out of their way, and
39//! `provide` below reproduces the deferral for the case where the package IS
40//! loaded.
41//!
42//! Each glyph binds the Unicode character carrying the author's visual intent
43//! (WISDOM #50). The upstream definitions build their glyphs by overprinting —
44//! `\Dbar` is `\leavevmode\lower.5ex\rlap{\hskip-.07em\accent"16}D` — which would
45//! reach the XML as a bare "D"; the mappings below are taken from the file's own
46//! **T1 branches**, which say what each glyph IS (`\Dbar`→`\DJ`, `\dbar`→`\dj`,
47//! `\polhk`→`\k`, `\soft`→`\v`, `\udot`→`\d`).
48//!
49//! This binding is the ONLY home of the family. An always-on `\cprime` stub was
50//! briefly kept in `latex_constructs_rust_only.rs` for `.bib`-borne use in a
51//! document that loads no package, and was retracted 2026-07-27: a definition
52//! that is always live can shadow an author's own, and since #416 we digest only
53//! the CITED entries of a `.bib`, which removed the trigger it existed for. A
54//! document that needs these must do what the real toolchain needs — load
55//! `mathscinet` (or `amsrefs`, which requires it), or define them in its own
56//! `.bib` `@preamble`, which executes.
57//!
58//! Witnesses: 2508.13753, 2508.20226, 2509.07628 (`\cprime`); 2605.11579
59//! (`\Dbar` in `MRREVIEWER = {Dragomir \v{Z}. \Dbar okovi\'{c}}`, which stays a
60//! parity error because that paper loads no package and its `.bst` has no
61//! `Dbar`).
62use crate::prelude::*;

64/// `\ProvideTextCommandDefault` semantics: define only if the name is free.
65///
66/// `body` is `&'static str` rather than `&str` because it is TeX source handed
67/// to the tokenizer, and `TeXString` (OXIDIZED_DESIGN — see `latexml_core::tokens`)
68/// only converts implicitly from a literal. Every caller below passes one, so
69/// this costs nothing and buys the guarantee: a runtime-built `String` — which
70/// is what a welded `Tokens::to_string()` arrives as — cannot reach this path
71/// without saying so via `TeXString::assembled`.
72fn provide(proto: &str, body: &'static str) -> Result<()> {
73  let (cs_tok, params) = parse_prototype(proto, true)?;
74  if lookup_meaning(&cs_tok).is_some() {
75    return Ok(());
76  }
77  def_macro(
78    cs_tok,
79    params,
80    ExpansionBody::Tokens(mouth::tokenize_internal(body)),
81    None,
82  )?;
83  Ok(())
84}

87LoadDefinitions!({
88  // L36 is `\RequirePackage{textcmds}`, deliberately NOT reproduced: textcmds
89  // has no binding, so requiring it would raw-load a docstrip `.sty` that plays
90  // `\pcatcode` games, to obtain exactly two commands (`\tprime`, `\tsup`) whose
91  // results are inlined below as the character and `\textsuperscript`.
92
93  // ---- Math alphabet shorthands (L38-49, verbatim) ----
94  provide("\\bold", "\\mathbf")?;
95  provide("\\scr", "\\mathcal")?;
96  // L41-49 defers \germ to \begin{document} only to diagnose a missing
97  // amsfonts; \mathfrak is always available here, so bind it directly.
98  provide("\\germ", "\\mathfrak")?;
99  // L50-52: superscript shorthands, both \tsup (textcmds).
100  provide("\\romsup{}", "\\textsuperscript{#1}")?;
101  provide("\\asup{}", "\\textsuperscript{#1}")?;
102  provide("\\hslash", "\\hbar")?;
103
104  // ---- Cyrillic / South-Slavic transliteration glyphs ----
105  // L57-58: \ProvideTextCommand{\Dbar}{T1}{\DJ}. T1's \DJ IS U+0110 LATIN
106  // CAPITAL LETTER D WITH STROKE, so the encoding branch names the character
107  // outright; the Default branch just draws it. Witness 2605.11579's
108  // `MRREVIEWER = {Dragomir \v{Z}. \Dbar okovi\'{c}}` — Đoković.
109  provide("\\Dbar", "\u{0110}")?;
110  // L63: \ProvideTextCommand{\dbar}{T1}{\dj} — U+0111, the lowercase đ.
111  // Safe to bind HERE and nowhere else: twelve of the twelve papers in the
112  // 2605 scan that define `\dbar` themselves mean a math differential, and a
113  // package binding cannot reach them unless they load the package.
114  provide("\\dbar", "\u{0111}")?;
115  // L75-77: \cprime is \tprime (U+02B9 MODIFIER LETTER PRIME), \cdprime is two
116  // of them (U+02BA MODIFIER LETTER DOUBLE PRIME), \bud is \cdprime.
117  // These render the Russian soft/hard signs in transliterated names —
118  // `Gel\cprime fand` is Gelʹfand. Witnesses 2508.13753 (body prose, L2131),
119  // 2508.20226, 2509.07628 (a pre-compiled `.bbl`).
120  provide("\\cprime", "\u{02B9}")?;
121  provide("\\cdprime", "\u{02BA}")?;
122  provide("\\bud", "\u{02BA}")?;
123  // L78: \cydot — a raised dot used in Cyrillic transliteration.
124  provide("\\cydot", "\u{00B7}")?;
125
126  // NOT in the real `mathscinet.sty`: `\Cprime`/`\Cdprime` are the capitalized
127  // spellings that `cyracc.def` (L53-55) and MathSciNet `.bst` preambles emit,
128  // and they arrive with exactly the same data as `\cprime`. Kept beside it so
129  // the four move together; the always-on stub in
130  // `latex_constructs_rust_only.rs` §5 covers the same four, so in practice
131  // `provide` finds them defined and these are the no-op they should be.
132  provide("\\Cprime", "\u{02B9}")?;
133  provide("\\Cdprime", "\u{02BA}")?;
134
135  // ---- Under-accents (L104-110) ----
136  // These use \DeclareTextCommandDefault, i.e. unconditional, and the file
137  // draws them with \@underaccent box kerning. The Unicode combining marks
138  // below are the same accents as characters, applied AFTER the base letter.
139  // \udot's own default IS the kernel \d (L109), and \polhk/\soft name kernel
140  // accents in every encoding branch they define (L111-113, L156-158).
141  DefMacro!("\\udot{}", "\\d{#1}");
142  DefMacro!("\\polhk{}", "\\k{#1}");
143  DefMacro!("\\soft{}", "\\v{#1}");
144  DefMacro!("\\utilde{}", "#1\u{0330}");  // combining tilde below
145  DefMacro!("\\uarc{}",   "#1\u{032E}");  // combining breve below
146  DefMacro!("\\lfhook{}", "#1\u{0326}");  // combining comma below
147  DefMacro!("\\dudot{}",  "#1\u{0324}");  // combining diaeresis below
148});
