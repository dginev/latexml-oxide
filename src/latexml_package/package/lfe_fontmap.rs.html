1//! LFE font encoding: arabi's Farsi font encoding (lfeenc.def).
2//!
3//! Each slot decodes to the character its glyph shows in the encoding's default font (nazli, lfecmr.fd), as the font's
4//! encoding vector `fonts/enc/dvips/arabi/farsiwebencoding.enc` names it (generated by `tools/arabi_fontmap_tables.py`). A letter's slot holds one of its
5//! contextual forms (the font's ligature program picks the others while setting); every form decodes to the
6//! letter itself, which the browser shapes again. A ligature decodes to its letters (`\llahchar`, set after
7//! `\alef`: lam lam shadda heh). The font draws for right-to-left setting: a slot holding the mirror image of a
8//! Bidi_Mirrored character (`(` holds `parenright`, `<` `guillemotright`) decodes to the logical character, which
9//! the bidi algorithm mirrors again on display. Perl has no LFE map: the encoding falls back to OT1 and the
10//! letters decode to nothing (OXIDIZED_DESIGN_DIVERGENCES #415). Witness: arabi/samplebook.
11//! `\alefmaqsura`'s slot holds the Farsi yeh glyph and decodes to it.
