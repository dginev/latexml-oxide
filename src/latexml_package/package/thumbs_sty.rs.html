1//! thumbs.sty — page-edge thumb tabs.
2//!
3//! The tabs are drawn at shipout (`\AtBeginShipout`, thumbs.sty:1076) at
4//! absolute page positions; LaTeXML never ships out, so the reset the
5//! handler performs (:1151 `\gdef\th@mbtoprint{0}`) never runs and the
6//! package's own state machine raises "\thumbnewcolumn after \addthumb"
7//! (:573) on the second column (thumbs-example; Perl identical). Thumb tabs
8//! have no reflowable-HTML meaning, so the real package is loaded and then
9//! put in the author's own off-mode — the `hidethumbs` branch, thumbs.sty:
10//! 1531-1538 (`\addthumb`/`\thumbnewcolumn` → `\relax`), applied after the
11//! load because kvoptions' `\DeclareBoolOption` (:130) re-initialises the
12//! flag at load time. Everything else stays the real thumbs.sty.
13//! Guard: `perfect_kernel_batch56::thumbs_loads_in_its_own_hide_mode`.
14use crate::prelude::*;
15
16LoadDefinitions!({
17  InputDefinitions!("thumbs", noltxml => true, extension => Some(Cow::Borrowed("sty")));
18  // thumbs.sty:1531-1538, the `\ifthumbs@hidethumbs` branch.

20    r"\thumbs@hidethumbstrue\renewcommand{\addthumb}[4]{\relax}\renewcommand{\thumbnewcolumn}{\relax}"
21  );
