1//! No-op stub for constants.sty.
2//!
3//! constants.sty (TL — "Labeling and numbering constants") provides
4//! `\newconstantfamily`, `\C`, `\Cl`, `\refconstant`, `\resetconstant`.
5//! Its end-of-document bookkeeping (constants.sty L143-148) does a *raw*
6//! `\if@filesw … \makeatletter \input\jobname.aux \fi` to re-read the
7//! label `.aux` for the "constants may have changed, rerun" check.
8//!
9//! Until `\begin{document}` opened `\jobname.aux` (sect02.rs, OXIDIZED_DESIGN
10//! #576), no in-memory `<jobname>.aux` existed and that raw `\input\jobname.aux`
11//! failed with
12//! `Error:missing_file:<jobname>.aux` (constants.sty uses the hard `\input`,
13//! not LaTeX's silent `\@input`). The re-read stays out of the port: there is
14//! no `.aux` round trip to check (see below).
15//!
16//! Perl LaTeXML never observes this: its default TEXINPUTS excludes
17//! `/usr/share/texlive`, so constants.sty is reported missing-file and
18//! skipped — providing ZERO constants functionality. Verified on
19//! arXiv:2002.05335: Perl emits `Warning:missing_file:constants` and
20//! completes (its residual errors are unrelated math-mode issues).
21//!
22//! The package is ported whole except that end-of-document re-read: `\Cl{<label>}` records its constant at once
23//! (where constants.sty writes `\newlabelconstant` to the `.aux` for the next run), so `\Cr{<label>}` after it gives
24//! the constant and a forward one the "??" and warning of LaTeX's first run. Run 340: `\Cr` was the first error of 253
25//! papers under the former no-op stub, which also dropped every `\C`'s C_n (2508.09984, 2103.05634, 2508.14888).
26//! The `\null` closing each `\@set…constant` branch (an empty box, ending the number or name the
27//! `\expandafter` produced) is `\relax` here, which ends it the same way without an empty box in the formula.
28//!
29//! Witnesses (CONVERR_1 → OK): 2004.04403, 2002.05335, 1501.05396,
30//! 1503.01423, 1505.03199, 1506.02544, 1506.03382, 1506.03705,
31//! 1508.03002, 1509.02505, 1512.06906, 1601.01096, 1603.05947,
32//! 1606.09238, … (70 total).
