1//! tabto.sty (tabto-ltx) — tab to a horizontal position.
2//!
3//! Perl LaTeXML has NO binding and raw-loads this package. The raw `\tabto`
4//! implements positioning via a `$$…$$` display-math measurement hack (it reads
5//! `\predisplaysize` inside a one-row `\halign`). Our engine turns that hack into a
6//! spurious empty display equation AND breaks the following content onto a new line
7//! — so a right-justified `algpseudocodex` `\Comment` (`\tabto{\dimexpr\linewidth-…}`,
8//! `\RequirePackage{tabto}` at algpseudocodex.sty L29) stacks BELOW its statement
9//! instead of flushing right (witness arXiv 2511.21969 Algorithm 1).
10//!
11//! LaTeXML has no positional layout model, so we approximate `\tabto` as `\hfill`
12//! (fill to the tab stop ≈ push the following content to the right) — the dominant
13//! use is exactly the right-justified algorithm comment, which `\hfill` renders as a
14//! `float:right` on the same line, matching the pdflatex golden. Surpass over Perl,
15//! which raw-loads the `$$` hack and stacks the comment. OXIDIZED_DESIGN #151.
16use crate::prelude::*;
17
18#[rustfmt::skip]
19LoadDefinitions!({
20  // Length registers documents read through tabto (algpseudocodex uses both).
21  DefRegister!("\\CurrentLineWidth" => Dimension::new(0));
22  DefRegister!("\\TabPrevPos" => Dimension::new(0));
23  // \tabto{pos} and \tabto*{pos} (the overlap `\tab*` variant) → right-flush.
24  DefMacro!("\\tabto OptionalMatch:* {}", "\\hfill");
25  // \tab advances to the next tab stop; same approximation.
26  DefMacro!("\\tab", "\\hfill");
27  DefMacro!("\\NextTabStop", "\\linewidth");
28  // Remaining tabto API a document may touch — harmless no-ops / stubs.
29  def_macro_noop("\\TabPositions{}")?;
30  def_macro_noop("\\NumTabs OptionalMatch:* {}{}")?;
31  def_macro_noop("\\TabsBadStop")?;
32});
