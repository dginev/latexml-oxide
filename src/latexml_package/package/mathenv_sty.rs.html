1//! mathenv.sty — TWO different packages ship under this name; the binding
2//! raw-loads the self-contained one and loads only `mdwtab` for the mdwtools one.
3//!
4//! * **Bosisio's "Extended math environments"** (Francesco Bosisio, 1997) — self-contained, defines
5//!   `\newenvironment{EqSystem}`/`{Equation}` and an active-`&` system-of-equations machinery. NOT
6//!   in TeX Live (papers ship it locally). Perl LaTeXML has no `mathenv.sty.ltxml`, so under the
7//!   ar5iv gate (`INCLUDE_STYLES=true`) it RAW-LOADS this file and converts cleanly (witness
8//!   1710.07800 → 92 errors here without the raw-load, 0 with it).
9//!
10//! * **Mark Wooding's mdwtools `mathenv`** — opens with `\RequirePackage{mdwtab}` (a full `tabular`
11//!   rewrite). Our `mdwtab` binding can't supply its `\tab@*` internals, so raw-loading Wooding's
12//!   mathenv cascades (`\tab@setstate` / `\tab@preamble` / … undefined → ~42 errors; witness
13//!   0910.3293). The binding does not raw-load it; it loads our `mdwtab` binding as mathenv.sty:53
14//!   does, whose `array` the document then uses (rc_struct3 E2). Its own environments (`eqnarray`
15//!   rewrite, `spliteqn`, …) are left to the kernel's. The principled fix for THIS variant is a
16//!   working `mdwtab` port.
17//!
18//! Distinguish the two by the `mdwtab` requirement (Bosisio's file never mentions it; Wooding's
19//! does `\RequirePackage{mdwtab}`): raw-load the self-contained Bosisio variant like Perl; for the
20//! mdwtools one load only `mdwtab`, where Perl (no binding for either) raw-loads both.
21//! (Task #273 — prefer raw-load over stubs; here the stub is kept ONLY for the variant whose
22//! dependency we can't yet raw-load.)
23use crate::prelude::*;
24
25LoadDefinitions!({
26  let requires_mdwtab = find_file(
27    "mathenv",
28    Some(FindFileOptions {
29      ext_type: Some(Cow::Borrowed("sty")),
30      ..Default::default()
31    }),
32  )
33  .and_then(|p| std::fs::read_to_string(&p).ok())
34  .is_some_and(|content| content.contains("mdwtab"));
35  if !requires_mdwtab {
36    // Bosisio's self-contained mathenv → raw-load it, matching Perl.
37    InputDefinitions!("mathenv", noltxml => true, extension => Some(Cow::Borrowed("sty")));
38  } else {
39    // Wooding's mdwtools mathenv → no raw load (avoid the broken-mdwtab cascade), but its
40    // `\RequirePackage{mdwtab}` (mathenv.sty:53) loads our mdwtab binding, whose `array` the document then uses.
41    RequirePackage!("mdwtab");
42  }
43});
