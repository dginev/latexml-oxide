42  // (`\count10`-`\count15` past 255, LaTeX 2020-02 on) etex.sty:103-139 aliases the single forms, as this binding does,
43  // and stops, leaving the block forms undefined (TL2025 pdflatex: "Undefined control sequence"). Papers of that era use
