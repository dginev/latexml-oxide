1//! currfile.sty — current input-file name/path/ext (Rust-only binding; Perl
2//! has none and falls through to `missing_file`).
3//!
4//! The real package is loaded raw: it is pure kernel-level TeX (kvoptions +
5//! filehook) and defines `\currfilename` = `\jobname.tex` for the main
6//! file, plus the `\ifcurrfilename{name}{yes}{no}` 3-argument macro family
7//! (currfile.sty:322-335, via `\currfile@if` :337-347). An earlier stub
8//! shape here defined that family as `DefConditional!` — a TeX `\if…`
9//! whose `\else`/`\fi` never arrives, so `\ifcurrfilename{x}{yes}{no}`
10//! swallowed the rest of the document as an `\iffalse` body (witness: TL
11//! doc corpus currfile/currfile, pythontex/pythontex — pythontex.sty:32
12//! `\RequirePackage{currfile}`). Complete support over stubs.
13//!
14//! Known limit: the per-`\input` push/pop (currfile.sty:68-73 hooks
15//! `\filehook@every@atbegin`/`@atend`, fired from LaTeX's `file/before`
16//! hooks in filehook-2020.sty) does not fire in this engine, which has no
17//! `file/*` hook layer (`tex_file_io.rs`, `\CurrentFile` note). Inside a
18//! `\input` file the macros keep reporting the main file.
19use crate::prelude::*;
20
21LoadDefinitions!({
22  // Real currfile.sty L30 `\RequirePackage{filehook}` — go through the
23  // binding (it locks `\filehook@cmp` and registers the versioned
24  // `filehook-2020.sty` sub-file as an INTERPRETABLE source) so the raw
25  // currfile.sty finds `\filehook@prefixwarg` & co. defined.
26  RequirePackage!("filehook");
27  InputDefinitions!("currfile", noltxml => true, extension => Some(Cow::Borrowed("sty")));
28});
