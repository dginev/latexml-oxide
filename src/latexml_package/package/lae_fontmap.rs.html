1//! LAE font encoding: arabi's Arabic font encoding (laeenc.def).
2//!
3//! Each slot decodes to the character its glyph shows in the encoding's default font (aealmohanadb, laecmr.fd), as the font's
4//! encoding vector `fonts/enc/dvips/arabi/ararabeyes.enc` names it (generated by `tools/arabi_fontmap_tables.py`). A letter's slot holds one of its
5//! contextual forms (the font's ligature program picks the others while setting); every form decodes to the
6//! letter itself, which the browser shapes again. A ligature decodes to its letters (`\llahchar`, set after
7//! `\alef`: lam lam shadda heh). The font draws for right-to-left setting: a slot holding the mirror image of a
8//! Bidi_Mirrored character (`(` holds `parenright`, `<` `guillemotright`) decodes to the logical character, which
9//! the bidi algorithm mirrors again on display; the font's `/` slot holds a backslash, which Unicode does not
10//! mirror, and decodes to the typed `/`. Perl has no LAE map: the encoding falls back to OT1 and the letters
11//! decode to nothing (OXIDIZED_DESIGN_DIVERGENCES #415). Witness: arabi/samplebook.
