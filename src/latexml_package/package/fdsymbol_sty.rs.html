1//! fdsymbol.sty — a math symbol font (Michael Ummels) for the symbols of amssymb and many more.
2//!
3//! The package is not raw-loaded: its `\fdsy@DeclareSymbol` does `\if\relax\noexpand#1\let#1\undefined\fi` before each
4//! `\DeclareMathSymbol` (fdsymbol.sty:110-114), which left locked kernel math chars (`\prime`, `\downarrow`, …)
5//! undefined (2406.19499, 2411.08746). Perl has no binding, and with INCLUDE_STYLES off skips the package. The binding
6//! loads what fdsymbol.sty loads, defines the AMS symbols and alphabets it redeclares from amsfonts' and amssymb's
7//! bindings without loading either (fdsymbol.sty:194-195; `\@ifpackageloaded{amssymb}` stays false, and the AMS names it
8//! never declares stay undefined: `NOT_FDSYMBOL`), and its own symbols as Unicode: `FDSYMBOL_SYMBOLS`.
