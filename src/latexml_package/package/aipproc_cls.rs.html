188  // Perl aipproc.cls.ltxml does NOT define \references — Perl behaves
189  // lossy-silent for `\begin{references}…\bibitem` under aipproc
190  // (drops the whole bibliography, reports "No obvious problems").
191  // Rust's stricter validator surfaces Error:malformed:ltx:bibitem
192  // "…isn't allowed in <ltx:section>". Rust-over-Perl improvement:
193  // alias to the thebibliography machinery so the content is
194  // preserved. Fixes 4 papers in docs/archive/SANDBOX_TRIAGE_2026-05-21.md Class D bibitem-aipproc
195  // cluster (astro-ph9711070, cond-mat0109365, nucl-ex9706010,
196  // nucl-th0010030). See also the mirror alias in aipproc_sty.rs.
197  //
198  // CRITICAL: `\reference` is `\let` to `\bibitem` ONLY WITHIN the `references`
199  // environment (inside `\references`'s body), NOT globally. Perl leaves
200  // `\reference` undefined, so a paper that defines its own
201  // `\newcommand{\reference}{...}` (a common math shorthand, e.g.
202  // `\newcommand{\reference}{\mathrm{ref}}`) succeeds. A GLOBAL alias here made
203  // `\reference` already-defined, so the user `\newcommand` silently failed and
204  // `\reference` stayed `\bibitem` — firing a `\bibitem` inside `$…$` math
205  // (`$\temp_{\reference}$`) → a `<ltx:bibitem>` in `<ltx:XMArg>` → math-mode
206  // leak that swallowed the real bibliography & caption tags. Witness
207  // 1701.08966: RUST 102 errors / FATAL_3 → 0 (Perl: 1; surpasses). Scoping to
208  // the env keeps the aipproc-bibitem cluster working (those use
209  // `\begin{references}\reference{…}`). The `\let` is local to the env group.
210  DefMacro!("\\references", "\\let\\reference\\bibitem\\thebibliography{}");
211  Let!("\\endreferences", "\\endthebibliography");
