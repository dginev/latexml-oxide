1//! The frontmatter observer (frontmatter model M3; KERNEL_CAPABILITIES K23): what the document's `\title`/`\author`-family
2//! calls hold, read as TeX prints them, which the emitter writes Perl's own API calls from (OXIDIZED_DESIGN_DIVERGENCES
3//! #837, #980).
4//!
5//! - [`ledger`]: a block per `\author`-family call (the kernel `\author`, the bindings' `\lx@add@authors*` calls) with
6//!   its stamped position range, its options and its place in the frontmatter queue; the S1 stamp of each `\title`;
7//!   the contact/affiliation API calls (`\lx@annotate@frontmatter`'s queue entries); the footnote texts made after a
8//!   block (`\footnotetext`, read for the `\footnotemark` a name shows).
9//! - [`rehearsal`]: a block's stamped tokens digested in a group of Layer-B event bindings (`\and` a separator, `\\` a
10//!   break, `\thanks` a note, the contact commands contacts), through the speculative-run engine: assignments rolled
11//!   back, diagnostics held, output muted, the frontmatter frozen; the digested list handed to the lexer, then
12//!   discarded.
13//! - [`events`]: the digested list read into events (names, marks, separators, breaks, contacts, notes, layout), each
14//!   with its span of the field's positions (`fieldProv`/`fieldSerial`, core `gullet::field_cover_of`) and its ink.
15//! - [`marks`]: whether a formula in a name or an affiliation is a mark, read from its digested XMath (as digested and
16//!   as parsed), the one reading of the content check's view of the placed output, `relocate::shown_marks` and
17//!   `name_text::is_name_mark` (frontmatter refactor stage 1).
18//! - [`resolver`] (S2a.2): the ledger's blocks and API calls read into the frontmatter tuples (creators with their
19//!   names, affiliations, contacts and notes; the block's own), each association with the rule that decided it, under
20//!   the family's conventions from [`policy`] (each binding declares its own at load; read keyed on the binding owning
21//!   `\author` and the hook).
22//! - [`reading`]: the flush's part — every real flush (`digest_front_matter`) rehearses and lexes each block not
23//!   rehearsed yet — and the ledger's JSON dump the guards read the reading by, in process.
24//! - [`emitter`]: the emitter (`emitter::emit`, OD #980), which replaces the flush's queued creators and their annotations
25//!   by Perl's calls built from the reading, its vocabulary and cuts, and the content check on the placed output. (The S2b
26//!   writer that rewrote placed frontmatter after `insert_frontmatter`, and the census switch `LATEXML_FM_SHADOW`, were
27//!   deleted in DEL4.)
28//! - [`argument_marks`]: the query on an argument's marks as digested (Option C F0), on the one rehearsal of
29//!   [`separators`].
30//! - [`separators`]: a binding's query on an argument's `\and`-family separators by meaning (`argument_separators`,
31//!   `\lx@fm@separators`; OD #995).
