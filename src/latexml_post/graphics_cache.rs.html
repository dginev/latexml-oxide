1//! Content-addressed graphics cache.
2//!
3//! Every `convert_image` / `convert_image_svg` call rasterises a
4//! self-contained source file (PDF / EPS / PNG / SVG) with a small set
5//! of render-shaping inputs (page, density, target format). Across a
6//! canvas of arXiv submissions the same byte content recurs constantly
7//! — common journal logos, reused author-affiliation marks, and
8//! regenerated runs of the same paper. PERFORMANCE.md §5 records the
9//! `graphics` phase as **36.5%** of corpus wall, so a cache that hits
10//! even a third of the time shaves ~11% off corpus wall.
11//!
12//! ## Heritage: Perl `LaTeXML.cache`
13//!
14//! The Perl post-processor stores a tied BerkeleyDB hash named
15//! `LaTeXML.cache` per output directory. Keys are built from the
16//! processor class, the source path, and the transform string; values
17//! are `"dest|width|height"` strings. The features we mirror are
18//! listed below.
19//!
20//! - **Disable flag** (Perl: `nocache`) → env `LATEXML_GRAPHICS_CACHE_OFF`.
21//! - **Re-use across runs** (Perl: one .cache per dest dir) → global XDG cache, shared across all
22//!   conversions on the host. This is a strict superset of the Perl behaviour: cross-paper sharing,
23//!   plus reproducible content-keying instead of path-keying.
24//! - **Source-staleness check** (Perl compared source mtime to cached output mtime) → unnecessary
25//!   here: the cache key is SHA-256 of the source *bytes*, so any source edit produces a different
26//!   key.
27//! - **Cached dimensions** (Perl: width/height in the cached value) → sidecar `<hash>.<ext>.dims`
28//!   file containing `width\nheight\n`. Lookup returns `(success, dims)`; callers skip the
29//!   `read_image_dimensions` syscall on hits.
30//!
31//! Beyond Perl: content-hash keying gives stricter staleness; XDG
32//! placement gives cross-paper reuse; multi-process safety (below)
33//! lets canvas sweeps share the cache without corruption.
34//!
35//! ## Cache key
36//!
37//! SHA-256 of:
38//!   `source bytes ‖ page ‖ density ‖ target-extension [‖ SVG_KEY_VERSION]`
39//!
40//! The page/density bytes are appended as 4-byte little-endian; the
41//! extension is appended as ASCII lower-case bytes, and an `svg` key ends
42//! with `SVG_KEY_VERSION`, which retires cached SVGs. Bytes-only keying
43//! makes the cache reproducible across machines and gives near-zero
44//! collision risk for our use.
45//!
46//! ## On-disk layout
47//!
48//!   `$XDG_CACHE_HOME/latexml-oxide/graphics/<aa>/<full-hash>.<ext>`
49//!   `$XDG_CACHE_HOME/latexml-oxide/graphics/<aa>/<full-hash>.<ext>.dims`
50//!   `$XDG_CACHE_HOME/latexml-oxide/graphics/.prune.lock`
51//!
52//! Sharded by the first two hex characters of the hash to keep any one
53//! directory's entry count bounded (worst case ~1/256th of the total
54//! cache size).
55//!
56//! `$XDG_CACHE_HOME` falls back to `$HOME/.cache` per the XDG spec.
57//!
58//! ## Multi-process safety
59//!
60//! The cache is designed to be shared by parallel `cortex_worker`
61//! processes within a canvas sweep. Concurrency guarantees:
62//!
63//! 1. **Concurrent writes to the same key**: each writer renders to a private
64//!    `<final>.tmp.<pid>.<nanos>` sidecar then issues a single `rename(2)` into the final path.
65//!    `rename` is atomic on the same filesystem; if two writers race, the last `rename` wins, and
66//!    because both sources are byte-equivalent the outcome is correct. `link_or_copy` retries once
67//!    on `EEXIST` for the same reason.
68//! 2. **Concurrent reads + writes**: a reader hardlinks the cached file into the destination. POSIX
69//!    `link(2)` either succeeds (returning a new directory entry that survives any subsequent
70//!    `unlink` of the source) or fails cleanly. If the cache file is unlinked between hash
71//!    computation and link, the reader gets a miss and falls through — no data corruption.
72//! 3. **Concurrent prunes**: prune holds `flock(LOCK_EX | LOCK_NB)` on `.prune.lock`. If another
73//!    process already holds the lock, this one skips its prune attempt. Only one prune runs at a
74//!    time per machine. The prune itself walks the dir, sorts by mtime, deletes oldest until under
75//!    cap — and tolerates `ENOENT` (another writer could have re-used the entry concurrently). It
76//!    also removes every `.tmp.` sidecar changed (ctime on Unix) over an hour ago: a killed process's
77//!    unfinished install.
78//! 4. **Hardlinked dest ↔ cache**: when `link_or_copy` hardlinks the cache file into the
79//!    destination, that hardlink is independent of the cache lifecycle. Even if a prune deletes the
80//!    cache entry afterwards, the destination's hardlink keeps the data alive on the filesystem.
81//!
82//! These guarantees hold on any POSIX filesystem. On Windows (which
83//! lacks robust `flock`), the prune lock is a best-effort `OpenOptions`
84//! create-new sentinel — same correctness, slightly more retry traffic.
85//!
86//! ## Lifecycle
87//!
88//! * **Hit**: hardlink the cache file into the destination (zero-copy on the same filesystem). If
89//!   hardlink fails (cross-filesystem, EXDEV), fall back to a regular file copy. Read the `.dims`
90//!   sidecar if present.
91//! * **Miss-then-success**: copy the produced destination back into the cache. Write the `.dims`
92//!   sidecar alongside.
93//! * **LRU prune**: each insertion checks the on-disk total against the cap
94//!   (`LATEXML_GRAPHICS_CACHE_MAX_MB`, default 2048 = 2 GB). When over cap, holds the prune lock,
95//!   sorts entries by mtime ascending, deletes until under cap. File access on read also refreshes
96//!   the mtime so frequently-hit entries survive.
97//!
98//! ## Disable / tune
99//!
100//! * `LATEXML_GRAPHICS_CACHE_OFF=1` — bypass entirely (read+write both skipped). The wrapper
101//!   devolves to the bare conversion call.
102//! * `LATEXML_GRAPHICS_CACHE_DIR=/path` — override the cache directory.
103//! * `LATEXML_GRAPHICS_CACHE_MAX_MB=N` — cache size cap.
104

126/// Memoised disabled flag (read env once at first call).
127fn disabled() -> bool {
128  static CELL: OnceLock<bool> = OnceLock::new();
129  *CELL.get_or_init(|| {
130    matches!(
131      std::env::var("LATEXML_GRAPHICS_CACHE_OFF")
132        .ok()
133        .as_deref()
134        .map(|s| s.trim()),
135      Some("1") | Some("true") | Some("yes")
136    )
137  })
138}

140/// Cache root, recomputed on each call.
141///
142/// Originally OnceLock-cached, but that bakes in whatever value the
143/// env-var has at first call and locks out any later setter. In tests
144/// (where one test binary contains both `graphics::*` and
145/// `graphics_cache::*` tests), an earlier `graphics::*` test that
146/// invokes `Graphics::process` triggers `cache_root()` with no
147/// `LATEXML_GRAPHICS_CACHE_DIR` set — pinning the cache to
148/// `~/.cache/latexml-oxide/graphics`. Subsequent `graphics_cache::*`
149/// tests then set the env var via `shared_cache_dir()` but the
150/// OnceLock ignores it, causing cache files to land outside the test
151/// dir and the assertions to fail. Re-reading the env var on each
152/// call costs ~one syscall in production (LATEXML_GRAPHICS_CACHE_DIR
153/// never changes there) — negligible compared to the disk I/O the
154/// cache layer drives.
155fn cache_root() -> Option<PathBuf> {
156  if let Ok(p) = std::env::var("LATEXML_GRAPHICS_CACHE_DIR") {
157    if !p.is_empty() {
158      return Some(PathBuf::from(p));
159    }
160  }
161  let base = std::env::var_os("XDG_CACHE_HOME")
162    .map(PathBuf::from)
163    .or_else(|| std::env::var_os("HOME").map(|h| PathBuf::from(h).join(".cache")))?;
164  Some(base.join("latexml-oxide").join("graphics"))
165}

167/// Cache size cap in bytes, read once from env.
168fn max_bytes() -> u64 {
169  static CELL: OnceLock<u64> = OnceLock::new();
170  *CELL.get_or_init(|| {
171    std::env::var("LATEXML_GRAPHICS_CACHE_MAX_MB")
172      .ok()
173      .and_then(|s| s.parse::<u64>().ok())
174      .unwrap_or(DEFAULT_MAX_MB)
175      .saturating_mul(1024 * 1024)
176  })
177}

193/// Whether a given conversion consults the shared graphics cache.
194///
195/// The cache root is *process-global, host-persistent* state: it comes
196/// from `LATEXML_GRAPHICS_CACHE_DIR`, else
197/// `$XDG_CACHE_HOME/latexml-oxide/graphics`, which survives across runs
198/// and across unrelated conversions. A caller that needs its conversions
199/// to actually *run* — rather than be served from whatever a previous
200/// run on this host happened to leave behind — must be able to opt out,
201/// and must be able to do so **without mutating the environment**
202/// (`set_var` is process-wide and racy against every other thread).
203/// Hence an explicit, caller-threaded policy rather than another env var.
204///
205/// The env kill-switch `LATEXML_GRAPHICS_CACHE_OFF=1` still applies
206/// independently, inside [`lookup`] / [`store`].
207#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
208pub enum CachePolicy {
209  /// Consult and populate the shared cache. The production default.
210  #[default]
211  Shared,
212  /// Bypass the cache entirely: every conversion runs, nothing is read
213  /// and nothing is stored. Used where the *conversion itself* is the
214  /// observable under test, so a prior run's cached output must not be
215  /// able to substitute for it.
216  Bypass,
217}

219/// Render-shaping inputs that go into the cache key alongside source
220/// bytes. Two calls with the same `RenderKey` MUST produce
221/// byte-equivalent output (modulo metadata variation tools like
222/// ImageMagick are known to introduce — see `compare_outputs_strict`
223/// audit in the spawn paths).
224#[derive(Debug, Clone, Copy, PartialEq, Eq)]
225pub struct RenderKey {
226  /// 1-based page selector (graphicx convention). `None` ⇒ default.
227  pub page:    Option<u32>,
228  /// DPI for raster conversions; 0 for pure vector (SVG) paths.
229  pub density: u32,
230  /// Target format, derived from destination extension (lowercase, no dot).
231  /// e.g. `"png"`, `"svg"`, `"jpg"`. Empty if missing.
232  pub ext:     &'static str,
233}

244/// A source file's SHA-256 state after its bytes: its content identity (the graphics pass's dedupe key) and, extended
245/// by a [`RenderKey`], its cache key, from one read of the file.
246#[derive(Clone)]
247pub struct SourceDigest(Sha256);
248
249impl SourceDigest {
250  /// Hash the file at `source_path`; `None` if it can't be opened or read.
251  pub fn of_file(source_path: &Path) -> Option<Self> {
252    let mut file = fs::File::open(source_path).ok()?;
253    let mut hasher = Sha256::new();
254    // 64 KB scratch buffer; large enough to dwarf syscall overhead, small
255    // enough to keep stack/heap pressure low under high concurrency.
256    let mut buf = [0u8; 64 * 1024];
257    loop {
258      match file.read(&mut buf) {
259        Ok(0) => break,
260        Ok(n) => hasher.update(&buf[..n]),
261        Err(_) => return None,
262      }
263    }
264    Some(SourceDigest(hasher))
265  }
266
267  /// The SHA-256 of the file's bytes.
268  pub fn content(&self) -> [u8; 32] { self.0.clone().finalize().into() }
269
270  /// The cache-key hash of `(source bytes, key)`, as lowercase hex.
271  fn key_hash(&self, key: RenderKey) -> String {
272    let mut hasher = self.0.clone();
273    hasher.update(key.page.unwrap_or(0).to_le_bytes());
274    hasher.update(key.density.to_le_bytes());
275    hasher.update(key.ext.as_bytes());
276    if key.ext == "svg" {
277      hasher.update(SVG_KEY_VERSION.as_bytes());
278    }
279    // sha2 0.11 returns a `hybrid_array::Array`, which (unlike 0.10's
280    // `GenericArray`) does not implement `LowerHex`, so `format!("{:x}", _)`
281    // no longer compiles. Render the digest to lowercase hex by hand — same
282    // output as the old `{:x}`, and version-agnostic.
283    use std::fmt::Write as _;
284    let digest = hasher.finalize();
285    let mut hash = String::with_capacity(digest.len() * 2);
286    for byte in digest.iter() {
287      let _ = write!(hash, "{byte:02x}");
288    }
289    hash
290  }
291}

293/// Compute the cache-key hash for `(source_bytes, render_key)`.
294fn hash_key(source_path: &Path, key: RenderKey) -> Option<String> {
295  Some(SourceDigest::of_file(source_path)?.key_hash(key))
296}

298/// The cache key of `(source, key)`: from `digest`, the source already read, or else from the file.
299fn source_key(source: &str, digest: Option<&SourceDigest>, key: RenderKey) -> Option<String> {
300  match digest {
301    Some(digest) => Some(digest.key_hash(key)),
302    None => hash_key(Path::new(source), key),
303  }
304}

306/// Build the cache file path for a given hash + extension.
307fn cache_path(root: &Path, hash: &str, ext: &str) -> PathBuf {
308  let shard = &hash[..2.min(hash.len())];
309  let mut p = root.join(shard);
310  if ext.is_empty() {
311    p.push(hash);
312  } else {
313    p.push(format!("{hash}.{ext}"));
314  }
315  p
316}

318/// Path to the `.dims` sidecar for a cache entry.
319fn dims_sidecar(cache_file: &Path) -> PathBuf {
320  let mut s = cache_file.as_os_str().to_owned();

322  PathBuf::from(s)

325/// Hardlink `src` → `dst`; on cross-filesystem or other failure, fall
326/// back to plain copy. Returns `true` on success.
327fn link_or_copy(src: &Path, dst: &Path) -> bool {
328  if let Some(parent) = dst.parent() {
329    if fs::create_dir_all(parent).is_err() {
330      return false;
331    }
332  }
333  // Try hardlink first (zero-copy). Hardlinking from cache to dest is
334  // safe because graphics outputs are immutable artefacts.
335  if fs::hard_link(src, dst).is_ok() {
336    return true;
337  }
338  // Hard-link can fail for cross-FS (EXDEV), permission, or because
339  // the destination already exists. Try to remove and retry once.
340  let _ = fs::remove_file(dst);
341  if fs::hard_link(src, dst).is_ok() {
342    return true;
343  }
344  // Final fallback: plain copy.
345  fs::copy(src, dst).is_ok()
346}

348/// Read a `.dims` sidecar if present.
349fn read_dims_sidecar(sidecar: &Path) -> Option<CachedDims> {
350  let raw = fs::read_to_string(sidecar).ok()?;
351  let mut lines = raw.split('\n').map(|s| s.trim());
352  let width = lines.next()?.parse::<u32>().ok()?;
353  let height = lines.next()?.parse::<u32>().ok()?;
354  Some(CachedDims { width, height })
355}
356
357/// Write a `.dims` sidecar via tmp+rename for atomicity. Idempotent
358/// and best-effort — failures leave no state behind.
359fn write_dims_sidecar(sidecar: &Path, dims: CachedDims) {
360  if let Some(parent) = sidecar.parent() {
361    if fs::create_dir_all(parent).is_err() {
362      return;
363    }
364  }
365  let pid = std::process::id();
366  let nanos = std::time::SystemTime::now()
367    .duration_since(std::time::UNIX_EPOCH)
368    .map(|d| d.as_nanos())
369    .unwrap_or(0);
370  let mut tmp = sidecar.as_os_str().to_owned();
371  tmp.push(format!(".tmp.{pid}.{nanos}"));
372  let tmp_path = PathBuf::from(tmp);
373  let body = format!("{}\n{}\n", dims.width, dims.height);
374  if fs::write(&tmp_path, body).is_err() {
375    let _ = fs::remove_file(&tmp_path);
376    return;
377  }
378  if fs::rename(&tmp_path, sidecar).is_err() {
379    let _ = fs::remove_file(&tmp_path);
380  }
381}

383/// Result of a cache lookup.
384#[derive(Debug, Clone, Copy)]
385pub struct CacheHit {
386  pub dims: Option<CachedDims>,
387}

389/// Look the cache up. On hit: hardlink/copy into `dest`, refresh the
390/// cache entry's mtime, return `Some(CacheHit{dims})`. On miss or any
391/// I/O hiccup, return `None` so the caller falls through to a real
392/// conversion.
393pub fn lookup(source: &str, dest: &str, key: RenderKey) -> Option<CacheHit> {
394  lookup_digest(source, None, dest, key)
395}
396
397/// [`lookup`], with the source's [`SourceDigest`] when the caller has it.
398fn lookup_digest(
399  source: &str,
400  digest: Option<&SourceDigest>,
401  dest: &str,
402  key: RenderKey,
403) -> Option<CacheHit> {
404  if disabled() {
405    return None;
406  }
407  let root = cache_root()?;
408  let hash = source_key(source, digest, key)?;
409  let cached = cache_path(&root, &hash, key.ext);
410  if !cached.exists() {
411    MISSES.fetch_add(1, Ordering::Relaxed);
412    return None;
413  }
414  if !link_or_copy(&cached, Path::new(dest)) {
415    MISSES.fetch_add(1, Ordering::Relaxed);
416    return None;
417  }
418  // Refresh mtime so the LRU prune doesn't evict an active entry.
419  // Errors here are non-fatal; the hit already succeeded.
420  let _ = touch_now(&cached);
421  let dims = read_dims_sidecar(&dims_sidecar(&cached));
422  HITS.fetch_add(1, Ordering::Relaxed);
423  Some(CacheHit { dims })
424}

426/// Insert `dest` (and optionally its dimensions) into the cache under
427/// `(source, key)`. Idempotent and best-effort: any I/O failure leaves
428/// the cache unchanged.
429pub fn store(source: &str, dest: &str, key: RenderKey, dims: Option<CachedDims>) {
430  store_digest(source, None, dest, key, dims)
431}

433/// [`store`], with the source's [`SourceDigest`] when the caller has it.
434fn store_digest(
435  source: &str,
436  digest: Option<&SourceDigest>,
437  dest: &str,
438  key: RenderKey,
439  dims: Option<CachedDims>,
440) {
441  if disabled() {
442    return;
443  }
444  let Some(root) = cache_root() else { return };
445  let Some(hash) = source_key(source, digest, key) else {
446    return;
447  };
448  let cached = cache_path(&root, &hash, key.ext);
449  // A sidecar without its entry is never reclaimed: the prune removes one only with its entry.
450  if install(Path::new(dest), &cached)
451    && let Some(d) = dims
452  {
453    write_dims_sidecar(&dims_sidecar(&cached), d);
454  }
455  // Best-effort LRU prune after insert (process-locked).
456  prune_if_over_cap(&root);
457}

459/// Install `dest` as the cache entry `cached`, unless an entry is already there; whether an entry is in place after.
460fn install(dest: &Path, cached: &Path) -> bool {
461  // Atomic install: write to .tmp.<pid>.<nanos>, rename into place.
462  // Concurrent writers each get a private tmp and race the rename —
463  // last rename wins, both sources are byte-equivalent.
464  let pid = std::process::id();
465  let nanos = std::time::SystemTime::now()
466    .duration_since(std::time::UNIX_EPOCH)
467    .map(|d| d.as_nanos())
468    .unwrap_or(0);
469  let mut tmp = cached.as_os_str().to_owned();
470  tmp.push(format!(".tmp.{pid}.{nanos}"));
471  let tmp = PathBuf::from(tmp);
472  // A failed copy may have left a partial tmp, a failed rename a whole one: neither is reclaimed otherwise but
473  // by the prune's `STALE_TMP_AGE` sweep (33k such files in the fleet's cache by 2026-11-16).
474  if !link_or_copy(dest, &tmp) {
475    let _ = fs::remove_file(&tmp);
476    return cached.is_file();
477  }
478  if !cached.is_file() {
479    // rename is atomic on the same filesystem; failures are non-fatal.
480    if fs::rename(&tmp, cached).is_err() {
481      let _ = fs::remove_file(&tmp);
482    }
483  } else {
484    // Cache file already present (race with another writer); clean up.
485    let _ = fs::remove_file(&tmp);
486    let _ = touch_now(cached);
487  }
488  cached.is_file()
489}

491fn touch_now(p: &Path) -> std::io::Result<()> {
492  let now = std::time::SystemTime::now();
493  let f = fs::File::options().write(true).open(p)?;
494  f.set_modified(now)?;
495  drop(f);
496  Ok(())
497}

499/// Acquire an advisory exclusive lock on the prune sentinel file. The
500/// lock is held for the lifetime of the returned handle. `None` =>
501/// another process already holds the lock; skip the prune.
502///
503/// On Unix uses `flock(LOCK_EX | LOCK_NB)`. On Windows the lock is a
504/// best-effort `create_new` sentinel; multi-process correctness is
505/// still preserved because the prune itself is `ENOENT`-tolerant.
506#[cfg(unix)]
507fn acquire_prune_lock(root: &Path) -> Option<fs::File> {
508  use std::os::fd::AsRawFd;
509  let lock_path = root.join(".prune.lock");
510  let _ = fs::create_dir_all(root);
511  let file = fs::File::options()
512    .create(true)
513    .write(true)
514    .truncate(false)
515    .open(&lock_path)
516    .ok()?;
517  // SAFETY: fd is an owned, open file descriptor for the lock file; flock(2)
518  // operates on it without aliasing Rust memory.
519  let rc = unsafe { libc::flock(file.as_raw_fd(), libc::LOCK_EX | libc::LOCK_NB) };
520  if rc == 0 { Some(file) } else { None }
521}
522
523#[cfg(not(unix))]
524fn acquire_prune_lock(root: &Path) -> Option<fs::File> {
525  let lock_path = root.join(".prune.lock");
526  let _ = fs::create_dir_all(root);
527  fs::File::options()
528    .create_new(true)
529    .write(true)
530    .open(&lock_path)
531    .ok()
532}
533
534#[cfg(not(unix))]
535fn release_prune_lock(root: &Path, _f: fs::File) {
536  let _ = fs::remove_file(root.join(".prune.lock"));
537}

539/// Walk the cache, total up sizes, and if over the cap delete oldest
540/// entries (by mtime) until under; remove the `.tmp.` files older than
541/// [`STALE_TMP_AGE`]. Errors are non-fatal. Only one process performs a
542/// prune at a time (advisory lock). Without a cap (`0`) it returns at
543/// once, so stale tmp files stay too.
544fn prune_if_over_cap(root: &Path) {
545  // A clock under an hour past the epoch has no stale tmp; the size cap still applies.
546  let now = std::time::SystemTime::now();
547  let stale_before = now
548    .checked_sub(STALE_TMP_AGE)
549    .unwrap_or(std::time::UNIX_EPOCH);
550  prune_if_over_cap_at(root, stale_before);
551}

553/// When a file's inode last changed: a tmp hard-linked from an old output keeps the output's mtime,
554/// but `link()` sets its ctime.
555#[cfg(unix)]
556fn changed(meta: &fs::Metadata) -> Option<std::time::SystemTime> {
557  use std::os::unix::fs::MetadataExt;
558  let since_epoch = std::time::Duration::new(
559    u64::try_from(meta.ctime()).ok()?,
560    u32::try_from(meta.ctime_nsec()).ok()?,
561  );
562  std::time::UNIX_EPOCH.checked_add(since_epoch)
563}
564
565#[cfg(not(unix))]
566fn changed(meta: &fs::Metadata) -> Option<std::time::SystemTime> { meta.modified().ok() }

568/// [`prune_if_over_cap`], taking the `.tmp.` files changed before `stale_before` for stale.
569fn prune_if_over_cap_at(root: &Path, stale_before: std::time::SystemTime) {
570  let cap = max_bytes();
571  if cap == 0 {
572    return;
573  }
574  let Some(_lock) = acquire_prune_lock(root) else {
575    // Another process is pruning; let it work.
576    return;
577  };
578  let mut entries: Vec<(PathBuf, u64, std::time::SystemTime)> = Vec::new();
579  let mut total: u64 = 0;
580  let Ok(shard_iter) = fs::read_dir(root) else {
581    return;
582  };
583  for shard in shard_iter.flatten() {
584    let path = shard.path();
585    let Ok(meta) = shard.metadata() else { continue };
586    // Skip non-dirs (e.g. .prune.lock).
587    if !meta.is_dir() {
588      continue;
589    }
590    let Ok(entry_iter) = fs::read_dir(&path) else {
591      continue;
592    };
593    for entry in entry_iter.flatten() {
594      let path = entry.path();
595      let Some(name) = path.file_name().and_then(|n| n.to_str()) else {
596        continue;
597      };
598      // A tmp sidecar is an install in flight, or one a killed process never finished: removed once
599      // older than any install takes. Dim metadata follows its parent's lifecycle.
600      if name.contains(".tmp.") {
601        let stale = entry
602          .metadata()
603          .ok()
604          .and_then(|meta| changed(&meta))
605          .is_some_and(|changed| changed < stale_before);
606        if stale {
607          let _ = fs::remove_file(&path);
608        }
609        continue;
610      }
611      if name.ends_with(".dims") {
612        continue;
613      }
614      let Ok(meta) = entry.metadata() else { continue };
615      let size = meta.len();
616      let mtime = meta.modified().unwrap_or(std::time::UNIX_EPOCH);
617      total = total.saturating_add(size);
618      entries.push((path, size, mtime));
619    }
620  }
621  if total <= cap {
622    // Lock auto-released when `_lock` goes out of scope at fn end.
623    return;
624  }
625  entries.sort_by_key(|(_, _, t)| *t);
626  let mut to_free = total.saturating_sub(cap);
627  for (path, size, _) in entries {
628    if to_free == 0 {
629      break;
630    }
631    // Tolerate ENOENT: another writer may have raced this entry away.
632    if fs::remove_file(&path).is_ok() {
633      // Also drop the .dims sidecar if present (best-effort).
634      let mut dims = path.into_os_string();
635      dims.push(".dims");
636      let _ = fs::remove_file(PathBuf::from(dims));
637      to_free = to_free.saturating_sub(size);
638    }
639  }
640  // _lock drops here, releasing the flock.
641}

643/// Three-state result from a cached conversion. Disambiguates the two
644/// failure modes that would otherwise collapse to `None`:
645///
646/// * `Ok { dims: Some(_) }` — conversion succeeded (or hit), dims known
647/// * `Ok { dims: None }`     — conversion succeeded but dims unknown
648/// * `Failed`                — conversion did not produce a usable output
649#[derive(Debug, Clone, Copy)]
650pub enum ConvertResult {
651  Ok { dims: Option<CachedDims> },
652  Failed,
653}
654
655impl ConvertResult {
656  pub fn is_ok(&self) -> bool { matches!(self, ConvertResult::Ok { .. }) }
657  pub fn dims(&self) -> Option<CachedDims> {
658    match self {
659      ConvertResult::Ok { dims } => *dims,
660      ConvertResult::Failed => None,
661    }
662  }
663}

665/// Cache-aware wrapper around any `(source, dest) -> bool` conversion
666/// that also wants to round-trip dimensions through the cache.
667///
668/// `measure` runs on the freshly-produced `dest` and feeds the cache
669/// for next time. On a cache hit `measure` is NOT called — the cached
670/// `.dims` value is returned instead.
671///
672/// Callers without a dimension hook can pass `measure = || None` to
673/// get the bytes-only cache behaviour.
674///
675/// `policy` decides whether the shared cache is consulted at all; see
676/// [`CachePolicy`].
677pub fn with_cache_dims<F, M>(
678  policy: CachePolicy,
679  source: &str,
680  digest: Option<&SourceDigest>,
681  dest: &str,
682  key: RenderKey,
683  convert: F,
684  measure: M,
685) -> ConvertResult
686where
687  F: FnOnce() -> bool,
688  M: FnOnce() -> Option<CachedDims>,
689{
690  if policy == CachePolicy::Bypass {
691    if !convert() {
692      return ConvertResult::Failed;
693    }
694    return ConvertResult::Ok { dims: measure() };
695  }
696  if let Some(hit) = lookup_digest(source, digest, dest, key) {
697    if let Some(d) = hit.dims {
698      return ConvertResult::Ok { dims: Some(d) };
699    }
700    // Dimensions sidecar missing or unreadable — measure now and
701    // attach so future hits get it for free.
702    let m = measure();
703    if let Some(d) = m {
704      if let (Some(root), Some(hash)) = (cache_root(), source_key(source, digest, key)) {
705        let cached = cache_path(&root, &hash, key.ext);
706        if cached.exists() {
707          write_dims_sidecar(&dims_sidecar(&cached), d);
708        }
709      }
710    }
711    return ConvertResult::Ok { dims: m };
712  }
713  if !convert() {
714    return ConvertResult::Failed;
715  }
716  let dims = measure();
717  store_digest(source, digest, dest, key, dims);
718  ConvertResult::Ok { dims }
719}
720
721/// Bytes-only cache wrapper. Use when the caller doesn't need
722/// dimensions cached (e.g. SVG path where viewBox dims are cheap to
723/// re-read from disk). Returns `true` on success.
724///
725/// `policy` decides whether the shared cache is consulted at all; see
726/// [`CachePolicy`].
727pub fn with_cache<F>(
728  policy: CachePolicy,
729  source: &str,
730  dest: &str,
731  key: RenderKey,
732  convert: F,
733) -> bool
734where
735  F: FnOnce() -> bool,
736{
737  if policy == CachePolicy::Bypass {
738    return convert();
739  }
740  if lookup(source, dest, key).is_some() {
741    return true;
742  }
743  let ok = convert();
744  if ok {
745    store(source, dest, key, None);
746  }
747  ok
748}

1219  fn concurrent_writers_converge_to_one_cache_entry() {
1220    // Multi-process safety simulation: spawn 8 threads, all writing
1221    // the SAME key, all writing distinct dests. After all join, the
1222    // cache must contain exactly one final file (no leftover .tmp.*
1223    // sidecars), and a follow-up hit must succeed.
1224    let _ = shared_cache_dir();
1225    let dir = temp_dir("concurrent");
1226    let bytes = unique_source_bytes("concurrent");
1227    let src = dir.join("src.bin");
1228    write_bytes(&src, &bytes);
1229    let key = RenderKey {
1230      page:    None,
1231      density: 90,
1232      ext:     "png",
1233    };
1234
1235    let src_s = src.to_string_lossy().into_owned();
1236    let dir_s = dir.to_string_lossy().into_owned();
1237
1238    std::thread::scope(|s| {
1239      for i in 0..8 {
1240        let src_s = src_s.clone();
1241        let dir_s = dir_s.clone();
1242        s.spawn(move || {
1243          let dest = format!("{dir_s}/dest_{i}.png");
1244          with_cache(CachePolicy::Shared, &src_s, &dest, key, || {
1245            // Tiny artificial work to encourage interleaving.
1246            std::thread::sleep(std::time::Duration::from_millis(5));
1247            fs::write(&dest, b"final-bytes").unwrap();
1248            true
1249          });
1250        });
1251      }
1252    });
1253
1254    // Verify exactly one cache file for this hash, no leftover tmp.
1255    let root = shared_cache_dir();
1256    let hash = hash_key(&src, key).unwrap();
1257    let cached = cache_path(root, &hash, key.ext);
1258    assert!(
1259      cached.exists(),

1261    );

1263    let tmp_count = fs::read_dir(shard_dir)
1264      .unwrap()
1265      .filter_map(Result::ok)

1268    assert_eq!(
1269      tmp_count, 0,

1271    );

1274    let dest_check = dir.join("dest_check.png");
1275    let hit = lookup(&src_s, dest_check.to_str().unwrap(), key);

1290  /// A store whose install fails leaves neither its tmp file nor a `.dims` sidecar, which the prune
1291  /// reclaims only with its entry: a missing output (the copy fails before the tmp exists), an output
1292  /// that fails mid-copy (a partial tmp), a directory in the entry's place (the rename fails).
1293  #[test]
1294  fn a_failed_install_leaves_neither_tmp_nor_dims() {
1295    let root = shared_cache_dir();
1296    let dir = temp_dir("install");
1297    let key = RenderKey {
1298      page:    None,
1299      density: 90,
1300      ext:     "png",
1301    };
1302    let missing = dir.join("missing.png");
1303    let in_the_way = dir.join("in-the-way.png");
1304    write_bytes(&in_the_way, b"png");
1305    let mut cases = vec![("missing", missing), ("in-the-way", in_the_way)];
1306    // Reading `/proc/self/mem` at offset 0 (unmapped) fails with EIO after the copy has created its target.
1307    if cfg!(target_os = "linux") {
1308      cases.push(("unreadable", PathBuf::from("/proc/self/mem")));
1309    }
1310    for (label, dest) in cases {
1311      let src = dir.join(format!("{label}.src"));
1312      write_bytes(&src, &unique_source_bytes(label));
1313      let cached = cache_path(root, &hash_key(&src, key).unwrap(), key.ext);
1314      if label == "in-the-way" {
1315        fs::create_dir_all(cached.join("occupied")).unwrap();
1316      }
1317      store(
1318        src.to_str().unwrap(),
1319        dest.to_str().unwrap(),
1320        key,
1321        Some(CachedDims { width: 1, height: 2 }),
1322      );
1323      let entry = cached.file_name().unwrap().to_string_lossy().into_owned();
1324      let shard = cached.parent().unwrap();
1325      let leftovers: Vec<String> = fs::read_dir(shard)
1326        .unwrap()
1327        .flatten()
1328        .map(|e| e.file_name().to_string_lossy().into_owned())
1329        .filter(|name| name.starts_with(&entry) && *name != entry)
1330        .collect();
1331      assert_eq!(leftovers, Vec::<String>::new(), "{label}");
1332      assert_eq!(cached.is_dir(), label == "in-the-way", "{label}");
1333      if label == "in-the-way" {
1334        fs::remove_dir_all(&cached).unwrap();
1335      }
1336    }
1337  }

1339  #[test]
1340  fn a_prune_reclaims_the_tmp_files_of_killed_installs() {
1341    let root = temp_dir("prune-tmp");
1342    let shard = root.join("ab");
1343    let old = shard.join("abcdef.png.tmp.17.1");
1344    let old_dims = shard.join("abcdef.png.dims.tmp.17.2");
1345    let entry = shard.join("abcdef.png");
1346    let output = root.join("out.png");
1347    for path in [&old, &old_dims, &entry, &output] {
1348      write_bytes(path, b"bytes");
1349    }
1350    let two_hours_ago = std::time::SystemTime::now() - std::time::Duration::from_secs(7200);
1351    for path in [&entry, &output] {
1352      fs::File::options()
1353        .write(true)
1354        .open(path)
1355        .unwrap()
1356        .set_modified(two_hours_ago)
1357        .unwrap();
1358    }
1359    // The kernel stamps inode times from a coarse clock: a margin on each side of the cutoff.
1360    std::thread::sleep(std::time::Duration::from_millis(50));
1361    let stale_before = std::time::SystemTime::now();
1362    std::thread::sleep(std::time::Duration::from_millis(50));
1363    // An install in flight, hard-linked from an old output: its mtime is the output's, its ctime the link's.
1364    fs::hard_link(&output, shard.join("abcdef.png.tmp.18.3")).unwrap();
1365    prune_if_over_cap_at(&root, stale_before);
1366    // On Unix the link's ctime keeps the in-flight tmp. Elsewhere the age is the mtime (std exposes no ctime), so it
1367    // is reclaimed: the install's rename then fails and the image is just not cached that time.
1368    let in_flight_kept: Vec<String> = if cfg!(unix) {
1369      vec!["abcdef.png.tmp.18.3".to_string()]
1370    } else {
1371      Vec::new()
1372    };
1373    assert_eq!(tmp_names(&shard), in_flight_kept);
1374    assert!(
1375      entry.is_file(),
1376      "an entry under the cap is kept, however old"
1377    );
1378  }
