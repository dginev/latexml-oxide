§Intermediate files

Besides the output you ask for (--dest, the images and stylesheets beside it, and the log), a conversion writes the files below. Caches are kept between runs and are always safe to delete. Scratch files are removed when a run ends, including on a timeout or a memory stop. A run that is killed or interrupted (Ctrl+C) can leave scratch behind; those files are dot-named or sit in the system temp directory, and are safe to delete. None of them is ever packed into a .zip or EPUB output.

$TMPDIR below is the system temp directory; $XDG_CACHE_HOME defaults to ~/.cache. The variables that move or turn off a cache are described in ENVIRONMENT.md.

§Written by the document itself

\openout, \write and filecontents write to an in-memory file store, never to disk, and \write18 runs nothing. One exception: Lua code run by \directlua may write files with io.open, but only under relative paths in the source directory (no .., no dot-files). These files are never removed.
