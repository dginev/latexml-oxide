Module loads

Expand description

Load sets the guards share: a package’s own file and the files it loads from other distribution packages, so a partial TeX Live (Debian’s split texlive-* packages, CI’s apt set) that ships one without the other skips the test instead of failing it (CIF0, 2026-11-13).
