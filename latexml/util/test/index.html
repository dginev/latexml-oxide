Source

Integration-test harness. Gated behind the test-utils feature (default on) so the distribution build (cargo build --no-default-features --profile maxperf --bin latexml_oxide) drops glob from the dependency graph (audit DEP-02).

Modules§

fixtures
The fixture directories’ requires tables that more than one harness reads: the tex_tests! binary and the streaming sweep (tests/streaming_sweep) of the same directory, keyed by the directory.
loads
Load sets the guards share: a package’s own file and the files it loads from other distribution packages, so a partial TeX Live (Debian’s split texlive-* packages, CI’s apt set) that ships one without the other skips the test instead of failing it (CIF0, 2026-11-13).

Structs§

GoldenVariant
A fixture’s golden <name>.<variant>.xml, compared instead of <name>.xml where the installed file’s text satisfies applies: a package release whose output really changed (pdflatex agrees), not a code divergence.
Requirements
What a test needs from the host: Perl’s requires value, in any of its three forms (a file, a list of files, or {packages => …, texlive_min => N, env => VAR}), plus programs on PATH (a Rust addition: jing).

Constants§

GUARD_JOBNAME
The jobname of a convert_with* conversion: its source is <GUARD_JOBNAME>.tex in a temporary directory, so a side file the document reads by \jobname is t.bbl, t.aux. A fixture names no file of its own t: the source is a real file, among \includegraphics{t}’s candidates and what \input{t} reads.
GUARD_TIMEOUT_SECS
The deadline of a convert_with* conversion, in seconds: the probe ceiling — a bound, so a runaway regression fails as a Fatal:Timeout rather than hanging the test, with headroom for a heavy raw-preload guard on a loaded CI box (the CLI’s own default is 60 s).
JING
The jing program the schema guards validate with (super::rng_error_count).

dump_available
True iff a latex kernel dump built from this TeX tree is on disk where the format loads one from (LATEXML_DUMP_PATH/LATEXML_DUMP_DIR, installed, dev tree). Without it the engine raw-loads expl3-code.tex (degraded mode) and the error landscape is dominated by unrelated raw-load cascades — dump-gated tests declare it (Requirements::format_dump) and SKIP visibly. The engine’s own lookup, so a test cannot disagree with the conversion it gates.

The category is anything up to the next : — missing_file, I/O, <char> count too (WISDOM 85; a lowercase-letters category missed them).

normalize_markup
Collapse pretty-printing whitespace and trim, so an element’s serialization compares equal whatever the indentation: a whitespace run that contains a newline is indentation — dropped when it touches a tag boundary (> before it or < after it), one space otherwise; a run without a newline is real text spacing and is kept verbatim.
rng_error_count
RelaxNG-validate a core-XML string against the repo’s authoritative LaTeXML.rng with jing (the S2 bar of the perfect-kernel program): the number of jing error lines, Some(0) = schema-valid; None when jing is not installed (CI installs it), logged as a skip of the check (skip); a guard whose point is the schema declares JING instead. The schema directory is prepared the way tools/perfect_kernel/validate.sh does — the .rng files copied to a temp dir with the urn:x-LaTeXML:RelaxNG: includes rewritten to relative paths — once for every process and checkout of the same schema: the directory is named by a hash of the files’ names and contents.
skip
Record a skipped test: Perl’s diag("Skip: …") on stderr and one line in skip_log_path. The only writer of the skip log.
skip_log_path
LATEXML_TEST_SKIP_LOG, else test-skips.log in the cargo target directory of the running test binary (<target>/<profile>/deps/<binary>), else in the temporary directory.
texlive_version
Perl’s texlive_version: LATEXML_TEST_TEXLIVE, else the host TeX Live year the engine resolves its dumps by, else 0.
warning_count
Count of lines carrying a Warning:<category>: diagnostic anywhere in the line (WISDOM 85: a diagnostic can follow other output on the same line), whatever its category spells. A package’s own notice that it is obsolete (aliascnt v1.7 on a 2026-06+ kernel, as pdflatex prints it) follows the installed TeX Live, not the document, so it is not counted: a guard’s count then holds on every TeX Live (portable tests, DG 2026-11-13).
xml_element
The first <tag …>…</tag> (or self-closing <tag …/>) element of xml whose start tag contains every fragment in attrs (e.g. key="smith2020"), returned WHOLE — start tag, attributes, children, end tag — with the inter-tag whitespace of pretty-printing collapsed (>\s+< → ><, trimmed) so the same element compares equal across serializers. Nesting of the same tag is tracked, so the outermost match is returned complete. None when no element matches.
