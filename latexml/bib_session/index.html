The recursive BibTeX session behind post-processing’s bibliography.

Port of LaTeXML::Post::MakeBibliography::convertBibliography (MakeBibliography.pm L171-242): a raw .bib is not parsed by a bespoke reader, it is converted — by the same engine, through BibTeX.pool, with the article’s own class and packages preloaded so the fields mean what the article meant.

It lives here rather than in latexml_post because a conversion needs convert_document, which needs this crate’s model loader; latexml_post depending on latexml_oxide would be a cycle. latexml_post declares the hook, this module fills it in — see install.
